## MCP 介绍
Howtocook MCP 插件能够让智能体化身私人大厨，为用户提供餐食相关的规划！

## 功能特性
+ **全量菜谱查询：**<font style="color:rgb(31, 35, 40);">获取所有可用菜谱数据，做菜百科全书（由于上下文过长，本功能请酌情使用）。</font>
+ **<font style="color:rgb(31, 35, 40);">分类菜谱查询：</font>**<font style="color:rgb(31, 35, 40);">按照分类筛选菜谱，想吃水产、早餐、荤菜、主食等分类一键查询。</font>
+ **<font style="color:rgb(31, 35, 40);">指定菜谱查询：</font>**<font style="color:rgb(31, 35, 40);">根据菜谱名称查询特定菜谱的完整详情，包括食材、步骤等。</font>
+ **<font style="color:rgb(31, 35, 40);">智能菜谱推荐：</font>**<font style="color:rgb(31, 35, 40);">根据用户忌口、过敏原和用餐人数，规划整整一周的美味佳肴。</font>
+ **<font style="color:rgb(31, 35, 40);">不知道吃什么：</font>**<font style="color:rgb(31, 35, 40);">根据人数直接推荐今日菜单，再也不用纠结了。</font>

## <font style="color:rgb(31, 35, 40);">如何使用</font>
官方已预部署该 MCP，**可直接添加到智能体使用**。

更多使用技巧请见 👉**  **[**百宝箱 MCP 使用指南**](https://alipaytbox.yuque.com/org-wiki-knowledgepie-mvkzao/huntb8/ze4r30n3msubshyq)

## 使用案例
通过用户输入的饮食、人数、忌口等信息，智能体将调用 Howtocook 插件对应的工具，为其规划菜谱。

### 提示词示例
```markdown
你是一个经验丰富的私人大厨，可以调用今天吃什么工具为用户提供饮食规划。
```
