## 插件介绍
Amap Maps 是高德地图推出的一款出行服务解决方案，旨在打破大模型的数据孤岛与能力边界限制，为用户提供更加智能、便捷的出行体验。

## 功能特性
+ **统一的通讯协议：**<font style="color:rgb(44, 44, 54);">MCP通过统一的大模型与外部数据、工具间的通讯协议，解决了传统出行助手应用在数据整合和功能扩展方面的难题，实现了高效的信息交流和服务协同。</font>
+ **<font style="color:rgb(44, 44, 54);">高质量数据支持：</font>**<font style="color:rgb(44, 44, 54);">自2025年3月首发以来，高德地图MCP为开发者提供了包括位置服务、地点信息搜索、路径规划、天气查询等在内的12大核心高鲜度数据，确保用户能够获取即时、准确的信息，极大地提升了出行规划和位置信息检索的效率。</font>
+ **<font style="color:rgb(44, 44, 54);">无缝的集成服务：</font>**<font style="color:rgb(44, 44, 54);">至2025年5月，随着高德地图MCP的全新升级，通过高德MCP Server与高德地图APP的无缝打通，用户可以将个性化的行程攻略自动转化为专属地图，并实现从攻略到一键导航、打车、订票的全流程丝滑体验。这不仅让用户的出行变得更加便捷，也让整个旅程更加个性化、智能化。</font>

## 使用案例
通过智能体对话查询指定城市的天气情况。

### Prompt 示例
```markdown
# 角色
你是一个智能天气查询助手，能够根据用户输入的城市名称，调用<|plugin_start|>maps_weather<|plugin_end|>来查询并反馈当地的天气情况。

## 技能
### 技能 1: 接收用户输入
1. 接受用户输入的城市名称，确保输入是有效的城市名称。
2. 验证输入的城市名称是否符合调用API的要求。

### 技能 2: 调用API查询天气
1. 使用有效的城市名称作为参数调用maps_weather API。
2. 确保API调用成功，并获取到最新的天气数据。

### 技能 3: 解析并反馈天气信息
1. 解析API返回的天气数据，提取关键信息，如温度、天气状况、风速等。
2. 将提取的信息以友好的格式反馈给用户。

#### 反馈示例
- 城市名称: <用户输入的城市名称>
- 天气状况: <如晴朗、多云、有雨等>
- 当前温度: <当前摄氏度温度>
- 风速: <当前风速>
- 更新时间: <数据最后更新时间>
===反馈示例结束===

## 限制
- 仅能查询maps_weather API支持的城市天气情况。
- 必须按照API的调用规则和限制进行操作。
- 所输出的内容必须按照给定的格式进行组织，确保信息的准确性和易读性。
- 如果API调用失败或城市名称无效，需要提供相应的错误信息。
```

## 附录：能力清单
| **能力** | **说明** | **输入** | **输出** |
| --- | --- | --- | --- |
| 地理编码 | 可将结构化地址转换为对应的经纬度坐标 | address (位置信息)，city (城市信息，非必须) | location (位置经纬度) |
| 逆地理编码 | 可将经纬度坐标转换为详细的行政区划地址信息 | location (位置经纬度) | addressComponent (位置信息，包括省市区等信息) |
| IP 定位 | 支持通过 IP 地址定位其所在地理位置 | IP | province (省)，city (城市)，adcode (城市编码) |
| 天气查询 | 支持根据城市名称或 adcode 查询指定城市的天气 | city (城市名称或城市adcode) | forecasts (预报天气) |
| 骑行路径规划 | 支持规划骑行通勤方案，最大支持 500km 路线规划，考虑天桥、单行线、封路等因素 | origin (起点经纬度)，destination (终点经纬度) | distance (规划距离)，duration (规划时间)，steps (规划步骤信息) |
| 步行路径规划 | 支持规划 100km 以内的步行路线，并返回详细规划数据 | origin (起点经纬度)，destination (终点经纬度) | origin (起点信息)，destination (终点信息)，paths (规划具体信息) |
| 驾车路径规划 | 支持根据起终点坐标规划小客车、轿车出行路线，并返回详细规划数据 | origin (起点经纬度)，destination (终点经纬度) | origin (起点信息)，destination (终点信息)，paths (规划具体信息) |
| 公交路径规划 | 支持规划包含火车、公交、地铁等多种交通方式的通勤路线，跨城场景需提供起点与终点城市 | origin (起点经纬度)，destination (终点经纬度)，city (起点城市)，cityd (终点城市) | origin (起点信息)，destination (终点信息)，distance (规划距离)，transits (规划具体信息) |
| 距离测量 | 支持计算两个经纬度坐标之间的距离和耗时 | origin (起点经纬度)，destination (终点经纬度) | origin_id (起点信息)，dest_id (终点信息)，distance (规划距离)，duration (时间) |
| 关键词搜索 | 支持根据关键词搜索相关的 POI 地点信息 | keywords (搜索关键词)，city (查询城市，非必须) | suggestion (搜索建议)，pois (地点信息列表) |
| 周边搜索 | 支持在指定中心点和半径范围内搜索 POI 地点信息 | keywords (搜索关键词)，location (中心点经度纬度)，radius (搜索半径，非必须) | pois (地点信息列表) |
| 详情搜索 | 支持查询关键词搜或周边搜获取的 POI ID 的详细信息 | id (关键词搜或周边搜获取的poiid) | location (地点经纬度)，address (地址)，business_area (商圈)，city(城市)，type (地点类型) 等 |
