# 适用场景
此插件构建方式是基于工作流搭建应用，将应用封装为插件被其他智能体应用集成使用。

**优势**：

1. 集成便捷，无需绑定卡片或其他额外配置操作
2. 信息透传，主应用的当前提问及历史对话等信息自动透传至子工作流中
3. 原生支持返回思考过程、文本恢复、信息卡片以及追问

# 创建流程
## 前置步骤：创建对话型-工作流应用
在工作空间下 **应用** 中点击 **新建应用**：选择**对话型-工作流**，基于应用功能、业务完成应用名称、介绍和logo的填写。

**搭建应用**：基于业务编排智能体功能，操作详见：[构建工作流应用](https://alipaytbox.yuque.com/org-wiki-knowledgepie-mvkzao/huntb8/zxu1rnocaz4azkxg)。

**完成应用发布**：点击右上角 **发布**，勾选平台服务协议，点击 **确认发布**。

> 已发布的工作流应用才能创建为插件

## 新建插件
在工作空间下点击 **插件**，点击 **新建插件：**

<img src="https://cdn.nlark.com/yuque/0/2025/png/29282973/1752828007065-771c0ee4-afb9-4a69-b5e6-1dca38c7d876.png" width="1440" title="" crop="0,0,1,1" id="uce591353" class="ne-image">

选择 **调用应用创建**，即 调用百宝箱企业版**当前空间下**搭建发布的智能体应用来创建插件。

| **配置项** | **说明** |
| --- | --- |
| 插件名称  | 自定义插件的名称，用于标识当前插件。输入清晰易理解的名称，便于用户使用 |
| 插件描述  | 插件的描述信息，清晰描述**主要功能**和**使用场景**，此信息将展示给用户并引导使用 |
| 插件图标  | 可使用默认图标/上传本地图片/根据描述和名称 AI 生成图标 |
| 插件调用的应用 | 选择当前空间下已发布的**对话型工作流应用**，**支持搜索** |
| 应用版本 | 若选择应用版本，即表示插件固定调用应用某个版本；若未选择，即表示始终调用应用发布最新版本 |

## 创建工具
### 填写工具的基础信息
| **配置项** | **说明** |
| --- | --- |
| 工具名称  | 用于标识当前工具的中文名称。此名称会直接向用户展示，需要使其清晰易理解。 |
| 工具英文名称 | 用于模型识别工具作用。可通过AI自动生成工具英文名。 |
| 工具描述  | 工具的描述信息。请尽量仔细描述工具的使用场景和主要功能，大模型会根据描述判断是否调用该工具，同时描述将展示给用户，需要使其准确、易于理解。 |
| 调用的应用 | 展示插件层级调用的工作流应用。可点击 **查看应用详情**跳转页面查看应用详情；若需修改应用，需返回插件层级。 |


<img src="https://cdn.nlark.com/yuque/0/2025/png/29282973/1752828786944-2e391867-ac88-413c-9b1f-a65ed2a2c8c9.png" width="1440" title="" crop="0,0,1,1" id="u643cdb31" class="ne-image">

### 配置输入参数
工具输入参数默认自动透传给调用的工作流应用

+ 若是当前对话信息、历史对话信息等系统参数，无需在入参定义，系统默认透传给调用的工作流应用；
+ 仅需添加调用的工作流应用依赖的**自定义参数**，确保工作流中同步定义了此参数。

<img src="https://cdn.nlark.com/yuque/0/2025/png/29282973/1752997545595-97f953f1-864a-49b9-990d-f815715e65e0.png" width="1440" title="" crop="0,0,1,1" id="u67809262" class="ne-image">

### 配置输出参数
输出参数不支持编辑，默认获取工作流应用的输出结果，跟随结束节点定义输出文本、卡片、追问问题建议。

配置完成后，点击 **保存**。

<img src="https://cdn.nlark.com/yuque/0/2025/png/29282973/1752997872325-10769ca0-d3fe-40dc-a3f4-c0b2944638a9.png" width="1440" title="" crop="0,0,1,1" id="u1493d514" class="ne-image">

## 发布插件
保存工具后，点击 **发布**，插件状态会更新为“已发布”。已发布的插件可被空间内智能体应用添加使用。

> 注意：该类型工具暂不支持调试。
>

<img src="https://cdn.nlark.com/yuque/0/2025/png/29282973/1752997919226-cb6bc060-336d-468e-91c5-42095705ef29.png" width="1440" title="" crop="0,0,1,1" id="u554b8062" class="ne-image">

## 工作流调试验证
在工作流应用中可引用上述发布插件，通过插件的方式引入旅行规划智能体应用的能力。

在所需的业务流程拖入插件节点，点击 **我的插件**，搜索插件名称，点击 **添加**。

<img src="https://cdn.nlark.com/yuque/0/2025/png/29282973/1752998783772-76752dda-fa0a-483a-9917-9421d02107d8.png" width="1440" title="" crop="0,0,1,1" id="u4a4e05d8" class="ne-image">

**输入**：对话信息等系统参数默认透传；自定义参数按业务逻辑选择固定传参、使用变量。

**输出**：结束节点添加 **变量消息**，变量名称自定义，变量值引用插件输出参数，即可获取应用返回的文本、卡片、追问问题建议消息。
