# 流式插件概述
百宝箱支持流式插件工具，在调用流式工具时，工具可输出多个内容片段，通过逐段动态显示，实现流式输出效果。流式工具可用在将智能体、大模型等流式接口的服务接入为插件工具的场景。

# 如何创建流式工具
目前自定义插件下，可创建流式工具。

**限制：**

+ 当前仅支持 String 类型的输出参数，在**工作流对话模式**下，可流式输出。后续将支持在简单构建的应用中支持流式工具的使用。
+ 仅[基于已有API创建插件](https://alipaytbox.yuque.com/sxs0ba/huntb8/wqnceq3h8ktg3q69)时，支持创建流式工具，在百宝箱 IDE 创建插件不支持流式工具。

### 设置输入参数
根据服务端要求，填写需要的请求参数

其中标准参数中的内容，需要在工作流中显示的传入，比如需要依赖大模型抽取的参数，可以定义在标准参数中

隐藏参数中的内容，在工作流中无需传入，取值方式分固定值和引用系统变量，实际插件执行时，平台会透传这些参数。

如：参数a字段设置了固定值为123，平台在调用插件时，会固定将a字段传入123给插件服务端，

如：参数b字段设置了引用系统变量为用户当前提问问题，平台在调用插件时，会当前用户提问时的问题以b字段透传给插件服务端

### 流式输出协议约定
配置流式工具，插件的接口需要实现 Server-Sent Events (SSE) 传输协议，并遵守以下数据协议规范

<font style="background-color:#FBDE28;">当前仅支持 String 类型的数据流式返回</font>

| 字段 | 类型 | 是否必填 | 含义 |
| --- | --- | --- | --- |
| id | String | 必填 | **事件 id** |
| event | String | 必填 | **事件类型**<br/>+ message：普通消息<br/>+ error：异常消息 |
| data | Object | 必填 | **数据** |


data数据协议

| 字段名 | 类型 | 是否必填 | 含义 |
| --- | --- | --- | --- |
| stream_id | String | 必填 | **消息 id**，相同的表示连续的消息片段，属于同一条消息，不同表示不同的消息（从0开始）<br/><font style="background-color:#FBDE28;">event = error 不需要传</font> |
| code | String | 选填 | **状态码**，event = error 时需要定义 |
| message | String | 选填 | **状态信息**，用来解释状态码的原因 |
| contentType | String | 必填 | **内容类型**<br/>+ stream：流式回答文本<br/>+ thinking：思考过程内容<br/>+ card：卡片内容 |
| content | Object | 必填 | **具体数据内容：**根据contentType不同，内容格式不同，具体见下面示例 |
| is_finish | Boolean | 选填 | **结束标识**，用来判断整个流是否结束，只需在最后一个业务数据包中设置 is_finish |

##### 消息输出的流程
###### 思维链分段开始
发送基础的标题和icon信息，同一个分段cotId，在流程中需要更新，可在思维链分段结束消息后，再次发送一次新数据来覆盖。

```json
id:0
event:message
data: {"stream_id": "2", "contentType": "cot_start","content": {
  "cotId": "1",
  "pTitle": "思考中",
  "pIconUrl": "https://mdn.alipayobjects.com/huamei_r8fpdq/afts/img/A*TekfR40u6j8AAAAAQJAAAAgAegGtAQ/original",
  "title": "天气查询中",
  "iconUrl": "https://mdn.alipayobjects.com/huamei_r8fpdq/afts/img/A*wWUOQ6V8h2YAAAAAJzAAAAgAegGtAQ/original"
}}
```

文本内容可一次消息全发出来，也可流式分多个消息发

###### 思维链分段结束
同一个分段cotId，思维链分段内容输出完，需要发送一次分段结束消息。

```json
id:0
event:message
data: {"stream_id": "2", "contentType": "cot_end","content": {
  "cotId": "1"
}}
```

###### 注意点
更新每一个分组思维链内容时，都需要完整的输出思维链分段开始(cot_start)、思维链分段内容输出(cot)、思维链分段结束(cot_end)，例如下面3个步骤节点都有开始和完成的状态需要更新思维链内容，则每个步骤里都需要发两组思维链消息。

第一组 代表步骤1开始时的思维链内容，分别发送cot_start、cot、cot_end三个消息

第二组 代表步骤1完成时的思维链内容，分别发送cot_start、cot、cot_end三个消息

#### 其它文本流内容
返回的文本字段，不要用content，任意用其他字段，可在工作流中传递给其它节点使用

```json
id:0
event:message
data: {"stream_id": "1","str": "我是一个字符"}
```



#### 异常示例
```json
id:0
event:error
data: {"code": "500", "message": "服务端异常"}
```
