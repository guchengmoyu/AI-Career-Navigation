<font style="color:rgba(0, 0, 0, 0.88);">业务参数是指除插件必需的请求入参外，针对特定业务场景所设置的额外配置参数。业务参数无需模型进行识别抽取。插件开发者在创建插件时定义所需的业务参数配置后，当其它用户在工作流或者应用中使用该工具时，平台会通过业务配置表单引导用户完成个性化业务参数设置。插件开发者工具服务内部可以获取用户填写的业务配置来实现插件业务逻辑。</font>

<font style="color:rgba(0, 0, 0, 0.88);">注意：仅“基于已有服务创建”、“在百宝箱IDE中创建”两种方式支持业务参数定义。</font>

# <font style="color:rgba(0, 0, 0, 0.88);">插件开发者定义业务参数</font>
## 方式一：列表定义
平台抽取常用表单组件和组件配置，支持通过列表方式定义业务参数表单。

在参数定义依据插件接收的输入结构定义表单字段描述、组件类型等，完成名称、描述等必填字段后，右侧支持实时预览表单。

## 方式二：表单Schema定义
使用表单Schema模式以支持高级功能。

列表模式在应对复杂场景（如表单字段联动校验、显隐规则）时存在局限，可通过**转换为表单Schema模式**，通过自定义Schema来构建复杂表单。

### 切换表单Schema定义
点击 切换表单Schema定义

1. **<font style="color:rgb(64, 64, 64);">初始转换：</font>**<font style="color:rgb(64, 64, 64);"> 如果您已定义了列表参数，平台会基于这些参数自动生成初始 Schema，可预览此Schema决策是否转换。</font>
2. **<font style="color:rgb(64, 64, 64);">操作不可逆：</font>**<font style="color:rgb(64, 64, 64);"> </font>**<font style="color:rgb(64, 64, 64);">转换到 Schema 模式后，将无法再切换回列表模式。</font>**<font style="color:rgb(64, 64, 64);"> 请谨慎操作！</font>

**<font style="color:rgb(64, 64, 64);">入口：</font>**<font style="color:rgb(64, 64, 64);">插件配置面板的</font>**<font style="color:rgb(64, 64, 64);">右上角</font>**<font style="color:rgb(64, 64, 64);">进行设置</font>

**<font style="color:rgb(64, 64, 64);">配置表单：</font>**<font style="color:rgb(64, 64, 64);">配置面板中的业务配置即为插件定义表单，使用该插件的用户将根据此表单填写所需参数并提交。</font>
