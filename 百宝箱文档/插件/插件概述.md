本文将介绍什么是插件，以及如何在百宝箱中创建并使用它。

## 什么是插件
插件是一个工具集，它提供了一种灵活的方式来扩展应用的能力，满足你不同的个性化需求。目前，百宝箱已在插件市场中提供多种场景的插件，包括：交通出行、文旅景区、高校服务、会展服务、内容搜索等，你可按需使用。

:::info
**说明**：插件可以包含一到多个工具，应用在调用某个工具时，实际上就是在调用对应的 API.

:::

## 创建插件
若百宝箱提供的插件无法满足你的业务需求，你可以通过下述方式在百宝箱中进行插件的创建与定义：

+ [基于已有服务创建](https://alipaytbox.yuque.com/sxs0ba/huntb8/wqnceq3h8ktg3q69)：适用于将已开发或公开的 API 快速封装为插件。
+ [在 IDE 中创建](https://alipaytbox.yuque.com/sxs0ba/huntb8/xh9iz5i64t9yo68a)：在百宝箱 IDE 中，通过代码编写的方式进行插件的定义与调试。
+ [调用应用创建](https://alipaytbox.yuque.com/sxs0ba/huntb8/yxlh2cxzhmh782y1)：将已发布的应用封装为插件，并供其他应用调用。
+ [创建 MCP 服务](https://alipaytbox.yuque.com/sxs0ba/huntb8/hwhtg4sp1mdppsib)：支持接入已有 MCP 或在百宝箱中进行部署。
+ [创建端插件](https://alipaytbox.yuque.com/sxs0ba/huntb8/gab7insico8xa51v)：端插件能够使应用直接与本地设备进行教书，从而实现对本地设备的控制与信息获取。

除了上述方式以外，你可以启用百宝箱发布在服务市场中的各类插件，并进行自定义改造，从而使其更加贴合业务需求。

## 使用插件
你可以将插件配置到自建的智能体应用中，从而进行能力扩展。

1. 访问百宝箱[应用](https://www.tbox.cn/agentWeb/my)。
2. 在应用列表中找到并点击进入目标应用编排页。
3. 在应用编排页的插件配置模块进行插件添加。
