### <font style="color:rgb(28, 30, 32);">功能描述</font>
<font style="color:rgba(0, 1, 9, 0.88);">获取最新新闻列表，支持分页查询，返回新闻标题、来源、图片及详情链接等信息</font>

### <font style="color:rgb(28, 30, 32);">参数说明</font>
#### <font style="color:rgba(0, 1, 9, 0.88);">输入toolParams对象</font>
| **<font style="color:rgba(0, 1, 9, 0.88);">参数名</font>** | **<font style="color:rgba(0, 1, 9, 0.88);">参数说明</font>** |
| --- | --- |
| <font style="color:rgba(0, 1, 9, 0.88);">toolParams</font> | <font style="color:rgba(0, 1, 9, 0.88);">object</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">pageNo</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 页码，默认第一页</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">pageSize</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 页大小，默认为10</font> |


```json
{
  "toolParams": {
    "pageNo": "1",
    "pageSize": "10"
  }
}
```

| **<font style="color:rgba(0, 1, 9, 0.88);">参数名</font>** | **<font style="color:rgba(0, 1, 9, 0.88);">参数说明</font>** |
| --- | --- |
| <font style="color:rgba(0, 1, 9, 0.88);">pageNo</font> | <font style="color:rgba(0, 1, 9, 0.88);">number · 当前页</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">result</font> | <font style="color:rgba(0, 1, 9, 0.88);">list · 查询结果</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">pageSize</font> | <font style="color:rgba(0, 1, 9, 0.88);">number · 页大小</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">totalPage</font> | <font style="color:rgba(0, 1, 9, 0.88);">number · 总页码</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">totalCount</font> | <font style="color:rgba(0, 1, 9, 0.88);">number · 总数量</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">result.date</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 发布时间 yyyy-mm-dd HH-mm-ss</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">result.from</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 新闻来源</font> |

| <font style="color:rgba(0, 1, 9, 0.88);">result.imgUrl</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 缩略图链接</font> |
