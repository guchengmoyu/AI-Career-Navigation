# 插件调用报错Plugin node execute httpProxyResult status_code is fail<font style="color:rgb(13, 26, 38);">？</font>
**问题**：百宝箱插件工具调用报错：`"error" :"{"errorMsg":"plugin node execute httpProxyResult status_code is fail:500 Illegal header name b'bear token'"}"`。

<img src="https://cdn.nlark.com/yuque/0/2026/png/29282973/1772249901499-86c92733-4438-42ce-91c3-3285de9488c7.png" width="889" title="" crop="0,0,1,1" id="ue8c0a047" class="ne-image">

**原因及解决方案**：服务地址网络不可达。如果您的服务部署在内网或受限网络，可能导致插件网关无法访问。

1. 检查服务地址是否支持公网访问
2. 如需IP加白，请添加以下插件代理网关IP：
    - `47.99.127.154`
    - `112.124.26.229`
