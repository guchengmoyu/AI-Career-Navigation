本文将介绍什么是思维链以及如何通过插件为智能体配置思维链。

## 功能介绍
**思维链（****<font style="color:rgb(6, 10, 38);">Chain-of-Thought, CoT</font>****）**是一种让智能体在输出最终答案前，先通过一系列清晰、可追溯的中间推理步骤进行思考的机制。它能够模拟人类解决问题的方式，将复杂任务分解为多个逻辑连贯的步骤，从而显著提升推理的准确性、减少错误输出、并增强决策过程的透明度。

通过百宝箱思维链插件，可以为智能体添加思维链，从而帮助智能体更加可靠地完成推理、工具调用和任务规划，让用户能够理解其思考过程、感知其运行状态，进而建立更高的信任度。

## 配置说明
### 步骤 1：引用插件
开发者可以访问百宝箱服务市场，找到并点击**思维链**插件卡片进入详情页，并点击右上角的添加至我的应用，将其添加至指定应用中。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1768362625309-416b90b1-530b-48f3-888a-09d0f9d6c7a1.png" width="1519.2" title="" crop="0,0,1,1" id="ufd487613" class="ne-image">

或者可直接在目标工作流应用的目标节点前后，分别通过添加插件节点 > 找到并添加**思维链**节点的方式，实现插件引用。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1768362709149-c53a90ca-8c2c-43a0-ad62-1573b2511f30.png" width="1020.8" title="" crop="0,0,1,1" id="ua8b49b5c" class="ne-image">

| 参数名 | 必填 | 说明 |
| --- | --- | --- |
| <font style="color:rgba(0, 0, 0, 0.88);">cot_id</font> | 是 | **思维链的唯一标识**。可用于关联同一推理过程中的多个消息，包括由思维链消息发送插件发出的结束消息。例如，在天气查询节点中，若需区分“查询中”和“查询完成”两种状态，可在该节点前后分别插入思维链插件，并将两者的 cot_id 设置为相同值，从而确保它们归属于同一条思维链上下文。 |
| <font style="color:rgba(0, 0, 0, 0.88);">p_title</font> | 否 | **思维链的主标题**。未填写时，将根据思考状态分别展示 `思考中`和 `思考完成` ，效果如上图中的 ②。 |
| <font style="color:rgba(0, 0, 0, 0.88);">p_icon_url</font> | 否 | **思维链主图标的 URL 地址**。未填写时，将展示百宝箱默认 icon， 效果如上图中的 ①。 |
| <font style="color:rgba(0, 0, 0, 0.88);">title</font> | 否 | **思维链的阶段标题**，效果如上图中的 ④。 |
| <font style="color:rgba(0, 0, 0, 0.88);">icon</font> | 否 | **思维链阶段图标的 URL 地址**。未填写时，将展示百宝箱默认 icon效果如上图中的 ③。 |
| <font style="color:rgba(0, 0, 0, 0.88);">text</font> | 否 | **思维链展示的文本内容**。效果如上图中的 ⑤，文本内容支持[markdown格式渲染](https://alipaytbox.yuque.com/sxs0ba/huntb8/lhpsw23n3xugom4x) |
| <font style="color:rgba(0, 0, 0, 0.88);">card_id</font> | 否 | 支持填入卡片 ID，实现在思维链中展示百宝箱卡片。卡片 ID 可在卡片编排页上方的地址栏中获取，如 `https://b.tbox.cn/inc/aicard/edit/20251224******2523`中的 `20251224******2523`。 |
| <font style="color:rgba(0, 0, 0, 0.88);">card_data</font> | 否 | 请使用 JSON 格式（key:value 形式）填写卡片内容参数，如 `{"scenicName":"外滩","provider":"上海旅游集团","imageUrl":"https://www.weavefox.cn/api/bolt/unsplash_image?keyword=上海,外滩&width=400&height=180&random=上海_外滩_400_180","description":"外滩是上海的标志性景观，沿黄浦江而建，拥有众多风格各异的历史建筑，夜晚灯光璀璨，是欣赏上海天际线的最佳地点。","detailUrl":"https://b.tbox.cn"}` |
