# 插件功能说明
为了解决数据分析处理时长过程的等待或超时问题，该插件提供了异步调用的功能。

# 使用方法
插件的配置过程和同步输出的chatBI插件一样，参考文档：

[Tbox AI ChatBI Agent](https://alipaytbox.yuque.com/sxs0ba/huntb8/qg3oy9qgpo64s8hw)
