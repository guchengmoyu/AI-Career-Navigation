站内导航插件适用于在高铁站智能体中为旅客提供基础设施的智能导航服务。如为旅客提供停车场、卫生间、服务台、网约车上客点等基础设施的路线指引。本文将介绍如何配置并使用相关插件。

## 配置说明
### 步骤 1：引用插件
开发者可以访问百宝箱服务市场，找到并点击**站内导航**插件卡片进入详情页，并点击右上角的添加至我的应用，将其添加至指定应用中。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1768446455349-de839205-475c-424f-8897-cb21c35e16bf.png" width="1520.8" title="" crop="0,0,1,1" id="u625cfb84" class="ne-image">

或者可直接在目标工作流应用的目标节点前后，分别通过添加插件节点 > 找到并添加**站内导航**节点的方式，实现插件引用。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1768446526266-8679da5d-fd3a-44bf-831e-9d02dd3ff773.png" width="1033.6" title="" crop="0,0,1,1" id="udd5f1fae" class="ne-image">

### 步骤 2：配置插件及业务参数
将站内导航插件的基础设施召回插件添加至工作流后，点击对应的节点，唤起配置面板，并完成相关的配置。

#### 配置插件参数
在插件配置面板，分别完成输入参数与输出参数的配置，确保插件能够顺畅运行。

<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1768447410039-3a94bbd6-4efb-493c-98b5-5ed29a27a96c.png" width="919.2" title="" crop="0,0,1,1" id="ud78a8f5a" class="ne-image">

其中，各参数说明如下：

| 模块 | 参数名 | 必填 | 数据类型 | 说明 |
| --- | --- | --- | --- | --- |
| **输入** | query | 是 | String | 触发插件运行的 query，可固定写入或引用前置节点的输出内容。 |
| | queryDistance | 是 | Number | 设定一个 0-1 之间的检索距离阈值，满足这个阈值的内容才能够被知识库召回。 |
| | poiType | 否 | String | 设施类型，需与基础设施中设定的内容相同。 |
| **输出** | serviceIp | - | String | 本次服务的 IP |
| | traceId | - | String | 本次请求的唯一标识，通常用于问题定位与排查。 |
| | resultObj | - | Object | 本次请求的结果 |
| | poiData | - | Array | 基础设施数据详情 |
| | contentText | - | String | 设施信息透出的开场语，固定为 `<font style="color:rgb(27, 18, 18);background-color:rgba(255, 255, 255, 0.4);">为您找到如下实际位置信息，供您参考</font>` |
| | poiInfo | - | String | 设施信息摘要 |
| | success | - | Boolean | 本次请求是否成功。<br/>+ true：成功<br/>+ false：失败 |
| | resultCode | - | Number | 本次请求的状态码 |
| | resultDesc | - | String | 本次请求的结果描述 |
| | serviceName | - | String | 服务端提供的服务标识 |


#### 配置业务参数
在工作流，点击插件节点或节点的配置面板中的**业务配置**，进行业务参数的调整，通常用于开发者对插件本身进行个性化配置，使其更加贴合业务诉求。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1768457574909-9ec57bf9-07b5-42ba-bc00-0da962680715.png" width="984" title="" crop="0,0,1,1" id="u3ed2156e" class="ne-image">

在插件业务配置面板中，开发者可以跳转至对应知识库完成基础设施信息的维护。同时，也支持调整召回距离、是否精排等设定实现插件微调，从而优化知识召回效果。

<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1768457731418-bd704dc6-a900-46d7-85dc-bfb4a045d212.png" width="500" title="" crop="0,0,1,1" id="ub1f7e3fe" class="ne-image">

其中，各配置说明如下。

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 基础设置知识库 | 否 | 在对客使用前，请**确保您已经完成基础设施知识库的维护**，若无，可点击**前往配置**，快速前往知识库进行内容的填充。 |
| 召回距离（0-1） | 是 | 召回默认值，如果前置节点并无对应基础设施的特殊召回值传入，则使用默认值从知识库中召回数据 |
| 前 N 个 | 是 | 指最大返回结果数。 |
| 是否重精排 | 是 | 精排，即精细排序，是指相连检索完成初步召回后没引入基于预训练语言模型的深度语义排序模型，对召回的文档片段进行二次相关性评估与重排序，以提升最终返回结果的寓意准确性与业务相关性。 |
| 是否需要兜底位置 | 是 | 默认开启，将在请求失败或查询不到结果时，向用户提供兜底位置的信息。 |
| 兜底位置 | 是 | 指进行兜底的基础设施名称，可按需调整。 |
| 兜底提示 | 是 | 指在为用户提供兜底设施信息时，透出的配套说明。 |
| 文本内容 | 是 | 指在为用户提供兜底信息时，透出的开场文案。 |
