# 配置流程
## 意图配置
在意图列举的大模型节点中加入【抽签祈福】的意图，让用户的query意图能被分发到后续相对的节点中<img src="https://cdn.nlark.com/yuque/0/2025/png/52106240/1764752080397-9cef094e-4a9e-4343-a33a-4128ad5eb91f.png" width="2140" title="" crop="0,0,1,1" id="nrFNK" class="ne-image">示例提示词

```plain
5.抽签解签
  - 描述:只有当用户的咨询为签名称、抽签时，如：国运第二十签、抽签等
  - 参数:
      - 名称: 提取签文的名称，示例：爱情第八签，提取为“爱情第八签”，无可提取内容时，则为空

```

注意：需要通过提示词来限制触发抽签意图的范围，描述越模糊，触发概率越大。
