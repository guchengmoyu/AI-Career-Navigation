# 功能说明
智能识别图像中的主体，并对图像进行主体分割。入参为主体清洗的图像，输出为透明背景的主体图像以及蒙版图像，主体图像和蒙版图像的尺寸与原图保持一致。

# 插件入参
| 参数名 | 参数类型 | 参数说明 |
| --- | --- | --- |
| originImageUrl | String | 原图链接 |


# 插件出参
| 参数名 | 参数类型 | 参数说明 |
| --- | --- | --- |
| success | Boolean | 是否成功 |
| <font style="color:rgb(28, 36, 51);background-color:rgba(0, 0, 0, 0.02);">resultImageUrl</font> | String | 结果图链接 |
| maskImageUrl | String | 蒙版图像链接 |
| resultDesc | String | 结果描述/错误信息 |
