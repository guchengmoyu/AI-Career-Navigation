插件支持依据音色和文本合成音频。

# 输入参数
| **参数名称 ** | ** 是否必填 ** | ** 说明 ** |
| --- | --- | --- |
| text | 必填 | <font style="color:rgba(15, 21, 40, 0.82);">要合成音频的文本内容</font> |
| speaker_id  | 选填 | <font style="color:rgba(15, 21, 40, 0.82);">音色ID，默认为爽快思思/Skye，详细音色列表参考 </font>[音色列表](https://alipaytbox.yuque.com/sxs0ba/huntb8/ruu7drlxiiw5si6q/edit?toc_node_uuid=M6h8SN2bMRCnnnBe#tDX0O) |
| speed_ratio | 选填 | <font style="color:rgba(15, 21, 40, 0.82);">语速，范围是[0.2,3]，默认为1，通常保留一位小数即可</font> |
| language | 选填 | <font style="color:rgba(15, 21, 40, 0.82);">语音语种，详情参考 </font>[音色列表](https://alipaytbox.yuque.com/sxs0ba/huntb8/ruu7drlxiiw5si6q/edit?toc_node_uuid=M6h8SN2bMRCnnnBe#tDX0O) 多语种场景 |
| voice_id | 选填 | voice_id |


# 输出参数
| **参数名称 ** | ** 说明 ** |
| --- | --- |
| code | 返回状态码，0 表示成功，非 0 表示失败 |
| msg | 执行插件时的状态描述或错误提示信息 |
| log_id | 日志 ID，用于问题排查和调试 |
| data | 数据体 |
| -link | 语音链接 |
