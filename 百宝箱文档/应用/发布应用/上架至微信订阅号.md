本文介绍如何将智能体应用发布到微信公众号-订阅号中<font style="color:rgb(64, 64, 64);">，助力业务多渠道上架</font>。

智能体创作完成后，您只需在发布渠道页面完成授权操作。发布完成后，订阅号就可以使用智能体应用回复用户消息（**<font style="color:#DF2A3F;">不支持卡片回复样式</font>**）。

# 使用限制
+ <font style="color:#000000;">一个智能体只能发布到一个</font>**<font style="color:#000000;">订阅号</font>**
+ 订阅号需为**个人以外的其他类型**
+ <font style="color:#000000;">使用行业应用模版克隆的应用，需添加至“白名单”后才可上架至该渠道，如需使用请在右下角在线客服联系平台添加“白名单”。自行创建的对话型应用，可以正常发布至该渠道。</font>

# 操作步骤
## 上架智能体
1. 应用创建完成后，单击页面右上角“发布”。“确认发布”后，进入发布渠道页面。

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1756446331531-1945f41d-ce23-40d3-8b6c-1683d2a20969.png" width="1590.0000421206169" title="" crop="0,0,1,1" id="tSaem" class="ne-image">

2. 在发布渠道页面，“微信tab”下选择发布渠道：微信公众号-订阅号，并点击“上架”。

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1756446329490-fd093ddd-8ec0-4174-8460-f377d2005f99.png" width="1610.000042650436" title="" crop="0,0,1,1" id="ub1f5f55b" class="ne-image">

3. 在“<font style="color:rgba(0, 0, 0, 0.88);">上架微信公众号-订阅号</font>”弹窗中，输入微信订阅号 APP ID

> 说明：
>
> <font style="color:#000000;">一个智能体只能发布到一个订阅号。该 APP ID 已经绑定其他智能体，请先解除之前绑定的智能体再进行绑定。</font>
>

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1756446330094-ee94998f-9d8b-477a-83a9-8059fe64b887.png" width="1577.7778195746162" title="" crop="0,0,1,1" id="u144301d1" class="ne-image">

**微信订阅号 APP ID获取方式：**

+ 点击“微信公众平台”，打开微信公众平台登录页面，请完成微信订阅号的登录

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1756446329336-c3c5085a-130d-4fdf-b9d4-139424acb7f1.png" width="893.3333569985855" title="" crop="0,0,1,1" id="u685b648c" class="ne-image">

+ 在微信订阅号后台：<font style="color:#000000;">设置与开发->开发接口管理->基本配置页面，复制开发者 ID（App ID）信息</font>

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1756446329693-40cc6760-099b-445a-ba11-b394f4c68f1b.png" width="1504.444484298613" title="" crop="0,0,1,1" id="u2a60051d" class="ne-image">

4. 在“<font style="color:rgba(0, 0, 0, 0.88);">上架微信公众号-订阅号</font>”弹窗中，输入微信订阅号 APP ID。请微信<font style="color:rgba(0, 0, 0, 0.88);">订阅</font>号管理员使用个人微信号扫描二维码，并在手机端对所有授权项完成授权。
5. 完成授权后，平台将自动发起智能体的上架。完成上架后，发布状态将变为已上架。

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1756446330698-e0f4a5ec-7018-4b8c-9526-bdafcf8d5301.png" width="928.8889134960417" title="" crop="0,0,1,1" id="ud26f41e4" class="ne-image">



## 下架智能体
点击“申请下架”，再次确认后，即可实现取消上架。

> <font style="color:#000000;">注意：</font>
>
> + <font style="color:#000000;">取消上架后，微信订阅号将无法使用智能体回复消息</font>
> + <font style="color:#000000;">取消上架，并不会同步取消授权，以方便后续快速发起上架</font>
>

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1756446331376-fe4ac811-d701-4764-b5ac-219210dd268d.png" width="931.1111357771326" title="" crop="0,0,1,1" id="u0f4e74d2" class="ne-image">

## 取消授权
点击“取消授权”，再次确认后，即可实现取消授权。取消授权后，将同步进行下架（原因：上架的前提是完成授权）。

> <font style="color:#000000;">注意：</font>
>
> <font style="color:#000000;">取消后，微信订阅号将无法使用智能体回复消息。如需完全取消授权，请前往“微信公众平台 > 账号详情 > 授权管理 > 第三方授权平台”中取消授权。</font>
>

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1756446331558-f9b55580-a41c-4984-8cab-62e77ee8e582.png" width="932.2222469176781" title="" crop="0,0,1,1" id="u02f26497" class="ne-image">

## 更新上架
当您创作了新的版本后，如需对新版本进行上架，无需下架线上版本，只需点击“更新上架”，即可实现对新版的上线。
