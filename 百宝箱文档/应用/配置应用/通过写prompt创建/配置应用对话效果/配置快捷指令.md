快捷指令是指预置在智能体应用对话框上方的快捷按钮，用户点击按钮即可发送其中预置的 query 发起对话或跳转至其中预置的外部链接。

## 配置说明
1. 开发者访问[我的应用](https://b.tbox.cn/inc/my)。
2. 在应用列表中，找到并进入目标应用编排界面。
3. 在应用编排页的对话配置中，点击快捷指令右侧的 +。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1766375907914-9a01a6cd-941d-48bb-b579-c830ae325d98.png" width="500" title="" crop="0,0,1,1" id="uad1de46a" class="ne-image">
4. 在新增快捷指令面板中配置指令名称、图标以及指令内容后，点击确定即可。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1762401108388-9c99ef4d-ba4a-4638-a6c8-26fb59c5f630.png" width="500" title="" crop="0,0,1,1" id="u7bc63ac8" class="ne-image">

其中，各配置项说明如下。

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 指令名称 | 是 | 自定义快捷指令的名称，该名称会以按钮的形式展示在对话框上方，最多支持输入 6 个字。 |
| 指令图标 | 否 | 点击<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1749713714857-93e906cb-8754-4c5d-adc7-da35de6b4015.png" width="23" title="" crop="0,0,1,1" id="uc7404ef8" class="ne-image">变更指令 icon，支持：<br/>+ 不使用图标。<br/>+ 选择百宝箱预置图标。<br/>+ 自定义上传：可前往 [iconfont](https://www.iconfont.cn/) 获取更多，并上传至百宝箱。 |
| 指令内容 | 是 | 自定义用户点击指令时，发送给应用的内容。支持：<br/>+ **文本内容：**以文本的形式命令应用执行相关操作，最多支持输入 200 个字。<br/>+ **服务端链接 URL**：支持配置为指定页面的地址链接，点击后进行跳转。 |
