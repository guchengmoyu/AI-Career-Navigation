在流程逻辑页面，开发者可通过资源列表管理当前应用所引用的插件资源与全局变量。同时，也可通过流程画板实现流程节点的添加、配置与编排操作。本文将介绍如何进行工作流的流程逻辑配置

## 管理插件资源
在流程逻辑页面左侧的资源列表中，会罗列当前应用所引用的各项资源（子工作流或插件）。点击即可定位至对应的节点，实现节点的快速查看与管理。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1764122883503-8dbe2186-1425-4601-9f60-f179d409134d.png" width="1534.4" title="" crop="0,0,1,1" id="u439af636" class="ne-image">

## 配置全局变量
全局变量是指包括用户信息、时间信息、空间信息以及系统信息等关键环境参数。这些参数能够帮助智能体应用更好的理解用户需求、感知用户侧时间与空间的变化，进而为用户提供更加精准、高效、个性化的智能服务。

**操作说明：**

1. 开发者访问[我的应用](https://b.tbox.cn/inc/my)。
2. 在应用列表中点击并进入目标工作流应用。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1764051276731-b41451d6-0cad-4d0c-8039-db4924a9d510.png" width="2044.8" title="" crop="0,0,1,1" id="u1c9d425b" class="ne-image">
3. 在工作流的流程编辑画板中，点击资源列表中全局变量右侧的**设置**。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1764051356901-9cd54202-3cf1-433d-9c91-2429b3219509.png" width="2040.8" title="" crop="0,0,1,1" id="u2904aaf9" class="ne-image">
4. 在环境面板中，根据业务需求控制各参数的启停，完成后点击右下角的**确定**，即可实现全局变量的配置。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1764051533378-3d037f3f-c8e4-45d9-a470-66bc9b921639.png" width="2048" title="" crop="0,0,1,1" id="u673bdb55" class="ne-image">

## 管理工作流节点
在流程逻辑页面的流程画板中，开发者可实现业务节点的添加、配置与编排，使工作流更加符合自身的个性化业务诉求。

### 添加工作流节点
1. 在流程画板中，点击下方快捷工具栏的 **+ 添加节点 **> 点击目标节点，即可将该节点添加至画板中。<img src="https://cdn.nlark.com/yuque/0/2025/gif/1397496/1764124229364-ceaff39a-74a6-4f3d-acac-2d6eaeb0b5f5.gif" width="1024" title="" crop="0,0,1,1" id="b1psb" class="ne-image">
2. 此时，点击前置节点右侧的 + 并进行拖拽可发起连线，实现节点间的串联。<img src="https://cdn.nlark.com/yuque/0/2025/gif/1397496/1764123952629-3a3f7513-924f-4678-b3c2-0e17b4f351c9.gif" width="1024" title="" crop="0,0,1,1" id="VwNbX" class="ne-image">
3. 同时，也可通过点击前置节点右侧的 + > 点击目标节点，在指定位置添加新的节点。<img src="https://cdn.nlark.com/yuque/0/2025/gif/1397496/1764124095378-9938658e-08dc-4418-be50-71ef2baa448e.gif" width="1024" title="" crop="0,0,1,1" id="JE9xv" class="ne-image">

### 配置工作流节点
节点是工作流的核心构建单元，通过对高频业务场景进行模块化封装，为开发者提供可复用、可编排的能力组件。各节点支持的配置能力与方法详见下表。

| **模块** | 节点名称 | 说明 |
| --- | --- | --- |
| [**基础节点**](https://alipaytbox.yuque.com/sxs0ba/huntb8/node_base) | 开始 | 工作流默认节点，用于接收用户 query 并触发工作流的运行。 |
| | 结束 | 工作流默认节点，用于结束当前工作流的运行，并给出智能体的答复。 |
| | 文本大模型 | 可以进行文本大模型选择、提示词编写并支持为大模型添加插件、知识库等技能进一步丰富输出内容。 |
| | 直接回复 | 用于在运行的流程中，输出文本、卡片或文件消息。 |
| [**工具节点**](https://alipaytbox.yuque.com/sxs0ba/huntb8/node_tools) | 插件 | 在工作流中引用三方提供或自定义的插件工具，以扩展智能体的能力边界。 |
| | 工作流 | 在当前工作流应用中，以子流程的形式引用其他工作流，实现多模块协同。 |
| [**知识&数据节点**](https://alipaytbox.yuque.com/sxs0ba/huntb8/node_knowledge-data) | 变量 | 支持设置或读取应用全局的变量内容。<br/>+ 读取时，变量名应与前置设置的变量名相同。<br/>+ 设置的变量默认按照用户维度进行数据隔离。<br/>+ 通过变量节点创建的变量，不会因为对话结束而重置，变量值会长期存续。 |
| | 知识库 | 知识库是用于存储、向量化处理开发者上传至百宝箱的应用数据，从而为智能体提供更加精准的回复内容。百宝箱支持以节点的形式将知识库串联在工作流中，为智能体提供知识管理能力。 |
| | Query 改写 | Query 改写（又称“多轮改写”）能力，旨在通过对用户当前提问结合历史对话上下文进行语义增强与结构补全，生成语义完整、指代明确、意图清晰的重写查询。从而提升下游任务的准确性与鲁棒性，确保系统能够在多轮交互过程中事中精准理解用户的真实意图。 |
| [**逻辑节点**](https://alipaytbox.yuque.com/sxs0ba/huntb8/node_logic) | 代码 | 支持通过 JavaScript 或 Python 语言编写运行脚本，实现数据处理、计算等任务。 |
| | 意图识别 | 支持根据用户对话的上下文进行用户意图的识别，并根据识别结果触发不同的流程分支。 |
| | 分支 | 支持根据上游节点输出的内容作为判断条件，控制工作流运行的分支，并决定下一步操作。 |
| [**图像处理节点**](https://alipaytbox.yuque.com/sxs0ba/huntb8/node_image) | 局部重绘 | 支持根据文字描述或上传的参考图进行图片生成。 |
| | 智能抠图 | 支持对上传的原图进行智能抠像处理。 |
| | AI 扩图 | 支持对上传的原图进行扩充绘制，以生成全新的图片。 |
| | 背景编辑 | 支持根据文字描述对所上传的原图的背景进行生成与替换。 |
| [**文件理解节点**](https://alipaytbox.yuque.com/sxs0ba/huntb8/node_understanding) | 文件理解 | 文件理解节点用于对用户在与智能体交互过程中上传的文档进行深度语义解析与内容理解。 |


### 复制与删除节点
在流程画板中，点击目标节点右上角的** ... > 复制/删除该节点**。<img src="https://cdn.nlark.com/yuque/0/2025/gif/1397496/1764140629404-d21c0548-26bc-4b44-9b27-2360fd47017f.gif" width="1024" title="" crop="0,0,1,1" id="uQXfL" class="ne-image">

+ **复制该节点：**复制所选节点，包括节点内的配置内容，但需要自行串联。
+ **删除该节点：**删除所选节点。
