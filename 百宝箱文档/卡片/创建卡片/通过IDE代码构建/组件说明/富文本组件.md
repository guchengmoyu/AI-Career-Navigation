本文将介绍如何使用富文本组件。

## 使用限制
:::warning
+ 支持`a`标签，不支持直接使用超链接，不支持注释。
+ 使用`a`标签时，设置a标签字体颜色 or 选中高亮色，请参考 [FAQ](https://yuque.antfin.com/fish-pond/paul/zbwfgw58t2tor5qs#WRcCl)
+ 使用`a`标签时，文本色or选中高亮色在Cube中默认颜色是`#108ee9`
+ 使用`onTap`等事件时，请先确认待投放的容器版本：
    - 投放至支付宝，需确保`**<font style="color:#DF2A3F;">支付宝客户端版本 》10.6.16</font>**`

:::

## 属性说明
| **属性名** | **类型** | **是否必填** | **说明** |

| `onTap` | `EventHandle` |  | 触摸 |
| `onLongTap` | `EventHandle` |  | 触摸后，超过 500ms 再离开。 |

## FAQ
### `a`标签设置文本色or高亮色
假设在富文本中需要设置`a`标签的文本色or高亮色，在小程序orH5中配置内联样式即可。但在Cube技术栈中，富文本标签不支持类似实现。

故在`Paul`提供的解决方案为：读取`nodes`节点数据，获取富文本内第一个`a`标签的内联样式，筛选`color``-webkit-tap-highlight-color`属性，赋值给原生`richtext`标签。
