## 使用限制
+ 图片格式不支持`svg``gif``webp`
+ 图片`src`属性不支持包内图片资源
+ `mode`属性不支持`heightFix`
+ `image`标签不支持嵌套子组件
+ 使用`onTap`等事件时，请先确认待投放的容器版本：
    - 投放至支付宝，需确保`**<font style="color:#DF2A3F;">支付宝客户端版本 》10.6.16</font>**`

## <font style="color:rgb(51, 51, 51);">属性说明</font>
| **属性名** | **类型** | **说明** |
| --- | --- | --- |
| `class` | String | 自定义样式名 |
| `style` | String | 内联样式 |
| `src` | String | 图片地址<br/>支持两种格式。base64图片、网络图 |
| `mode` | String | 图片模式<br/>默认值 `scaleToFill` |
| `default-source` | String | 默认图片地址。<br/>若设置默认图片地址，会先显示默认图片，等 src 对应的图片加载成功后，再渲染对应的图片。 |
| `onLoad`<br/><font style="background:#F6E1AC;color:#664900">10.6.6支持</font> | EventHandle | 当图片加载完成后触发。<br/>```javascript event.detail = {   width: '图片宽度 px',   height: '图片高度 px' } ```  |
| `onError`<br/><font style="background:#F6E1AC;color:#664900">10.6.6支持</font> | EventHandle | 当图片加载失败时触发。<br/>```javascript event.detail = {   errMsg: '错误信息' } ```  |
| `onTap` | EventHandle | 点击。 |
| `onTouchMove` | EventHandle | 触摸后移动。 |
| `onTouchEnd` | EventHandle | 触摸动作结束。 |
| `onTouchCancel` | EventHandle | 触摸动作被打断，如来电提醒，弹窗。 |
| `onLongTap` | EventHandle | 长按 500ms 之后触发，触发了长按事件后进行移动将不会触发屏幕的滚动。 |


### mode 说明
| **模式** | **枚举值** | **说明** |
| --- | --- | --- |
| 缩放 | scaleToFill | 不保持横纵比缩放图片，是图片的宽高完全拉伸至填满 image 元素 |
| 缩放 | aspectFit | 保持图片的横纵比，使图片的长边能够完全显示出来 |
| 缩放 | aspectFill | 保持图片的横纵比，只保证图片的短边能够完全显示出来 |
| 裁剪 | top | 不缩放图片，仅显示图片的顶部区域 |
| 裁剪 | right | 不缩放图片，仅显示图片的右边区域 |
| 裁剪 | bottom | 不缩放图片，仅显示图片的底部区域 |
| 裁剪 | left | 不缩放图片，仅显示图片的左边区域 |
| 裁剪 | center | 不缩放图片，仅显示图片的中间区域 |
| 裁剪 | top left | 不缩放图片，仅显示图片的左上区域 |
| 裁剪 | top right | 不缩放图片，仅显示图片的右上区域 |
| 裁剪 | bottom left | 不缩放图片，仅显示图片的左下区域 |
| 裁剪 | bottom right | 不缩放图片，仅显示图片的右下区域 |
