本文将介绍动画（lottie）组件的使用方法。

## 使用限制
+ `<font style="color:rgb(51, 51, 51);">lottie</font>`<font style="color:rgb(51, 51, 51);"> 内部不可嵌套任何其他组件。</font>

## 属性说明
| **属性名** | **类型** | **必填** | **说明** |
| --- | --- | --- | --- |
| `class` | String | 否 | 自定义样式名 |
| `style` | Object | 否 | 内联样式 |
| `id` | String | 是 | id |
| `path` | String | 否 | Lottie 资源地址，只支持远端（网络）的 JSON 文件地址。 |
| `repeat-count` | Number | 否 | 循环次数。    <br/>+ 如果是 -1 表示无限次。<br/>+ 如果是 0 表示不循环，播放一次。<br/>+ 如果是 1 表示循环一次，播放两次。<br/>**默认值：** 0 |
| `placeholder` | String | 是 | 兜底图或者降级图地址。 |
| `optimize` | Boolean | 否 | 降级。降级是指如遇低端设备，Lottie 会降级展示为 placeholder。   当 optimize 为 true ，并且传入了 placeholder 时，在低端设备上只会展示 placeholder，不展示 Lottie。 |
| `onTap` | EventHandle | 否 | 点击。   **说明：** 每点击一次会触发一次事件，建议自行使用代码防止重复点击,可以使用 js 防抖和节流实现。 |
| `onDataReady` | EventHandle | 否 | 当数据下载+视图创建完成时触发。 |
| `onDataFailed` | EventHandle | 否 | 数据加载失败时触发。 |
| `onAnimationStart` | EventHandle | 否 | 动画开始时触发。 |
| `onAnimationEnd` | EventHandle | 否 | 动画结束时触发。 |
| `onAnimationRepeat` | EventHandle | 否 | 动画一次重播结束。 |


## 方法
可以参考 [my.createLottieContext](https://opendocs.alipay.com/mini/api/createlottiecontext?pathHash=3c07ec93) 的使用，但只支持如下方法：

| **<font style="color:rgb(38, 38, 38);">名称</font>** | **<font style="color:rgb(38, 38, 38);">类型</font>** | **<font style="color:rgb(38, 38, 38);">功能说明</font>** |
| --- | --- | --- |
| [<font style="color:rgb(38, 38, 38);">LottieContext.play</font>](https://opendocs.alipay.com/mini/07t1o3?pathHash=7b2e2847) | <font style="color:rgb(38, 38, 38);">Function</font> | <font style="color:rgb(51, 51, 51) !important;">开始播放。</font> |
| [<font style="color:rgb(38, 38, 38);">LottieContext.stop</font>](https://opendocs.alipay.com/mini/07suia?pathHash=86942d74) | <font style="color:rgb(38, 38, 38);">Function</font> | <font style="color:rgb(51, 51, 51) !important;">停止播放。</font> |
| [<font style="color:rgb(38, 38, 38);">LottieContext.goToAndStop</font>](https://opendocs.alipay.com/mini/07sspx?pathHash=c56f5723) | <font style="color:rgb(38, 38, 38);">Function</font> | <font style="color:rgb(51, 51, 51) !important;">跳转到指定进度并停在该进度。</font> |
| [<font style="color:rgb(38, 38, 38);">LottieContext.goToAndPlay</font>](https://opendocs.alipay.com/mini/07t07e?pathHash=9b76cf34) | <font style="color:rgb(38, 38, 38);">Function</font> | <font style="color:rgb(51, 51, 51) !important;">跳转到指定进度并从该进度开始播放。</font> |


## 代码示例
```plain
// index.axml
<lottie
  id="autoPlay"
  path="{{successItem.path}}" 
  repeat-count="{{successItem.repeatCount}}"
  placeholder="{{successItem.placeholder}}"
  class="item"
  optimize="{{successItem.optimize}}"
  onDataReady="onDataReady"
  onAnimationStart="onAnimationStart"
  onAnimationEnd="onAnimationEnd"
  onAnimationRepeat="onAnimationRepeat"
  >
</lottie>

// index.ts
Component({
 // ...
 didMount() {
 },
 methods: {
   onDataReady() {
      // 自动播放
      const lottieContext = my.createLottieContext('autoPlay');
      lottieContext.play();
   },
 }
})

```

## FAQ
### 如何自动播放
暂不支持 lottie 自动播放，如需实现自动播放效果，请在组件生命周期中主动调用 `<font style="color:rgb(38, 38, 38);">LottieContext.play</font>`<font style="color:rgb(38, 38, 38);"> 方法。</font>

### <font style="color:rgb(38, 38, 38);">cube 预览 lottie 无法播放</font>
<font style="color:rgb(38, 38, 38);">lottie 的播放资源必须带上 .json 后缀，例如：</font>`https://mdn.alipayobjects.com/huamei_dn7w2u/afts/file/A*MKhaRotTcz4AAAAAAAAAAAAADqLdAQ/yuebao.json`
