本文将介绍进度条组件的使用方法。

## 使用限制
+ <font style="color:rgb(51, 51, 51);">由于 cube 默认开启样式隔离，因此不支持通过 class 指定 progress 样式，支持通过 style 修改 progress 样式。</font>
+ `<font style="color:rgb(51, 51, 51);">progress</font>`<font style="color:rgb(51, 51, 51);"> 内部不可嵌套任何其他组件。</font>

## 属性说明
| **属性名** | **类型** | **必填** | **说明** |
| --- | --- | --- | --- |
| `style` | Object | 否 | 内联样式 |
| `percent` | Float | 否 | 百分比 (0~100) |
| `stroke-width` | Number | 否 | 线的粗细，单位 px。   **默认值：** 6 |
| `active-color` | Color | 否 | 已选择的进度条颜色。   **默认值：** rgb(16, 142, 233) |
| `background-color` | Color | 否 | 未选择的进度条颜色。<br/>**默认值：**#eee |
| `active` | Boolean | 否 | 是否添加从 0% 开始加载的入场动画。   **默认值：**`active="{{false}}"` |
| `show-info` | Boolean | 否 | 在右侧显示百分比值。   **默认值：** `show-info="{{false}}"` |




## 代码示例
```plain
<view class="page">
  <text class="page-description">进度条</text>
  <view class="page-section">
    <view class="page-section-demo">
      <progress percent="20" show-info style="{{marginBottom: '60rpx'}}"/>
      <progress percent="{{activePercent}}" style="{{marginBottom: '60rpx'}}" active show-info />
      <progress percent="60" stroke-width="10" style="{{marginBottom: '60rpx'}}" />
      <progress percent="80" activeColor="#6abf47" backgroundColor="#f4333c" style="{{marginBottom: '60rpx'}}" />
    </view>

    <button size="default" type="primary" onTap="addPercent">add</button>
  </view>
</view>

```
