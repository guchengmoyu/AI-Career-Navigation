本文将介绍复选框组件的使用方法。

## 使用限制
+ <font style="color:rgb(51, 51, 51);">由于 cube 默认开启样式隔离，因此不支持通过 class 指定 switch 样式，支持通过 style 修改 checkbox 样式。</font>

## 属性说明
| **属性** | **类型** | **必填** | **描述** |
| --- | --- | --- | --- |
| `value` | String | 否 | 组件值，选中时 change 事件会携带的 value。 |
| `checked` | Boolean | 否 | 当前是否选中，可用来设置默认选中。   **默认值：** false |
| `disabled` | Boolean | 否 | 是否禁用。   **默认值：** false |
| `onChange` | EventHandle | 否 | 组件发生改变时触发，detail = {value: 该 checkbox 是否 checked }。 |
| `color` | String | 否 | checkbox 的颜色，同 CSS 色值。   **版本要求：** 基础库 1.10.0 及以上 |
| `style` | Object | 否 | 内联样式 |


## 代码示例
```typescript
<view>
  <text class="text">{{ dataReadyParams }}</text>
  <text>默认</text>
  <checkbox onChange="onChange" />
  <text>启用并勾选</text>
  <checkbox checked />
  <text>禁用</text>
  <checkbox disabled />
  <text>禁用并勾选</text>
  <checkbox disabled checked />
</view>
```
