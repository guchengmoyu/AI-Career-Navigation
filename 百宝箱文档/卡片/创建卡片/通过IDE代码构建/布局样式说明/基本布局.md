## Flex布局 <font style="background:#F6E1AC;color:#664900">以下特性仅Cube下受限</font>
Paul 组件内的元素仅支持 Flex 布局，所有`<view>`标签带有默认属性`display: flex`。

### Flex容器
| **属性** | **描述** | **默认值** | **可选值** | **备注** |
| :--- | :--- | :--- | :--- | :--- |
| flex-direction | 定义flex成员项的排列方向 | column | column,row,row-reverse, column-reverse |  |
| justify-content | 定义flex成员项在主轴方向上如何排列以处理空白部分 | flex-start | flex-start, flex-end, center, space-between, space-around |  |
| align-items | 定义flex成员项在纵轴方向上如何排列以处理空白部分 | stretch | stretch, center, flex-start, flex-end |  |
| flex-wrap | <font style="color:#2C3E50;">决定了flex成员项</font><font style="color:#2C3E50;">在一行还是多行分布</font> | nowrap | wrap, nowrap |  |
| align-content | 定义flex成员项如何沿着纵轴在内容项之间和周围分配空间 | flex-start | auto, stretch, center, flex-start, flex-end | flex-wrap: 为 nowrap 时无效 |


:::info
**注意**：**Flex容器的width和height必须显式给定**，避免在由成员撑开容器宽高的情况下，web标准和cube计算方式不一致导致的差异。

:::

### Flex成员
:::info
**注意**：每个Flex成员的width和height必须显式给定。

:::
