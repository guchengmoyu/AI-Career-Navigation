目前，通过百宝箱可视化搭建的卡片**仅支持在 H5 容器中渲染，无法直接生成支付宝或微信小程序资产**，因此不能在小程序环境中原生运行。若需在支付宝或微信小程序运行的智能体中使用卡片，需要订阅百宝箱在对应小程序平台发布的官方插件并将卡片代码进行注入，最终实现卡片的投放。本文将介绍如何实现上述链路。

## 操作流程
1. 开发代码：根据自身业务需求，在宿主小程序中完成卡片代码的开发。
2. 新建卡片：在百宝箱卡片模块，使用卡片的 mock 数据，获取平台解析并生成对应的卡片参数，从而实现百宝箱卡片的创建。
3. 关联卡片：在目标智能体中引用卡片，并进行变量绑定。
4. 投放卡片：通过卡片代码注入、小程序项目配置实现卡片在宿主小程序中的投放

## 操作步骤
### 步骤 1：开发代码
在宿主小程序中完成卡片组件代码开发，若您需要快速构建卡片组件，可选择使用百宝箱提供的官方组件模板。

1. 安装宿主小程序平台的开发者工具。
    1. 支付宝小程序：[点击下载支付宝小程序开发者工具](https://opendocs.alipay.com/mini/ide/overview?pathHash=4da33275)。
    2. 微信小程序：[点击下载微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. （可选）下载百宝箱提供的卡片代码模板。
    1. 支付宝小程序卡片模板：[aicard_in_miniapp.zip](https://alipaytbox.yuque.com/attachments/yuque/0/2026/zip/1397496/1770716421257-aa28832b-a887-4ce8-b779-29860da102aa.zip)。
    2. 微信小程序卡片模板：[agent-chat-h5-template-wx.zip](https://alipaytbox.yuque.com/attachments/yuque/0/2026/zip/1397496/1770716421202-94d68134-e8a5-4961-bb88-6ce187649ee5.zip)。
3. 在本地，使用宿主小程序开发者工具完成代码开发，并生成卡片的 mock 数据。

### 步骤 2：新建卡片
1. 开发者登录[百宝箱卡片](https://b.tbox.cn/inc/card)。
2. 在卡片列表页，点击右上角的新建卡片 > 代码导入模块的**新建**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770101689030-944fd7ed-0349-455b-a26d-132aff592236.png" width="920" title="" crop="0,0,1,1" id="ue80e4fd4" class="ne-image">
3. 在卡片资产配置面板中，完成卡片资产类型选择等配置后，点击右上角的**保存并发布**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770101929831-357f428f-8b03-4eb6-8a47-23662b90c9af.png" width="1521.6" title="" crop="0,0,1,1" id="udc21eaed" class="ne-image">

其中各配置项说明如下：

| 配置项/操作 | 必填 | 说明 |
| --- | --- | --- |
| 自定义卡片名称 | 否 | 点击左上角的<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770102074606-6af8a1da-da7a-45c4-a6b0-1ebc450506c5.png" width="16" title="" crop="0,0,1,1" id="u29069284" class="ne-image">，输入卡片名称，实现卡片名称的自定义，若不执行自定义操作，则默认为“未命名卡片”。 |
| 卡片资产类型 | 是 | 根据卡片所绑定智能体的对客渠道进行分类，主要包括：<br/>+ **H5 卡片：**在 H5 环境中运行的智能体，详细说明可参见：[导入 H5 代码卡片](https://alipaytbox.yuque.com/sxs0ba/huntb8/oqwlah6ppeg6xpyr)。<br/>+ **支付宝/微信小程序卡片：**适用于在支付宝或微信小程序中运行的智能体，即本文所介绍的卡片导入方式。 |
| 小程序插件是否三方自定义组件 | 是 | 固定选择“是”。 |
| 卡片参数 | 是 | 在输入框中填写步骤 1 结尾处生成的 mock 数据，并点击自动解析，以生成卡片所需的变量参数模板。<br/>+ 格式要求：请填入 JSON 格式（key:value 形式）的 mock 数据。 |


4. 完成上述参数配置并点击右上角的保存并发布后，可将卡片推进至能与智能体应用绑定的（<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770105759359-68ef2f41-3ae4-49f1-8aa3-bda78f59530f.png" width="16" title="" crop="0,0,1,1" id="kKPDX" class="ne-image">已发布）状态。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770105801120-25eb16d6-3346-4261-a8a0-850437f76b5a.png" width="1522.4" title="" crop="0,0,1,1" id="uda589e16" class="ne-image">
