# 概述
百宝箱支持导入已开发好的卡片，如您已经通过**<font style="color:#DF2A3F;">H5或小程序</font>**等前端语言代码开发好了卡片，可通过该方式引用到百宝箱平台，卡片配置发布后，在应用工作流中使用卡片消息引用，并返回卡片相关数据，应用发布后，可以实现**<font style="color:#DF2A3F;">一次搭建发布，卡片可在多端渲染</font>**。

# 配置多端资产
### 配置H5资产
如您的智能体应用需要在H5或者Web端投放使用，并且希望能展示对话返回的卡片，请填写您卡片的静态资源地址。如不需要投放H5或者Web端，可不填写。注意此处不填写，在百宝箱智能体搭建平台运行智能体应用时，因为同属Web端，也将无法展示该卡片，可参考下面文档录入。

[打包H5卡片](https://alipaytbox.yuque.com/sxs0ba/huntb8/oqwlah6ppeg6xpyr)

### 配置小程序资产
如您的智能体应用需要在支付宝小程序端投放使用，并且希望能在您的小程序上展示对话返回的卡片，请选择是即可。将开发好的卡片组件对接百宝箱对话支付宝小程序插件即可。详细见文档

[引用自定义小程序组件卡片](https://alipaytbox.yuque.com/sxs0ba/huntb8/dk6uupdcczud9s7y)
