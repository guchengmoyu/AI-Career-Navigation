### 提取卡片类型
如果查询到了天气数据卡片类型就是CHAT_LLM_myassistant_weather，否则就代表为查询到数据，在下个节点进行判断

代码如下：

```python
# 入口函数 main
# @param {dict} params - 输入项的集合
# @param {dict} context - 包含环境参数、应用ID等信息
# @return {dict} data - 返回的数据集合
import json

def main(params: dict, context: dict) -> str:
    try:
        # 安全获取输入参数
        input_data = params.get('param', {})
        
        # 处理字符串输入
        if isinstance(input_data, str):
            try:
                data = json.loads(input_data)
            except json.JSONDecodeError:
                # 尝试直接查找 cardType 字符串
                if '"cardType":' in input_data:
                    start = input_data.find('"cardType":') + len('"cardType":')
                    end = input_data.find('"', start + 1)
                    if end > start:
                        return input_data[start:end].strip('"')
                return ""
        elif isinstance(input_data, dict):
            data = input_data
        else:
            return ""
        
        # 尝试从根级别的 card 对象中提取 cardType
        if "card" in data and isinstance(data["card"], dict):
            card = data["card"]
            # 先尝试直接获取 cardType
            if "cardType" in card:
                card_type = card["cardType"]
                if isinstance(card_type, str):
                    return card_type
                else:
                    return str(card_type)
            
            # 如果没有直接获取到，尝试解析 content 字段
            if "content" in card:
                content = card["content"]
                if not isinstance(content, str):
                    content = json.dumps(content)
                
                try:
                    # 解析嵌套的JSON内容
                    nested_data = json.loads(content)
                    if "cardType" in nested_data:
                        card_type = nested_data["cardType"]
                        if isinstance(card_type, str):
                            return card_type
                        else:
                            return str(card_type)
                    
                    # 尝试从服务列表中提取
                    if "list" in nested_data and isinstance(nested_data["list"], list) and nested_data["list"]:
                        service = nested_data["list"][0]
                        if "name" in service:
                            return service["name"]
                        if "desc" in service:
                            return service["desc"]
                
                except (json.JSONDecodeError, TypeError):
                    # 如果解析失败，尝试从字符串中提取 cardType
                    if '"cardType":' in content:
                        start = content.find('"cardType":') + len('"cardType":')
                        end = content.find('"', start + 1)
                        if end > start:
                            return content[start:end].strip('"')
        
        # 尝试从根级别提取
        if "cardType" in data:
            card_type = data["cardType"]
            if isinstance(card_type, str):
                return card_type
            else:
                return str(card_type)
        
        # 所有尝试都失败时返回空字符串
        return ""
    except Exception as e:
        # 捕获所有异常防止服务崩溃
        return ""
```

### 卡片数据解析
在查询到了天气数据后，在此代码节点解析天气数据，并在结束节点通过取值绑定到卡片所需要的字段上

代码如下：

```python
# 入口函数 main
# @param {dict} params - 输入项的集合
# @param {dict} context - 包含环境参数、应用ID等信息
# @return {dict} data - 返回的数据集合
import json
def main(params: dict, context: dict) -> dict:
    input = params.get('param', {}) # 从节点输入项中提取名为 param 的参数
    card = json.loads(input).get("card")
    ## 提取content中响应的内容
    content_str = card.get("content")
    content = json.loads(content_str)
    ## 拿到列表数据
    result = content.get("result")
  
    ## 对列表数据进行处理

    detailed_converted_data = []
  
    for item in result:
      
        main_item = {
            "weather": item.get("weather", ""),
            "weather_code": item.get("weatherCode", ""),
            "time": item.get("time", ""),
            "date": item.get("date", ""),
            "day": item.get("day",""),
            "temperature": item.get("temperature", ""),
            "lowest_temperature": item.get("lowestTemperature", ""),
            "highest_temperature": item.get("highestTemperature", ""),
            "wind_level": item.get("windLevel", ""),
            "highlighted": item.get("highlighted", False)
        }
        detailed_converted_data.append(main_item)
      
    data = {
      "type":content.get("type"),
      "result_url":content.get("resultUrl"),
      "city_name":content.get("cityName"),
      "district":content.get("district"),
      "update_time":content.get("updateTime"),
      "sunrise_time":content.get("sunriseTime"),
      "sunset_time":content.get("sunsetTime"),
      "provider":content.get("provider"),
      "provider_logo":content.get("providerLogo"),
      "temperature":content.get("temperature"),
      "weather":content.get("weather"),
      "weather_code":content.get("weatherCode"),
      "wind_direction":content.get("windDirection"),
      "wind_level":content.get("windLevel"),
      "humidity":content.get("humidity"),
      "aqi_score":content.get("aqiScore"),
      "aqi_quality":content.get("aqiQuality"),
      "warning":content.get("warning"),
      "today_weather":content.get("todayWeather"),
      "today_lowest_temperature":content.get("todayLowestTemperature"),
      "today_highest_temperature":content.get("todayHighestTemperature"),
      "list": detailed_converted_data
    }
    return data
```

### 入参说明
该插件有三个入参，location为要查询的城市名称，time为查询的时间点，可以是明天、后天、未来几天、8号等（不支持过去时间点的天气查询），aoilocation为中心点位坐标，当传入次参数时，根据城市名称为查询到天气数据时，会根据此经纬度坐标来查询；当为传入城市名称时，也会根据此经纬度坐标来查询

### 出参说明
content为查询出来的天气信息，为文本数据，主要用于下面的数据解析
