本文将介绍什么是知识库以及如何使用支持库。

## 什么是知识库
知识库是智能体与用户交互过程中的“信息管家”，统管您上传至百宝箱中的各类文档与资料，即数据仓库中存储的数据。

在百宝箱，支持开发者将上传至数据仓库的各类文档，关联至知识库，并结合向量相似度检索能力，实现高效的知识检索，既可以提升知识库的利用和管理效率，又能够解决大模型幻觉、行业专业知识不足的问题，从而提升大模型回复的准确率。

简单来说，当用户提出问题时，智能体会先在知识库中搜索和问题相关的知识，继而将这些知识连同用户问题一并给到大语言模型（LLM），从而提升回复内容的精准度。

## 检索类型
百宝箱支持**语义/全文检索**以及**地理位置检索**两种知识库检索方式，以满足不同业务场景下的知识获取需求。

| 检索类型 | 索引方式 | 核心能力 | 典型场景 |
| --- | --- | --- | --- |
| 语义/全文检索 | 向量嵌入、关键词匹配 | 语义理解、模糊匹配、精确查找 | 问答咨询、文档检索、标签查询 |
| 地理位置检索 | 空间距离计算（经纬度） | 空间感知、距离排序、范围查询 | 本地服务、门店查询、物流配送 |


### 语义/全文检索
语义/全文检索知识库是百宝箱基础知识库类型，通过向量相似度检索和关键词匹配就技术，实现对文档内容的深度理解和高效检索。

#### 能力特性
百宝箱采用**数据准备层**与**知识库管理层**结合的知识库架构。该架构将数据处理与知识重组解耦，实现专业化分工与资源的高效复用，从而为企业提供更加强大、灵活且高效知识管理能力，共同支撑企业级知识服务的构建与运营。

| 架构层级 | 核心职责 | 关键能力 |
| --- | --- | --- |
| 数据准备层 | 负责原始应用的接入与预处理 | 数据上传、格式解析、文本分段、智能总结 |
| 知识库管理层 | 负责存储、向量化数据，并将其与智能体集成 | 知识库创建、应用集成、知识检索 |


**特性说明**：

+ **职责解耦，独立优化：**数据准备层专注于将原始文档转化为结构清晰、语义完整的文本片段；知识管理层则聚焦于如何将这些片段组织为可检索、可推理的知识资产，并完成向量化以支持语义搜索与 AI 推理。
+ **数据复用，降本增效：**同一份经过高质量处理的分段数据，可被多个知识库同时引用。
+ **运维优化，体验升级：**用户先准备数据，再按需构建知识库的操作路径更加清晰；数据质量归因于数据准备层，知识效果归因于管理层，便于快速排查于优化。

#### 检索能力
| 能力 | 说明 |
| --- | --- |
| 语义检索 | 基于文本 embedding 实现语义相似度匹配，支持模糊查询和意图理解 |
| 关键词检索 | 精确匹配关键词，支持标签和元数据过滤 |
| 智能检索 | 结合语义和关键词检索，取交集或加权融合，提升召回精度 |


#### 适用场景
| 场景 | 说明 |
| --- | --- |
| 智能问答助手 | 用户提问时，检索相关知识文档，辅助 Agent 生成准确回答 |
| 企业级知识库 | 存储和检索企业内部规章制度、操作手册等文档资料 |
| 行业知识库 | 构建垂直领域专业知识库，如文旅、医疗、法律、金融等行业 |
| 产品 FAQ | 自动匹配用户问题与 FAQ 库中的标准问答 |
| 文档检索 | 根据自然语言描述检索相关合同、报告、论文等文档 |


### 地理位置检索
地理位置检索知识库是百宝箱提供的一种特殊索引类型知识库，基于地理空间数据（经纬度）建立索引，允许开发者通过配置**目标位置的经纬度坐标**与**搜索半径**，结合**表格类型知识库**完成知识内容的结构化配置，从俄日为用户提供基于位置的相关服务。

#### 能力特性
| 维度 | 说明 |
| --- | --- |
| 空间感知 | 将知识检索从关键词匹配扩展到空间邻近匹配，使 Agent 具备地理认知能力 |
| 结构化管理 | 基于表格类型知识库，知识内容以行列结构组织，便于批量维护与精确查询 |
| 可视化配置 | 开发者无需编写地理计算代码，通过可视化配置即可完成位置索引的搭建 |
| 实时响应 | 支持根据用户当前位置或指定位置，实时检索半径范围内的知识条目 |


#### 检索能力
| 能力 | 说明 |
| --- | --- |
| 圆形范围查询 | 以指定坐标为圆心、搜索半径为半径，返回范围内所有知识条目 |
| 结果截断 | 支持配置最大返回条数，避免信息过载 |


#### 适用场景
| 场景 | 说明 |
| --- | --- |
| 本地生活服务推荐 | 用户询问“附近有什么好吃的”时，Agent 根据用户位置检索半径范围内的商户信息并推荐 |
| 连锁门店/网点查询 | 为用户提供最近网点/门店的查询服务，如银行、运营商、零售连锁等 |
| 物流与配送范围判定 | 判定用户地址是否在配送范围内，或查找最近的配送站点/自提点 |
| 文旅景区导览 | 游客在景区内询问附近景点、洗手间、餐饮等设施位置 |


## 如何使用知识库
:::info
**说明：**在使用知识库之前，请先通过[上传数据](https://alipaytbox.yuque.com/sxs0ba/huntb8/database_create)进行数据上传。

:::

知识库的使用通常需要完成创建知识库 > 关联数据 > 知识检索命中测试 > 关联智能体应用这些关键的知识库操作步骤。其中：

1. [创建知识库](https://alipaytbox.yuque.com/sxs0ba/huntb8/knowledge_create)：完成知识库示例的创建并配置基本参数。
2. [关联数据](https://alipaytbox.yuque.com/sxs0ba/huntb8/knowledge_bind)：将已经上传至数据仓库并经过处理的数据与知识库建立联系。
3. [知识检索命中测试](https://alipaytbox.yuque.com/sxs0ba/huntb8/knowledge_recall)：执行一些列查询测试以验证知识库的数据准确性与检索效率。
4. [关联智能体](https://alipaytbox.yuque.com/sxs0ba/huntb8/knowledge_use)：将经过测试验证的知识库与智能体应用进行关联，使其能够实时调用知识库中的信息进行响应。

同时，百宝箱也提供整套知识库维护的 API 开放能力，开发者可通过调用对应的 API 完成知识库创建、数据引用与分段处理等操作，详细说明可参见：[知识库管理 API](https://alipaytbox.yuque.com/sxs0ba/huntb8/api_datasets_create-datasets)。
