本文将介绍如何在百宝箱创建并配置知识库。

## 操作步骤
1. 开发者访问[知识库](https://b.tbox.cn/inc/knowledge)。
2. 在知识库页面，点击**创建知识库**或点击知识库搜索框右侧的 **+ > 新建知识库**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775543082407-4550ae96-efdb-4ff4-8ff8-46fcfe689688.png" width="1535.2" title="" crop="0,0,1,1" id="u3253196f" class="ne-image">
3. 在新建知识库面板中，根据自身诉求选择知识库类型并进行配置后，点击**完成，**即可完成知识库的创建。

:::info
**说明：**此时，知识库数据为空，您可以通过[关联数据](https://alipaytbox.yuque.com/sxs0ba/huntb8/knowledge_bind)完成数据的填充。或者直接点击**下一步，添加数据**，完成后续步骤。 

:::

<img src="https://cdn.nlark.com/yuque/0/2026/png/55921448/1775630840353-98613feb-3b16-4054-9aed-10234b4d09b2.png" width="1362" title="" crop="0,0,1,1" id="u6c61deee" class="ne-image">

其中，各配置项说明如下：

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 知识库类型 | 是 | 请结合业务诉求与应用场景选择知识库类型，其中：<br/>+ **文档知识库：**允许上传多种类型的文档，且无严格的数据格式约束，适用于大部分通用的知识库应用场景。<br/>+ **表格知识库：**采用表格形式进行数据约束，从而支持知识的条件筛选能力，进而提高知识检索的精准度。<br/>+ **图片知识库**：支持上传图片并进行图像内容识别，适用于以图搜图的知识库场景，实现精准图像检索。该功能基于多模态大模型技术，能够同时理解图片的视觉内容和语义信息，广泛应用于商品图库检索、设计图纸比对、文物照片识别等场景 |
| 图标与名称 | 是 | 是知识库的基础信息，独特的图标与场景化的知识库名称能够有效降低查找、维护知识库的成本。<br/>+ **图标：**创建知识库时，系统会生成默认的图标，支持开发者自行上传。<br/>+ **名称：**是知识库的唯一标识，建议保证其唯一性，最大可输入 100 字符。 |
| 描述 | 否 | 支持开发者自定义知识库的描述信息，最大可输入 600 字。 |
| 配置文档属性 | 否 | **仅当知识库类型为文档时，可选配置**。点击页面上的添加属性，可维护属性名称、描述、类型等信息，为知识库的文档设置属性信息。属性信息可用于知识检索、问答时筛选文档范围，提高检索准确率。详细说明可参见：[数据属性](https://alipaytbox.yuque.com/sxs0ba/huntb8/rpmqg1kkwlvfh1da)。 |


4. 完成配置后，您可以选择点击右上角的完成或下一步，添加数据，进行推进。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775545067804-017e026a-d83e-4d79-9f15-53e264908e53.png" width="1089.6" title="" crop="0,0,1,1" id="ud6ef00d6" class="ne-image">

其中：

    - 点击**完成**：仅创建一个空白知识库，后续可通过关联数据，完成数据填充。
    - 点击**下一步，添加数据**：在当前页面，直接进行数据维护，适用于您已经完成数据准备的场景。
