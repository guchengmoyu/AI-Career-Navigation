本文将介绍如何进行数据上传。

## 上传文档数据
文档数据是指没有预定义的数据模型或固定格式的，比如包含形式多样的自由文本、段落、标题等内容的文档，无法直接填进表格中的信息。  

1. 开发者访问[数据仓库](https://b.tbox.cn/inc/appBase)。
2. 在数据列表页，点击页面**添加数据**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775552780874-e5e82e5c-b33e-40f9-9a6d-9a1a5717bffd.png" width="1532" title="" crop="0,0,1,1" id="u0ce333ed" class="ne-image">
3. 在添加数据面板中，选择**文档**，通过点击或拖拽的方式完成原始文件的上传。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775552867181-6b4cd400-34d2-41ce-8fe9-1b26011a0664.png" width="1096.8" title="" crop="0,0,1,1" id="ua2608473" class="ne-image">
4. 完成文件上传后，可根据自身需求进行分段策略与总结策略的配置，完成配置后，点击右上角的**确认**即可。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775552912137-becca1e6-f551-4552-ac9e-59d6d012abf0.png" width="1100.8" title="" crop="0,0,1,1" id="ua2d93bc8" class="ne-image">

其中，各配置项说明如下。

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 文件上传 | 是 | + **支持的格式：**DOCX、PDF、TXT、MD<br/>+ **上传限制：**<br/>    - 单次上传最多 10 个文件。<br/>    - 每个文件不超过 10MB。<br/>    - PDF文件不超过 300 页，超出 300 页的部分将不会进行解析。 |
| 分段策略 | 是 | 根据配置的分段规则将原始文件切分成逻辑较为完整的文本片段。支持选择以下两种分段策略。<br/>+ **智能分段策略：**根据语义或表格的表头进行段落切分。<br/>+ **自定义分段策略：**支持自行定义分段最大限制、标识符、上下文重叠长度等参数来实现对原始文档的切分。各参数说明如下：<br/>    - **<font style="color:rgba(9, 18, 33, 0.9);">分段最大限制：</font>**<font style="color:rgba(9, 18, 33, 0.9);">设置每个切片内的字符数上限，确保切片的最大长度与模型所支持的上下文长度范围相匹配，以确保数据处理的准确性和效率。</font><br/>        * <font style="color:rgba(9, 18, 33, 0.9);">长度越大，召回的上下文越丰富。</font><br/>        * <font style="color:rgba(9, 18, 33, 0.9);">长度越小，召回的信息越精简。</font><br/>        * <font style="color:rgba(9, 18, 33, 0.9);">当前切片最大长度默认为 500 字，最低下限为 300 字，最高上限为 8000 字。</font><br/>    - **<font style="color:rgba(9, 18, 33, 0.9);">分段标识符：</font>**<font style="color:rgba(9, 18, 33, 0.9);">支持按照所选的标识符切分文本时，可以选择的标识符有：中文句号、中文逗号、中文叹号、英文句号、英文逗号、英文叹号或自定义标识符。</font><br/>    - **<font style="color:rgba(9, 18, 33, 0.9);">上下文重叠长度：</font>**<font style="color:rgba(9, 18, 33, 0.9);">指当前切片与前后切片的 “重叠部分字符数” 相较于设置的 “分段最大限制” 的比例。如果重叠部分存在不完整的句子，则此切片舍去该句。占比越大，相邻切片重叠字符越多， 占比越小，重叠字符越少。</font> |
| 总结策略 | 否 | 对切分完成的文本段落进行总结归纳，从而提升知识召回的精准度与匹配度。支持选择以下两种总结策略，二者可同时开启。<br/>+ **分段智能总结：**通过对分段进行内容的智能总结，使得知识库在召回过程中能够带入更为丰富的上下文信息，从而提升召回的精准度。<br/>+ **分段问题生成：**由 AI 根据文档上下文和分段内容，生成推荐的问题列表，用于在知识召回中，提高分段的匹配成功率。 |


## 上传表格数据
表格是指按某个预定义的表结构组织的数据，<font style="color:rgba(0, 0, 0, 0.85);">可直接用规则化方式处理，比如 Excel 里的姓名、年龄、手机号，有固定格式，能直接写入表格中的数据。</font>

<font style="color:rgba(0, 0, 0, 0.85);">您可以通过本地导入、自定义数据表以及 API 同步三种方式进行文件上传，下文将分别进行说明。</font>

### <font style="color:rgba(0, 0, 0, 0.85);">方式 1： 通过本地导入上传</font>
1. 开发者访问[数据仓库](https://b.tbox.cn/inc/appBase)。
2. 在数据列表页，点击页面**添加数据**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775552780874-e5e82e5c-b33e-40f9-9a6d-9a1a5717bffd.png" width="1532" title="" crop="0,0,1,1" id="pjVNH" class="ne-image">
3. 在添加数据面板中，选择**结构化数据 **> **本地上传**，然后通过点击或拖拽的方式完成原始文件的上传。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775553004480-866cae53-6187-4a7f-ad7c-5640346d5def.png" width="1092" title="" crop="0,0,1,1" id="u6f15efaa" class="ne-image">
4. 文件上传完毕后，系统会自动进行文件解析，支持进行字段名称、描述、数据类型等属性的调整与确认，完成后点击**确认**即可。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775553029316-a7ca0249-bb5e-483b-bd11-501e8fc37031.png" width="1097.6" title="" crop="0,0,1,1" id="u4639cfa0" class="ne-image">

其中，各配置项说明如下。

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 字段名称 | 是 | 指当前列的字段名称，允许二次编辑，但需保证唯一性且最大长度为 100 个字符。 |
| 字段描述 | 是 | 指当前列的字段补充信息，允许二次编辑，但需保证最大长度为 100 个字符。 |
| 数据类型 | 是 | 指当前列的数据类型，允许二次选择，目前已经支持多种数据类型，数据类型的详细说明可参见：[数据类型枚举](https://alipaytbox.yuque.com/vksmxp/help/database_create#ZCe8V)。 |
| 默认值 | 否 | 若填写默认值，当录入数据此行数据为空时，则会按照默认值自动填充，填写格式参考以上数据类型的格式要求进行填写。 |
| 是否必填 | 否 | 默认不开启；若开启，则会对后续此字段进行非空校验，若有空值，会报错提示。 |
| 是否唯一值 | 否 | 默认不开启；有且仅有一个字段可以处于开启状态，开启后用以作为数据重复校验的唯一区分标签。 |

### 方式 3：通过调用 API 同步
百宝箱支持从公网可访问的 JSON 文件中自动拉取并导入数据。开发者仅需：

+ 将数据保存为一个**以 **`**.json**`**结尾的静态文件。**
+ 将其部署在支持 HTTPS 的公网服务器上。
+ 在百宝箱数据仓库添加页的网关地址 URL 中输入该文件 URL。
+ 系统将通过 `GET`请求获取数据并完成导入。
+ 流程示意如下：

```latex
[您的服务器]
     ↓ (HTTPS GET)
https://your-site.com/data.json
     ↓
[百宝箱] → 解析 → 导入 → 成功/失败
```

****

**操作步骤**

1. 在[数据仓库页](https://b.tbox.cn/inc/appBase)，点击右上角**添加数据**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775614303028-c54d9c4e-c14d-4139-8f6f-d910d7e50b29.png" width="1535.2" title="" crop="0,0,1,1" id="u1057ee9e" class="ne-image">
2. 在添加数据面板中，选择**表格 **> **API 同步** > 输入数据表名称并完成 API 必要参数的配置，完成后，点击**确认**即可完成表结构的维护。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775614367146-3af34f29-1e25-4c65-bf1d-5c190cbeb5a8.png" width="1096" title="" crop="0,0,1,1" id="uc3b53588" class="ne-image">

其中，各配置项说明如下。

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 数据表名称 | 是 | 自定义数据表名称，字数最大限制为 20 个字符。 |
| 网关 URL | 是 | 输入以 `.json` 结尾的 API URL，同时<font style="color:rgb(0, 0, 0);">GET请求需要增加2个param，</font>例如 `[<font style="color:#000000;">https://your-site.com/data.json</font>](https://your-site.com/data.json)<font style="color:rgb(0, 0, 0);">?pageSize=50&pageNum=10</font>` 。在公网环境中通过 HTTPS 协议执行 Get 请求获取到的数据，均支持导入。 |
| 同步方式 | 是 | 根据数据量大小可选一次全量同步与分页增量同步。<br/>+ 一次性同步：默认项，单次导入的数据量小于 5000 条时，建议选择此项。<br/>+ 分页同步：若单次同步数据量大于 5000 条，系统会进行拆分分页导入，需要您输入「总数据量」与您期望的「单页数据量」，「单页数据量」最大不超过 5000 条。<br/>:::info **说明**：使用【分页增量同步】同步时，需要传输 <font style="color:rgb(0, 0, 0);">pageSize 和 pageNum 这两个 key，例如：</font>`[<font style="color:#000000;">https://your-site.com/data.json</font>](https://your-site.com/data.json)<font style="color:rgb(0, 0, 0);">?pageSize=50&pageNum=10</font>`<font style="color:#000000;">。</font><br/>:::  |
| URL Header | 否 | 用于向服务器传递额外的请求信息，例如认证令牌或内容格式。 |
| 更新频率 | 是 | 选择是否自动更新指定页面的内容及自动更新的频率。可选：<br/>+ 不自动更新<br/>+ 每 1 天<br/>+ 每 7 天<br/>+ 每 30 天<br/>+ 自定义时间，可精确到小时级。 |


3. 百宝箱从网关 URL 获取到数据后，会解析表结构，自动将字段名与数据类型进行回显，但结果可能存在误差，请进行二次确认。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1764320477149-ee8ce141-200d-48a0-aa23-74af0085c099.png" width="1016.8" title="" crop="0,0,1,1" id="ua4f07158" class="ne-image">
