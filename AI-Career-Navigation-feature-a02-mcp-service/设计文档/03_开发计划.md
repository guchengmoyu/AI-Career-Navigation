# A02 项目开发计划

## 一、项目概述

**项目名称**：AI 职业导航与终身学习伙伴系统

**技术路线**：基于蚂蚁百宝箱企业版平台，采用"百宝箱智能体 + MCP 工具 + 自定义前端"架构

**开发周期**：建议 6-8 周（利用百宝箱平台能力，减少基础设施搭建工作量）

**团队规模**：建议 3-4 人

---

## 二、团队分工建议

### 2.1 角色定义

| 角色 | 人数 | 主要职责 |
|------|------|---------|
| 项目经理/产品经理 | 1 | 需求管理、进度把控、百宝箱平台配置 |
| 前端开发 | 1 | 可视化页面开发、百宝箱卡片设计 |
| 全栈开发 | 1-2 | MCP 工具开发、数据库设计、百宝箱工作流编排 |

### 2.2 技能要求

**前端开发**：
- React 框架经验
- TypeScript 开发能力
- ECharts 可视化图表开发经验
- 百宝箱卡片设计能力（加分）

**全栈开发**：
- Node.js/TypeScript 开发经验
- MySQL 数据库设计与优化能力
- 百宝箱平台使用经验（加分）
- MCP 协议理解（加分）

### 2.3 架构简化带来的分工变化

| 传统架构职责 | 百宝箱架构职责 | 说明 |
|------------|-------------|------|
| 后端 API 开发 | MCP 工具开发 | 仅封装核心业务逻辑，无需完整 API 层 |
| 数据库管理员 | MySQL 设计 | 仅保留业务数据库，无需 Redis/MongoDB/Neo4j |
| AI 工程师 | 百宝箱配置 | 知识库构建、工作流编排、Prompt 优化 |
| DevOps | 平台部署 | 百宝箱一键发布，大幅简化部署流程 |

## 五、风险管理

### 5.1 风险识别

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|---------|
| 百宝箱平台功能限制 | 中 | 高 | 深入研究平台文档，必要时通过自定义前端补充 |
| MCP 协议对接困难 | 中 | 高 | 提前研究文档，及时寻求技术支持 |
| 知识库检索精度不足 | 中 | 中 | 优化数据分段策略，调整检索参数 |
| 大模型输出不稳定 | 低 | 中 | 工作流中增加输出校验与重试节点 |
| 开发进度延迟 | 中 | 中 | 预留缓冲时间，及时调整计划 |

### 5.2 应急预案

**技术风险应急**：
- 百宝箱功能限制：将受限功能迁移至自定义 MCP 工具或前端页面实现
- MCP 对接问题：降级为自定义 REST API，前端直接调用
- 知识库精度不足：人工补充关键数据，优化分段策略

**进度风险应急**：
- 功能延期：优先保障核心功能，非核心功能简化
- 人员变动：及时调整分工，利用百宝箱平台降低技术门槛

| 项目 | 预估成本 | 备注 |
|------|---------|------|
| 服务器 | ¥300-500/月 | 仅部署 MCP 工具服务 |
| MySQL | ¥100-200/月 | 阿里云 RDS 基础版 |
| 大模型 API | ¥0 | 百宝箱平台提供 Token 资源 |
