## 二、核心模块设计

### 2.1 百宝箱智能体配置

**功能职责**：
- 承载用户对话交互的核心入口
- 多角色对话风格切换（职业导师/学习伙伴/面试教练）
- 意图识别与功能路由

**平台配置**：
- **创建方式**：通过工作流创建模式，编排业务逻辑
- **角色与指令**：配置系统 Prompt，定义 AI 人设与行为规范
- **对话效果**：配置开场白、快捷指令、用户问题建议、底纹词等
- **模型选择**：百灵/通义千问/DeepSeek，支持参数调优（温度、top-p、最大输出长度）

**对话流程**：
```
用户输入
    │
    ▼
百宝箱智能体接收
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 工作流编排                                        │
│                                                   │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐   │
│  │ 意图识别  │───→│ 分支节点  │───→│ 对应处理  │   │
│  │ 节点     │    │(条件路由) │    │ 节点     │   │
│  └──────────┘    └──────────┘    └──────────┘   │
│                                                   │
│  路由分支:                                        │
│  · 职业咨询 → 知识库检索 + 大模型回复              │
│  · 画像生成 → MCP工具(画像计算) + 大模型分析       │
│  · 路径规划 → MCP工具(路径生成) + 知识库匹配       │
│  · 场景模拟 → MCP工具(场景管理) + 对话引擎         │
│  · 闲聊陪伴 → 大模型直接回复                       │
└─────────────────────────────────────────────────┘
```

### 2.2 知识库模块

**功能职责**：
- 存储职业、技能、行业、学习资源等结构化知识
- 为大模型提供 RAG（检索增强生成）上下文
- 支持语义检索与全文检索

**知识库规划**：

| 知识库名称 | 类型 | 数据内容 | 数据来源 |
|-----------|------|---------|---------|
| 职业知识库 | 文档知识库 | 职业描述、技能要求、薪资范围、发展路径 | 行业报告、招聘数据 |
| 学习资源库 | 表格知识库 | 课程、书籍、文章、视频等学习资源 | 公开平台数据整理 |
| 行业趋势库 | 文档知识库 | 行业发展趋势、人才需求分析 | 行业研究报告 |
| 认证考试库 | 表格知识库 | 职业认证信息、考试要求 | 官方认证机构数据 |

**数据处理流程**：
```
原始数据（文档/表格）
    │
    ▼
百宝箱数据仓库上传
    │
    ▼
智能分段 + 摘要生成（平台自动处理）
    │
    ▼
向量化存储（平台自动处理）
    │
    ▼
知识库检索（工作流中知识库节点调用）
```

**检索策略**：
- 职业咨询场景：语义检索 + 重排序，返回最相关的知识片段
- 路径生成场景：按技能标签精确匹配 + 语义补充
- 场景模拟场景：按场景类型检索相关行业知识

### 2.3 工作流模块

**功能职责**：
- 编排核心业务逻辑
- 串联知识库检索、MCP 工具调用、大模型处理等节点
- 实现自动化业务流程

**核心工作流设计**：

#### 工作流 1：职业画像生成工作流

```
开始节点（接收用户问卷数据）
    │
    ▼
代码节点（数据预处理与校验）
    │
    ▼
MCP 插件节点（调用画像计算工具）
    │
    ▼
知识库节点（检索目标岗位技能要求）
    │
    ▼
文本大模型节点（综合分析，生成画像报告）
    │
    ▼
直接回复节点（返回画像结果 + 雷达图数据）
```

#### 工作流 2：学习路径生成工作流

```
开始节点（接收目标职位 + 用户约束）
    │
    ▼
MCP 插件节点（获取用户当前画像）
    │
    ▼
知识库节点（检索目标岗位技能要求与学习资源）
    │
    ▼
MCP 插件节点（调用路径生成算法）
    │
    ▼
文本大模型节点（优化路径排序与时间安排）
    │
    ▼
直接回复节点（返回分阶段学习路径）
```

#### 工作流 3：场景模拟训练工作流

```
开始节点（接收场景类型 + 用户消息）
    │
    ▼
意图识别节点（判断当前轮次状态）
    │
    ├── 对话进行中 → 文本大模型节点（角色扮演回复）
    │                    │
    │                    ▼
    │              直接回复节点（返回 AI 角色回复）
    │
    └── 对话结束 → MCP 插件节点（调用场景评估工具）
                      │
                      ▼
                 文本大模型节点（生成评估报告文本）
                      │
                      ▼
                 直接回复节点（返回评估结果）
```

### 2.4 MCP 插件模块

**功能职责**：
- 封装核心业务计算逻辑
- 对接 MySQL 业务数据库
- 作为百宝箱工作流中的可调用工具

**MCP 工具清单**：

| 工具名称 | 功能描述 | 调用场景 |
|---------|---------|---------|
| `calculate_career_profile` | 根据问卷数据计算多维度能力评分 | 画像生成工作流 |
| `get_career_profile` | 获取用户当前画像数据 | 对话查询、路径生成 |
| `generate_learning_path` | 基于能力差距生成学习路径 | 路径生成工作流 |
| `get_learning_path` | 获取用户当前学习路径 | 对话查询、进度展示 |
| `update_task_status` | 更新学习任务状态 | 用户操作反馈 |
| `get_learning_progress` | 获取学习进度统计 | 面板展示、对话查询 |
| `start_scenario_session` | 创建场景模拟会话 | 场景训练工作流 |
| `submit_scenario_message` | 提交场景对话消息 | 场景训练交互 |
| `evaluate_scenario` | 评估场景训练表现 | 场景训练结束 |
| `get_scenario_history` | 获取场景训练历史 | 记录查询 |

**MCP 工具技术实现**：
- 运行环境：Node.js 18 + Express 4
- 数据库访问：Prisma 5 ORM → MySQL 8.0
- 认证方式：百宝箱平台鉴权 + 工具级别权限控制
- 部署方式：独立服务部署，通过 MCP 协议与百宝箱平台对接

## 六、部署架构

### 6.1 部署方案

```
┌─────────────────────────────────────────────────┐
│              百宝箱企业版平台                      │
│  · 智能体应用托管与运行                           │
│  · 大模型推理服务                                 │
│  · 知识库存储与检索                               │
│  · 工作流引擎                                     │
│  · 多端发布（Web/H5/小程序）                      │
│  · 用户认证与会话管理                             │
└─────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────┐
│           自定义 MCP 工具服务                      │
│  · Node.js + Express 应用                        │
│  · 部署在云服务器 or 容器服务                      │
│  · 对接百宝箱 MCP 协议                            │
└─────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────┐
│           MySQL 8.0 数据库                        │
│  · 阿里云 RDS 托管服务                            │
│  · 存储业务数据（用户、画像、路径、记录）           │
└─────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────┐
│           自定义前端页面                           │
│  · React 应用部署在 CDN                           │
│  · 可视化面板、雷达图、路径时间轴等                │
└─────────────────────────────────────────────────┘
```

### 6.2 部署优势

相比传统全栈架构，本方案具有以下优势：
- **无需自建 LLM 服务**：百宝箱平台提供大模型调用能力
- **无需自建知识图谱**：百宝箱知识库替代 Neo4j 图数据库
- **无需自建对话引擎**：百宝箱智能体提供对话管理、上下文维护
- **无需自建缓存层**：百宝箱平台管理对话状态与会话数据
- **无需自建文档存储**：百宝箱知识库替代 MongoDB 存储半结构化数据
- **一键多端发布**：百宝箱原生支持 Web、H5、小程序发布

## 八、扩展性设计

### 8.1 模块扩展

- MCP 工具可独立扩展，新增工具不影响现有工作流
- 知识库可独立扩展，支持新增数据源
- 工作流支持版本管理，可平滑升级
