在百宝箱中，H5 卡片是指基于 React 框架开发、可在 H5 环境（如浏览器或 WebView）中运行的自定义交互卡片。本文将介绍如何开发 H5 卡片，并将其导入百宝箱平台，最终在智能体的工作流中调用和使用。

## 前置说明
百宝箱目前支持 UMD 格式的单文件 React 组件包。为确保兼容性与加载效率，请按以下要求构建打包产物：

+ **外部依赖配置：**`react`和 `react-dom`需配置为 external，分别通过全局变量 `React`和 `ReactDOM`引用。
+ **样式内联：**所有 CSS 样式必须内联打包指至 JS 文件中。当前卡片仅支持单文件交付，不接收独立的 CSS 或资源文件。
+ **部署要求：**打包后的 JS 文件需上传至 CDN，并确保可通过 `render.antgroup.com`域名正常访问（即 CDN 资源对该域名开放 CORS 或无跨域限制）。

关于 UMD 的详细介绍可参见：[UMD 官方概述](https://github.com/umdjs/umd)。

## 步骤 1：环境配置
在进行卡片开发前，需要先配置打包环境，下方将为您介绍一些常见的配置。

### 配置 Webpack
参考下方代码示例将`webpack.config.js`文件下`output`中`library.type` 设置为 `'umd'` 。

```xml
output: {
  path: path.resolve(__dirname, 'dist'),
  filename: 'my-library.umd.js',
  library: {
    name: 'MyLibrary', // 全局变量名
    type: 'umd',
  },
  globalObject: 'this', // 确保在 Node.js 和浏览器中都可用
}
```

### 配置 Rollup
参考下方代码示例将`rollup.config.js` 文件下`output` 中 `format`设置为 `'umd'`。

```xml
output: {
  file: 'dist/my-library.umd.js',
  format: 'umd',
  name: 'MyLibrary', // 全局变量名
}
```

### 配置 Vite
参考下方代码示例，将 `vite.config.js`文件下 `build.lib.formats`配置为 `'umd','es'`。

```xml
build: {
  lib: {
    entry: 'src/index.js',
    name: 'MyLibrary',
    fileName: (format) => `my-library.${format}.js`,
    formats: ['umd', 'es'], // 可以同时输出多种格式
  }
}
```

通过上述步骤完成环境配置后，我们建议您单独启用一个项目进行卡片构建。

## 步骤 2：开发卡片
:::info
**说明：**

为帮助您快速上手卡片开发，百宝箱提供了一个基于 Vite 构建的示例工程，支持打包输出符合要求的 UMD 格式组件包，并可导出多个子组件。点击右侧链接即可下载：[umd-component-vite.zip](https://alipaytbox.yuque.com/attachments/yuque/0/2026/zip/1397496/1770715933728-442f66d4-f00b-45b3-98c4-869d45cb1809.zip)。

:::

下文将基于百宝箱提供的 demo 为您介绍如何进行卡片开发。

1. 解压附件中的示例工程。
2. 使用下述命令进行工程构建。

```shell
npm install
npm run build
```

此时，您会得到一个 `dist/umd-component-lib.umd.js`的文件，该文件满足打包产物的全部要求。		<img src="https://cdn.nlark.com/yuque/0/2025/png/294116/1757511083875-b6350ce8-da44-4079-8e81-d0068c90acf6.png?x-oss-process=image%2Fformat%2Cwebp" width="399" title="" crop="0,0,1,1" id="vxRua" class="ne-image">

3. 在项目中的 `src/components`中可进行卡片组件的自定义，并支持在 `src/lib/index.ts`中通过下述代码示例进行卡片的导出。

```tsx
// 导出所有组件
export { Button } from "../components/Button";
export { Card } from "../components/Card";
// TODO 新增导出
```

4. 通过下述命令实现自定义卡片的预览。

```shell
npm run dev
```

5. 开发完毕并预览无误后，可将产物再次打包并将 JS 上传至 CDN，并记录静态资源地址，供后续导入时使用。
