本文将介绍输入框组件的使用方法。

## 使用限制
+ 设置为密码框类型时，只支持单行输入
+ 暂不支持键盘相关JSAPI

## 属性说明
| **属性** | **类型** | **必填** | **描述** |
| --- | --- | --- | --- |
| `value` | String | 否 | 初始内容。 |
| `password` | Boolean | 否 | 是否是密码类型。   **默认值：** false<br/> |
| `disabled` | Boolean | 否 | 是否禁用。   **默认值：** false |
| `placeholder` | String | 否 | 占位符。 |
| `maxlength` | Number | 否 | 最大长度。   默认值： 140 |
| `focus` | Boolean | 否 | 获取焦点。   **默认值：** false |
| `type` | String | 否 | input 的类型，有效值：`text`、 `number`、 `idcard`、 `digit`(可以唤起带有小数点的数字键盘)、`numberpad`、`digitpad`、 `idcardpad`、`nickname`。<br/>**默认值：** text   **注意：** 当启用数字键盘时，在 Android 客户端上，脱离文档流（如设置了 `float`<br/> 或 `position: fixed`<br/> 等样式）并指定了 `bottom`<br/> 属性的元素会被影响（该元素会被键盘顶起）。可以采用如下方法来暂且避免这个问题：当 input 框聚焦后隐藏被影响的元素。 |
| `onInput` | EventHandle | 否 | 键盘输入时触发 input 事件，`event.detail = {value: value,cursor: cursor}`<br/>。 |
| `onConfirm` | EventHandle | 否 | 点击键盘完成时触发，`event.detail = {value: value}` |
| `onFocus` | EventHandle | 否 | 聚焦时触发，`event.detail = {value: value}`<br/>。 |
| `onBlur` | EventHandle | 否 | 失去焦点时触发（仅支持真机），`event.detail = {value: value}`。 |
| `style` | Object | 否 | 内联样式 |


## 代码示例
```typescript
<view class="input-root">
    <text class="text">paul-input输入框测试 {{dataReadyParams}}</text>
    <input
      placeholder="文本框"
      type="text"
    ></input>
    <input
      placeholder="数字框"
      type="number"
    ></input>
    <input
      placeholder="idcard"
      type="idcard"
    ></input>
    <input
      placeholder="digit"
      type="digit"
    ></input>
    <input
      placeholder="numberpad"
      type="numberpad"
    ></input>
    <input
      placeholder="digitpad"
      type="digitpad"
    ></input> 
    <input
      placeholder="idcardpad"
      type="idcardpad"
    ></input>
    <input
      value="123"
      password
    ></input>
    <input
      placeholder="禁用输入框"
      disabled="true"
    ></input>
      <input
        placeholder="最大长度2"
        maxlength="2"
      ></input>
      <input
        placeholder="聚焦"
        type="text"
      ></input>
    <input
      placeholder="input事件"
      onInput="onInput"
      onConfirm="onConfirm"
      onFocus="onFocus"
      onBlur="onBlur"
      type="idcardpad"
      id="myInput"
      focus="{{ true }}"
    ></input>
    <!-- 受控input实现测试 -->
</view>
```
