本文将介绍地图组件的使用方法。

## 使用限制
+ 地图组件实现都是支付宝容器的同层组件，因此在 Web 浏览器里暂不可用

## 属性说明
> 详情可参考：[支付宝小程序云-map 地图](https://opendocs.alipay.com/mini/component/map?pathHash=c9886630)
>

| **属性名** | **类型** | **必填** | **说明** |
| --- | --- | --- | --- |
| latitude | number | 否 | 中心纬度。 |
| longitude | number | 否 | 中心经度。 |
| scale | number | 否 | 缩放级别，取值范围为 5-18。 |
| skew | number | 否 | 倾斜角度，范围 0 ~ 40 , 关于 z 轴的倾角。 |
| rotate | number | 否 | 顺时针旋转的角度，范围 0 ~ 360。 |
| markers | array | 否 | 覆盖物，在地图上的一个点绘制图标。 |
| polyline | array | 否 | 覆盖物，多个连贯点的集合（路线）。 |
| circles | array | 否 | 覆盖物，圆 |
| controls | array | 否 | 在地图 View 之上的一个控件。 |
| polygon | array | 否 | 覆盖物，多边形。 |
| showLocation | boolean | 否 | 是否显示带有方向的当前定位点。 |
| includePoints | array | 否 | 视野将进行小范围延伸包含传入的坐标。 |
| includePadding | object | 否 | 视野在地图 padding 范围内展示。 |
| groundOverlays | array | 否 | 覆盖物，自定义贴图。 |
| tileOverlay | object | 否 | 覆盖物，网格贴图。 |
| customMapStyle | string | 否 | 设置地图样式。 <br/>+ default：默认样式<br/>+ light：精简样式 |
| panels | array | 否 | 基于 map 高级定制渲染，设置覆盖在地图上的 view。 |
| setting | object | 否 | 设置 |
| showCompass | boolean | 否 | 显示指南针。 |
| showScale | boolean | 否 | 显示比例尺。 |
| enablePoi | boolean | 否 | 是否展示 POI 点。 |
| enableZoom | boolean | 否 | 是否支持缩放 |
| enableScroll | boolean | 否 | 是否支持拖动 |
| enableRotate | boolean | 否 | 是否支持旋转 |
| enableSatellite | boolean | 否 | 是否开启卫星图 |
| enableOverlooking | boolean | 否 | 开发俯视 |
| enableTraffic | boolean | 否 | 是否开启实时路况 |
| enableBuilding | boolean | 否 | 是否展示建筑物 |
| onRegionChange | function | 否 | 视野发生变化时触发。 |
| onMarkerTap | function | 否 | 点击 Marker 时触发。 |


### 代码示例
```plain
<view class="map">
  <map
    latitude="39.937020"
    longitude="116.387370"
  />
</view>
```
