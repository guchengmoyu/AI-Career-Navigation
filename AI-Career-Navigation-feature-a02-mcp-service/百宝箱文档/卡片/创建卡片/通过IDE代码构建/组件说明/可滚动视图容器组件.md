可滚动视图容器，可实现纵向滚动和横向滚动。使用纵向滚动时，需要给改组件一个固定高度。

## 使用限制
+ <font style="color:rgb(51, 51, 51);">不支持同方向的</font>`<font style="color:rgb(51, 51, 51);">scroll-view</font>`<font style="color:rgb(51, 51, 51);">嵌套使用</font>
+ <font style="color:rgb(51, 51, 51);">暂不支持在</font>`<font style="color:rgb(51, 51, 51);">scroll-view</font>`<font style="color:rgb(51, 51, 51);">初始化阶段设置</font>`scroll-top``scroll-left`
+ 使用`onTap`等事件时，请先确认待投放的容器版本：
    - 投放至支付宝，需确保`**<font style="color:#DF2A3F;">支付宝客户端版本 》10.6.16</font>**`

## <font style="color:rgb(51, 51, 51);">属性说明</font>
| **属性名** | **类型** | **默认值** | **说明** |
| --- | --- | --- | --- |
| `class` | String | 自定义样式名 | `class` |
| `style` | String | 内联样式 | `style` |
| `scroll-x` | Boolean | false | 允许横向滚动 |
| `scroll-y` | Boolean | false | 允许纵向滚动 |
| `upper-threshold` | Number | 50 | 距离顶部（左边界）多远时，触发 scrolltoupper 事件 |
| `lower-threshold` | Number | 50 | 距离底部（右边界）多远时，触发 scrolltolower 事件 |
| `scroll-top`<br/><font style="background:#F6E1AC;color:#664900">客户端10.2.58以上版本支持</font> | Number | - | 设置纵向滚动位置 |
| `scroll-left`<br/><font style="background:#F6E1AC;color:#664900">客户端10.2.58以上版本支持</font> | Number | - | 设置横向滚动位置 |
| `scroll-with-animation`<br/><font style="background:#F6E1AC;color:#664900">客户端10.3.70 支持</font> | Number | false | 在设置滚动位置时使用动画过渡 |
| `onScroll` | EventHandle | - | 当视图容器滚动时触发<br/>事件对象：`event.detail = {scrollHeight: '滚动区域内容高度px', scrollLeft: '横向滚动距离px', scrollTop: '纵向滚动距离px', scrollWidth: '滚动区域内容宽度px'}`<br/><font style="color:rgb(38, 38, 38);">滚动时触发</font><br/>`<font style="color:rgb(85, 85, 85);">event.detail = {scrollLeft, scrollTop, scrollHeight, scrollWidth}</font>`<br/><font style="color:rgb(38, 38, 38);"></font> |
| `onScrollToLower` | EventHandle | - | 滚动到底部 / 右边时触发 |
| `onScrollToUpper` | EventHandle | - | 滚动到顶部 / 左边时触发 |


## 代码示例
```html
<scroll-view
  scroll-y="{{true}}"
  style="height: 200px;"
  onScrollToUpper="upper"
  onScrollToLower="lower"
  onScroll="scroll"
  scroll-top="{{scrollTop}}"
  >
  <view id="blue" class="scroll-view-item bc_blue"></view>
  <view id="red"  class="scroll-view-item bc_red"></view>
  <view id="yellow" class="scroll-view-item bc_yellow"></view>
  <view id="green" class="scroll-view-item bc_green"></view>
</scroll-view>
```
