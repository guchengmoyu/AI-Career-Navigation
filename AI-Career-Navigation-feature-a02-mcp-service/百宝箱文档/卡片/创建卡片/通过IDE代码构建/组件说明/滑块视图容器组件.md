滑块视图容器内部仅允许使用 swiper-item 组件描述滑块内容，否则会导致未定义的行为。

## 使用限制
+ <font style="color:rgb(51, 51, 51);">样式限制：不支持包括盒子模型中的 padding、布局中的 flex 容器、flex 成员、背景中的 background-image 相关、hover、动画</font>
+ 使用`onTap`等事件时，请先确认待投放的容器版本：
    - 投放至支付宝，需确保`**<font style="color:#DF2A3F;">支付宝客户端版本 》10.6.16</font>**`

## <font style="color:rgb(51, 51, 51);">属性说明</font>
| **属性名** | **类型** | **说明** |
| --- | --- | --- |
| `class` | `String` | 自定义样式名 |
| `style` | `String` | 内联样式 |
| `indicator-dots` | `Boolean` | <font style="color:rgb(38, 38, 38);">是否显示指示点。</font>   **<font style="color:rgb(38, 38, 38);">默认值：</font>**<font style="color:rgb(38, 38, 38);"> false</font> |
| `indicator-color` | `Color` | <font style="color:rgb(38, 38, 38);">指示点颜色。</font>   **<font style="color:rgb(38, 38, 38);">默认值：</font>**<font style="color:rgb(38, 38, 38);"> #</font>e8e8e8 |
| `indicator-active-color` | `Color` | <font style="color:rgb(38, 38, 38);">当前选中的指示点颜色。</font>   **<font style="color:rgb(38, 38, 38);">默认值：</font>**<font style="color:rgb(38, 38, 38);"></font>#108ee9 |
| `autoplay` | `Boolean` | <font style="color:rgb(38, 38, 38);">是否自动切换。</font>   **<font style="color:rgb(38, 38, 38);">默认值：</font>**<font style="color:rgb(38, 38, 38);"> false</font> |
| `current` | `Number` | <font style="color:rgb(38, 38, 38);">当前页面的 index，可以增加左右箭头来控制轮播滚动。</font>   **<font style="color:rgb(38, 38, 38);">默认值：</font>**<font style="color:rgb(38, 38, 38);"> 0</font> |
| `interval` | `Number` | <font style="color:rgb(38, 38, 38);">自动切换时间间隔。</font>   **<font style="color:rgb(38, 38, 38);">默认值：</font>**<font style="color:rgb(38, 38, 38);"> 500(ms)</font> |
| `<font style="color:rgb(38, 38, 38);">onChange</font>` | `<font style="color:rgb(38, 38, 38);">EventHandle</font>` | <font style="color:rgb(38, 38, 38);">current 改变时会触发</font><br/>```javascript event.detail = {   current: Number } ```  |


## 代码示例
```html
<swiper style="height: 150px;">
  <swiper-item key="swiper-item-{{index}}" a:for="{{background}}">
      <view style="background-color:{{item.color}}">
        <text>{{item.text}}</text>
      </view>
  </swiper-item>
</swiper>
```

```javascript
Component({
  data: {
    background: [
      { color: 'blue', text: '支付宝' },
      { color: 'red', text: '小程序' },
      { color: 'yellow', text: 'Swiper' }
    ],
  }
});
```
