本文将介绍按钮组件的使用方法。

## 使用限制
+ `<font style="color:rgb(51, 51, 51);">button</font>`<font style="color:rgb(51, 51, 51);"> 内部不可嵌套任何其他组件。</font>
+ <font style="color:rgb(51, 51, 51);">由于 cube 默认开启样式隔离，因此不支持通过 class 指定 button 样式，支持通过 style 修改 button 样式。</font>
+ <font style="color:rgb(51, 51, 51);">button 目前只支持 onTap 事件，如果需要在 onTap 事件中接收标签上绑定的 data-* 值，基于约定一律放在</font>`<font style="color:rgb(51, 51, 51);">data-value</font>`<font style="color:rgb(51, 51, 51);"> 下。</font>

```plain
// index.axml
<button onTap="handleTapBtn" data-value="{{value1: "xx", value2: "yy"}}">我是按钮</button>

// index.ts
Component({
  // ...
  methods: {
    handleTapBtn(e) {
      const { value1, value2 } = e.target.dataset?.value ?? {}
    }
  }
})
```

+ 使用`onTap`等事件时，请先确认待投放的容器版本：
    - 投放至支付宝，需确保`**<font style="color:#DF2A3F;">支付宝客户端版本 》10.6.16</font>**`**<font style="color:#DF2A3F;">。</font>**

## 属性说明
| **属性名** | **类型** | **必填** | **说明** |
| --- | --- | --- | --- |
| `style` | Object | 否 | 内联样式 |
| `type` | String | 否 | 按钮的样式类型，有效值 primary、default、warn、ghost。   **默认值：** default |
| `disabled` | Boolean | 否 | 是否禁用。   **默认值：** false |
| `loading` | Boolean | 否 | 按钮文字前是否带 loading 图标。   **默认值：** false |
| `onTap` | EventHandle | 否 | 点击。   **说明：** 每点击一次会触发一次事件，建议自行使用代码防止重复点击,可以使用 js 防抖和节流实现。 |
| `hover-class` | String | 否 | 如果需要关闭 hover 效果，可以指定为 "none" |
| `hover-start-time` | Number | 否 | 按住后多少时间后出现点击状态，单位毫秒。   **默认值：** 20 |
| `hover-stay-time` | Number | 否 | 手指松开后点击状态保留时间，单位毫秒。   **默认值：** 70 |
