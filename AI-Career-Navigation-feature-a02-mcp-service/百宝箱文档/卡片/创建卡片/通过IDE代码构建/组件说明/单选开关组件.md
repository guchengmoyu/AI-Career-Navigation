本文将介绍单选开关组件的使用方法。

## 使用限制
+ <font style="color:rgb(51, 51, 51);">由于 cube 默认开启样式隔离，因此不支持通过 class 指定 switch 样式，支持通过 style 修改 switch 样式。</font>
+ `<font style="color:rgb(51, 51, 51);">switch</font>`<font style="color:rgb(51, 51, 51);"> 内部不可嵌套任何其他组件。</font>

## 属性说明
| **属性名** | **类型** | **必填** | **说明** |
| --- | --- | --- | --- |
| `style` | Object | 否 | 内联样式 |
| `checked` | Boolean | 否 | 是否选中<br/>**默认值：** false |
| `disabled` | Boolean | 否 | 是否禁用   **默认值：** false |
| `color` | Color | 否 | 组件颜色   **默认值：** #108ee9 |
| `controlled` | Boolean | 否 | 是否为受控组件，为 true 时，`checked`<br/> 会完全受 setData 控制。   **默认值：** false |
| `onChange` | EventHandle | 否 | checked 改变时触发，`event.detail={ value:checked}` |




## 代码示例
```plain
<view class="page">
  <switch onChange="switch1Change" style="{{marginBottom: '20rpx' }}"/>
  <switch disabled onChange="switch2Change" checked="{{checked}}" controlled="{{false}}" style="{{marginBottom: '10rpx' }}"/>
  <switch color="red" checked="{{checked}}" controlled style="{{marginBottom: '10rpx' }}"/>
  <switch color="red" checked="{{checked}}" style="{{marginBottom: '10rpx' }}"/>

  <switch disabled  onChange="switch1Change" style="{{marginBottom: '10rpx' }}"/>
  <switch disabled checked  onChange="switch1Change" style="{{marginBottom: '10rpx' }}"/>
  <switch color="yellow" disabled checked="{{checked}}"  onChange="switch1Change" style="{{marginBottom: '10rpx' }}"/>
  
  <button onTap="handleTap">改变check</button>
</view>

```
