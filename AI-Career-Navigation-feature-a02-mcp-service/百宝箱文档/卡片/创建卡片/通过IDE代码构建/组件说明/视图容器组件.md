文本将介绍视图容器组件的属性集代码示例。

## 使用限制
+ `<font style="color:rgb(51, 51, 51);">view</font>`<font style="color:rgb(51, 51, 51);">不支持直接添加文本，如要添加文本需使用</font>`<font style="color:rgb(51, 51, 51);">text</font>`<font style="color:rgb(51, 51, 51);">组件包裹</font>
+ `<font style="color:rgb(51, 51, 51);">view</font>`<font style="color:rgb(51, 51, 51);">不可滚动，如需滚动需要使用</font>`<font style="color:rgb(51, 51, 51);">scroll-view</font>`<font style="color:rgb(51, 51, 51);">组件代替</font>
+ 使用`onTap`等事件时，请先确认待投放的容器版本：
    - 投放至支付宝，需确保`**<font style="color:#DF2A3F;">支付宝客户端版本 》10.6.16</font>**`

## <font style="color:rgb(51, 51, 51);">属性说明</font>
| **属性名** | **类型** | **说明** |
| --- | --- | --- |
| `class` | String | 自定义样式名 |
| `style` | String | 内联样式 |
| `onTap` | EventHandle | 点击。 |
| `onTouchStart` | EventHandle | 触摸动作开始。 |
| `onTouchMove` | EventHandle | 触摸后移动。 |
| `onTouchEnd` | EventHandle | 触摸动作结束。 |
| `onTouchCancel` | EventHandle | 触摸动作被打断，如来电提醒，弹窗。 |
| `onLongTap` | EventHandle | 长按 500ms 之后触发，触发了长按事件后进行移动将不会触发屏幕的滚动。 |


## 代码示例
```html
<view class="active" onTap="onViewClick">
  <text>Hello Paul</text>
</view>
```
