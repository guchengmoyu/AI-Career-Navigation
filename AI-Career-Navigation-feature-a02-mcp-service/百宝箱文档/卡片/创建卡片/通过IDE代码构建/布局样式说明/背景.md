## 使用方法 <font style="background:#F6E1AC;color:#664900">以下特性仅Cube下受限</font>
指定一个元素的背景样式有以下2种方式：

+ background-color，定义元素的背景颜色

| **属性** | **值类型** | **默认值** | **可选值** |
| :--- | :--- | :--- | :--- |
| background-color | 色彩单位 | transparent |  |


+ background-image，定义元素的背景图像

| **属性** | **值类型** | **默认值** | **可选值** | **写法** | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| background-image | <font style="color:#262626;">string</font> | 无 | <font style="color:black;">url(“https:/xxx”)CDN地址；url(“data:”)base64编码；</font><br/><font style="color:black;">linear-gradient(s1,s2,…,slast),</font><font style="color:black;">第一段（渐变角度设置，取值为具体对角度值以deg结尾，或者为方向描述，包括 top、to top、right、to right、bottom、to bottom、left、to left）</font><font style="color:black;">，第二段（渐变起始颜色设置，色彩单位；如果</font><font style="color:black;">有百分比值，必须为</font><font style="color:black;">0%</font><font style="color:black;">），中间段（渐变过程颜色设置，色彩单位；支持设置百分比值，必须为线性递增方式，不提供百分比时，颜色占比情况将被均分），最后一段（渐变终止颜色设置，色彩单位；如果有百分比值，必须为</font><font style="color:black;">100%</font><font style="color:black;">）；</font><br/><font style="color:black;">none：清除背景；</font> | <font style="color:black;">background-image: </font>linear-gradient(45deg, red 0%, #333 50%, rgb(255,0, 255) 80%, green 100%); |  |
| | | | | background-image: linear-gradient(to top,red, #333, rgb(255, 0, 255), green); | |
| | | | | background-image: url("https://gw-office.alipayobjects.com/basement_prod/e047f6c8-dc14-481f-a22c-8dd9012b01a3.png"); | |
| background-size | string或长度单位 | auto | <font style="color:black;">单描述值（</font><font style="color:black;">cover</font><font style="color:black;">，</font><font style="color:black;">contain</font><font style="color:black;">，</font><font style="color:black;">auto</font><font style="color:black;">）</font><font style="color:black;">；</font><br/><font style="color:black;">${x}px ${y}px </font><font style="color:black;">双精确值</font><font style="color:black;"> </font><font style="color:black;">长度单位</font><font style="color:black;">+</font><font style="color:black;">百分比；</font><br/><font style="color:black;">${x}px </font><font style="color:black;">单值长度单位</font><font style="color:black;">+</font><font style="color:black;">百分比；</font> | background-size:contain; | 精确值或百分比只单值时，另外一个值默认auto |
| | | | | background-size:100px 200px; | |
| background-position | string | 0 | 单描述值（top，right，bottom，left，center）；<br/>双描述值（bottom right）；<br/>${x}px 单值长度单位/${y}px 单值长度单位+单描述值；<br/>${x}px 单值长度单位+百分比；${y}px 单值长度单位+百分比 | background-position:top; | 单值时，另一个值默认居中 |
| | | | | background-position:bottom right; | |
| | | | | background-position:30px top; | |
| | | | | background-position:100px; | |
| | | | | background-position:50px 50px; | |
| background-repeat | string | repeat | repeat-x, repeat-y, no-repeat, repeat | 单值：background-repeat: repeat-x; |  |
| | | | | 双值：background-repeat: repeat no-repeat; 其中x轴描述包含（no-repeat、repeat）y轴描述包含（no-repeat、repeat） |  |


## 阴影
用于设置元素的阴影。

| **属性** | **值类型** | **默认值** | **可选值** | **写法** | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| box-shadow | 长度单位&色彩单位 | 无 | <font style="color:black;">支持格式</font><font style="color:black;">${x}${y}${size}${color}</font><font style="color:black;">，</font><font style="color:black;">x</font><font style="color:black;">，</font><font style="color:black;">y</font><font style="color:black;">，</font><font style="color:black;">size</font><font style="color:black;">满足长度单位，</font><font style="color:black;">color</font><font style="color:black;">满足色彩单位</font> | <font style="color:black;">box-shadow: 10px 20px 10px red;</font> | 四个值必需 |


:::info
**注意：**每个元素只支持设置一个阴影效果，不支持多个阴影同时作用于一个元素。

:::
