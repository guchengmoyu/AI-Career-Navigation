#### <font style="color:rgb(53, 53, 53);">字体资源</font>
<font style="color:rgb(34, 34, 34);">在模板的 manifest.json 中添加 importFonts 字段来配置需要导入的字体. </font>

<font style="color:rgb(34, 34, 34);">以 AlipayNumber 示例如下:</font>

```json
{
    "version": "1.0.0",
    "name": "KE_CONTENTS",
    "sdk_version": "1.0.0",
    "description": "",
    "extend": "",
    "importFonts":["AlipayNumber"]
}
```

<font style="color:rgb(34, 34, 34);">然后在 CSS 样式中即可应用该字体</font>

```vue
<template>
  ...
<text class="gtd_arrow" value=''></text>    
  ...
</template>

<style>
.gtd_arrow {
  font-family: IconFont;
  font-size: 12sp;
  color: #BBBBBB;
}
  </style>
```

```css
.scribPrice {
    lines: 1;
    font-family: AlipayNumber;
    font-size: 12sip;
    text-overflow: ellipsis;
    color: #999999;
}
```

<font style="color:#F5222D;">目前仅支持 IconFont 和 AlipayNumber 。</font>

## <font style="color:rgb(34, 34, 34);">动画支持</font>
:::info
1. <font style="color:rgb(34, 34, 34);">要使用 CSS keyframes 动画，需依赖 ACT 最低版本 3.10.3，并且在 manifest.json 中需要开启特定配置字段；</font>
2. <font style="color:rgb(34, 34, 34);">开启上述 CSS 动画能力后，支付宝客户端 5.10 版本对动画的标准行为存在 breaking-change，如果业务对低版本动画表现有强需求建议质量回归低版本支付宝客户端表现一致性及是否符合业务预期；</font>
3. <font style="color:rgb(34, 34, 34);">如果不开启上述 CSS keyframes 动画能力，可以使用卡片老版本支持的动画 </font>[JSAPI 注册 keyframes](https://alipaytbox.yuque.com/sxs0ba/huntb8/rv7c75g42uepg07r)<font style="color:rgb(34, 34, 34);">，在CSS 中的 animation-name 使用 JS 定义的 keyframes。</font>

:::

<font style="color:rgb(34, 34, 34);">升级 ACT 到支持动画库的版本（version > 3.10.3）</font>

```shell
tnpm i -g @alipay/cube@latest
```

<font style="color:rgb(34, 34, 34);">在 manifest.json 里开启支持动画的 config：</font>

`<font style="color:rgb(34, 34, 34);">jsformat = 1</font>`

`<font style="color:rgb(34, 34, 34);">featureConfig.aniPipe = 1</font>`

```json
{
    "name": "test-animate",
    "version": "1.0.0",
    "compilerType": 1,
    "jsformat": 1,
    "featureConfig": {
        "aniPipe": 1
    }
}
```
