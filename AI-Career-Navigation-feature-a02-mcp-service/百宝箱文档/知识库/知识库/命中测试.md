命中测试是知识库质量保障的重要环节，用于在知识库构建完成后、正式上线前，通过模拟用户查询来验证知识库能否准确、高效地返回相关知识内容。百宝箱提供简洁易用的在线命中测试工具，支持自定义召回策略配置，帮助开发者快速验证知识可用性，确保智能体能够为用户提供准确的知识服务。

## 配置测试参数
1. 开发者访问[知识库](https://b.tbox.cn/inc/knowledge)。
2. 在知识库详情页，点击右上角的**命中测试**。

3. 在命中测试页面，选择检索方式并输入测试内容，点击**测试**。

:::info
**说明：**百宝箱支持**语义/全文检索**和**地理位置检索**两种检索方式，两种方式仅支持单独启用，不支持同时使用。请根据知识库所选检索方式选择对应的方式进行命中测试。

:::

### 语义/全文检索
选择**语义/全文检索**时，命中测试的配置项说明如下。

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 检索关键词或语句 | 是 | 指进行命中测试的提问语句，建议使用简短的陈述句，最多可输入 1000 个字。 |
| 检索匹配策略 | 否 | 指从知识库中获取知识时所采用的检索方式，合适的检索策略能够更有助于找到正确且有效的信息，继而提高智能体答案生成的准确性与可用性。当前支持：<br/>+ **智能检索：**结合语义检索和关键词检索的优势，经过综合排序后再给出检索的结果列表，召回效果较好但是耗时会更长。<br/>+ **语义检索：**指通过向量化文本对比的方式，判断问题与知识之间的关联程度，从而筛选出高关联的部分。该策略会像人类一样去理解上下文之间的关系，适用于需要理解语义或跨语言查询的场景。<br/>+ **关键词检索：**指使用提问时的关键词在知识库中进行精确匹配，适用于需要精准回答的场景。 |
| 检索最大结果数 | 否 | 指从知识库返回的最大段落数，该值越大，返回的段落条目越多。默认值为 `5`。 |
| 检索最小匹配度 | 否 | 匹配度是衡量用户查询（query）与知识库中文档分段见的寓意相关程度的指标，通常取值范围在 `[0,1]`，默认值为 `0.500`:<br/>+ 越靠近 1，说明语义越相关，为 1 时完全一致；<br/>+ 越靠近 0，说明相关性越低，为 0 时毫不相关。<br/>最小匹配度则是一个可预置的阈值，用于对召回结果进行相关性的过滤，低于该值的内容将不会被召回。 |
| 语义精排 | 否 | 精排，即精细排序，是指相连检索完成初步召回后没引入基于预训练语言模型的深度语义排序模型，对召回的文档片段进行二次相关性评估与重排序，以提升最终返回结果的寓意准确性与业务相关性。适用于对回答准确性、专业性和相关性要求较高的业务场景，如智能客服、技术文档 FAQ 等。<br/>+ **未启用精排时：**系统直接一句向量相似度对召回结果进行降序排列，响应速度快，但语义理解能力有限。<br/>+ **启用精排后：**系统将向量化检索召回的候选文档输入至百宝箱预置的 Rerank 模型，该模型会通过细粒度的语义匹配、上下文对齐以及内容质量评估，对结果进行精细化打分和重排，确保与用户查询意图最相关、信息最完整的文档优先输出，开启后会增加耗时。 |
| 精排最大结果数 | 否 | 开启语义精排后可配置，用于设定系统最终返回给用户的最相关结果的数量上限，默认值为 `3`。 |
| 精排最小匹配度 | 否 | 开启语义精排后可配置，用于设定系统最终检索的匹配度阈值，仅保留相关性高于该值的结果，低于该值的将被筛除。默认值为 `0.800`。 |
| 后排序 | 否 | 开启后将打乱知识库原有的混合召回排序，召回结果会按自定义规则重新排列，可拖拽调整优先级。 |
| 筛选条件 | 否 | 仅适用于表格型知识库。通过添加筛选条件，可精确筛选具体表格字段内容，例如在向用户推荐商品时，仅推荐保质期大于 30 天的优秀商品。不同字段类型支持的筛选条件也有所差别，详细说明可参见：[表格字段筛选条件枚举](https://alipaytbox.yuque.com/vksmxp/draft/gd4cz3td4fnnb085#bMWeh)。 |


### 地理位置检索
选择**地理位置检索**时，各配置项说明如下。

:::info
**说明：**地理位置检索仅支持对表格知识库进行命中测试，请确保知识库中包含有效的经纬度字段。

:::

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 当前位置（POI） | 是 | 指定用于检索的经纬度坐标。点击右侧地图图标进行选点，坐标需精确至小数点后 6 位。<br/>+ 示例：`119.297014,26.084312`（经度,纬度）<br/>+ 经度取值范围：[-180, 180]<br/>+ 纬度取值范围：[-90, 90] |
| 搜索半径 | 否 | 设定检索的空间范围，单位为米（m）。根据业务需求设置合理的搜索半径，默认值为 `1000`。 |
| 搜索范围 | 否 | 指定检索的目标区域范围，支持：<br/>+ **范围内**（默认）：返回指定坐标周围搜索半径范围内的知识条目。<br/>+ **范围外**：返回指定坐标周围搜索半径范围外的知识条目。 |
| 检索最大结果数 | 否 | 指从知识库返回的最大结果条数，默认值为 `5`。该值越大，返回的结果条目越多。 |


## 查看命中结果
完成测试后，命中效果将展示在右侧的命中段落中。您可以根据命中效果来调整对应的应用数据的分段设置，直至其符合期望。应用数据分段的调整说明，可参见：[管理数据](https://alipaytbox.yuque.com/sxs0ba/huntb8/database_setting)。
