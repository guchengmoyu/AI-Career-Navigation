本文将介绍什么是知识库的数据属性以及如何使用。

## 功能介绍
**数据属性**是指平台预设及开发者自定义的、用于描述知识库中文档特征的元信息。这些属性在知识检索过程中可作为筛选条件，帮助实现更精准、高效的内容匹配。

平台为所有问文档知识库文档自动提供一组通用的内置数据属性（doc_id 、doc_name与<font style="color:rgba(0, 0, 0, 0.88);background-color:rgba(250, 250, 250, 0.592);">gmt_create</font>），无需用户手动配置，系统会在文档上传或更新时自动生成并维护。开发者在检索时可直接基于这些固有属性进行精确筛选，无需额外设置。

此外，开发者还可根据业务需求自定义数据属性（如“部门”“适用场景”“文档类型”等），进一步增强知识库的结构化能力与检索灵活性。

## 功能特性
+ **<font style="color:rgb(15, 17, 21);">开箱即用</font>**<font style="color:rgb(15, 17, 21);">：已完成对文档唯一标识</font>`<font style="color:rgb(15, 17, 21);">doc_id</font>`<font style="color:rgb(15, 17, 21);"> 和 文档名称</font>`<font style="color:rgb(15, 17, 21);">doc_name</font>`<font style="color:rgb(15, 17, 21);"> 等元信息的索引，开发者可立即在查询中将其作为过滤条件使用，无需额外开发或设置。</font>
+ **<font style="color:rgb(15, 17, 21);">提升精度</font>**<font style="color:rgb(15, 17, 21);">：在检索时，通过指定 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">doc_id</font>`<font style="color:rgb(15, 17, 21);"> 或 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">doc_name</font>`<font style="color:rgb(15, 17, 21);">，可将检索范围严格限定在特定的一个或多个目标文档内，有效排除无关内容干扰，显著提升结果的相关性与准确性。</font>
+ **<font style="color:rgb(15, 17, 21);">增强扩展：</font>**<font style="color:rgb(15, 17, 21);">在内置属性基础上，开发者可根据业务场景（如“所属部门”“适用产品线”“文档密级”等）定义自定义数据属性，进一步丰富知识库的结构化能力，支持更复杂的筛选与权限控制需求。</font>

## 平台预设属性
| **属性名称** | **属性描述** | **数据类型** |
| :--- | :--- | :--- |
| doc_id | 文档ID | NUMBER |
| doc_name | 文档名称 | STRING |
| <font style="color:rgba(0, 0, 0, 0.88);background-color:rgba(250, 250, 250, 0.592);">gmt_create</font> | <font style="color:rgba(0, 0, 0, 0.88);background-color:rgba(250, 250, 250, 0.906);">文档创建时间</font> | <font style="color:rgba(0, 0, 0, 0.88);background-color:rgba(250, 250, 250, 0.396);">DATETIME</font> |


## 使用示例：基于数据属性实现精准文档检索
<font style="color:rgb(15, 17, 21);">假设您的知识库里有以下文档：</font>

| 文档名称 | doc_id | doc_name |
| --- | --- | --- |
| 《2023年第四季度财报》 | <font style="color:rgb(15, 17, 21);">finance_report_2023_q4</font> | <font style="color:rgb(15, 17, 21);">2023年第四季度财报.pdf</font> |
| 《2024-01-01 项目会议纪要》 | <font style="color:rgb(15, 17, 21);">meeting_minutes_0101</font> | <font style="color:rgb(15, 17, 21);">2024-01-01 项目会议纪要.docx</font> |
| 《产品使用手册 V2.0.pdf》 | <font style="color:rgb(15, 17, 21);">product_handbook_v2</font> | <font style="color:rgb(15, 17, 21);">产品使用手册 V2.0.pdf</font> |


在发起知识库检索请求时，您可直接通过内置数据属性 doc_id 或 doc_name 添加过滤条件，实现对特定文档或文档集合的精准检索。

+ 精确检索单篇文档：通过 `关键词 + doc_id`/`关键词 + doc_name`的方式查询单个文档。
+ 联合检索多篇文档：通过 `in`操作符进行联合检索。

+ 文档名称 =“2025年第四李度财报”
+ 文档id =“ <font style="color:rgb(51, 51, 51);background-color:rgb(252, 252, 252);">20260119999def87910vOb201829121 ”</font>

+ 创建时间 早于 “ 2026-01-23”
