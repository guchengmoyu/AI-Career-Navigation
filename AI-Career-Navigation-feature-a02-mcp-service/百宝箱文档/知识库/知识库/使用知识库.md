完成知识库的创建与数据的关联后，需要将知识库关联至智能体应用才能为用户提供知识服务。本文将介绍如何使用知识库。

## 在对话型应用中使用
对于对话型应用来说，开发者需要在应用编排的过程中，在知识&技能模块添加知识库。详细说明可参见：[配置知识库](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_setting_knowledge)。

## 在工作流应用中使用
在工作流应用中，知识库以节点的形式存在。开发者需要在工作流编排页面添加知识库节点，并将其与其他节点串联。详细说明可参见：[知识库节点](https://alipaytbox.yuque.com/sxs0ba/huntb8/node_knowledge_base)。

## 通过 API 调用知识库
百宝箱提供了一系列知识库管理的 API，开发者可以按需调用，实现在三方系统中使用知识库的相关能力。详细说明可参见：[知识库 API](https://alipaytbox.yuque.com/sxs0ba/huntb8/api_datasets_create-datasets)。
