本文将介绍什么是图片知识库以及如何使用。

## 什么是图片知识库
图片知识库是百宝箱推出的新型多模态知识库类型，支持上传图片并进行图像内容识别，适用于以文搜图、以图搜图的知识库场景，实现精准图像检索。该功能基于多模态大模型技术，能够同时理解图片的视觉内容和语义信息，广泛应用于商品图库检索、设计图纸比对、文物照片识别等场景。

## 核心能力
### 双模态向量存储
每张图片上传解析完成后，系统将执行双路向量化存储：

| 向量类型 | 说明 |
| --- | --- |
| **文本特征向量** | 使用多模态模型理解图片生成图片描述或 OCR 提取图片内容信息，再通过 Text-Embedding 模型提取文本特征。 |
| **视觉特征向量** | 使用 qwen3-VL-Embedding模型提取图像视觉特征。 |


### 2. 智能检索机制
+ **以文搜图**：用户输入纯文本提问，系统提取文本向量与知识库图片的文本特征向量进行相似度匹配。
+ **以图搜图**：用户上传图片，系统提取上传图片的视觉特征向量与知识库图片的视觉特征向量进行相似度匹配。

### 3. 重排序能力
+ 对召回结果使用多模态模型Rerank进行精排，剔除视觉相似但语义不相关的图片。

### 4. 结果返回
+ 同时返回命中的图片，以及图片的内容描述或信息。

## 如何使用
### 创建图片知识库
1. 开发者访问[知识库](https://b.tbox.cn/inc/knowledge)。
2. 在知识库页面，点击**创建知识库**或点击知识库搜索框右侧的 **+ > 新建知识库**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775543082407-4550ae96-efdb-4ff4-8ff8-46fcfe689688.png" width="1535.2" title="" crop="0,0,1,1" id="u3253196f" class="ne-image">
3. 在新建知识库面板中，选择图片并配置知识库的图片、名称以及描述信息。完成后，点击右上角的**完成，**即可完成知识库的创建。

:::info
**说明：**此时，知识库数据为空，您可以通过[关联数据](https://alipaytbox.yuque.com/sxs0ba/huntb8/knowledge_bind)完成数据的填充。或者直接点击**下一步，添加数据**，完成后续步骤。 

:::

其中，各配置项说明如下：

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 知识库类型 | 是 | 选择图片，支持上传图片并进行图像内容识别，适用于以图搜图的知识库场景，实现精准图像检索。该功能基于多模态大模型技术，能够同时理解图片的视觉内容和语义信息，广泛应用于商品图库检索、设计图纸比对、文物照片识别等场景 |
| 图标与名称 | 是 | 是知识库的基础信息，独特的图标与场景化的知识库名称能够有效降低查找、维护知识库的成本。<br/>+ **图标：**创建知识库时，系统会生成默认的图标，支持开发者自行上传。<br/>+ **名称：**是知识库的唯一标识，建议保证其唯一性，最大可输入 100 字符。 |
| 描述 | 否 | 支持开发者自定义知识库的描述信息，最大可输入 600 字。 |


### 添加知识库数据
您可以通过下述方式进行图片知识库数据的添加。

#### 方式 1：在新建知识库中添加
1. 在进行新建知识库，并完成知识库基本信息的配置后，可以直接点击右上角的下一步，添加数据。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775634249860-c9a4a749-44a9-491a-ae50-20d967f97082.png" width="1094.4" title="" crop="0,0,1,1" id="u97847c07" class="ne-image">
2. 在数据添加阶段，按需选择上传数据或选择数据两种方式进行图片数据的维护。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775634389305-c9df3fcd-f225-4368-aeb1-903f31c97e27.png" width="1096" title="" crop="0,0,1,1" id="ubba7ec24" class="ne-image">

其中：

    - 上传数据：可通过点击或将文件拖拽至文件上传区域进行图片上传。
    - 选择数据：需先前往数据仓库，通过本地上传的方式进行图片上传，然后在此处进行选择关联，详细说明可参见：[上传图片数据](https://alipaytbox.yuque.com/sxs0ba/huntb8/database_create#ZTfTG)。
3. 完成数据上传后，系统将默认采用 AI 智能解析策略对您上传的图片进行解析，生成每张图片的描述信息，待解析完成后，点击右上角确认即可。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775634791706-fe14f7eb-7d58-4d1f-957b-11fd3238744f.png" width="1002.4" title="" crop="0,0,1,1" id="ucd6a1dee" class="ne-image">

#### 方式 2：在已有知识库中添加
1. 在知识库页面左侧的知识库目录中，找到并点击目标知识库名称。
2. 在知识库详情页，点击右上角的添加数据，唤起添加数据面板，进行知识库数据的维护，维护方式同[方式1](#Qx56H)。

### 维护知识库数据
在完成知识库图片添加后，百宝箱会自动执行 AI 智能解析，为每张图片生成对应的图片描述信息。您可以通过下述方式对描述信息进行手动修改，进而提升图文内容与自身业务的贴合程度。

1. 访问知识库详情页，点击目标图片的名称或操作列的编辑。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775635817416-29d4ee24-b1d9-48f5-8bf9-c06b4464610b.png" width="1536" title="" crop="0,0,1,1" id="udadf6a30" class="ne-image">
2. 在编辑图片描述信息面板的描述信息输入框中自定义描述信息后，点击右下角保存即可。

:::success
**特别提示：**

图片描述信息内容有变更后，一定要点击保存按钮。保存按钮仅会保存当前页的内容信息，故若有多张图片都修改了描述信息，需要多次保存。

:::

### 测试召回命中效果
1. 在目标知识库详情页，点击右上角的**命中测试**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775636034066-e44073dd-cc40-4918-9b57-bce85eb34654.png" width="1534.4" title="" crop="0,0,1,1" id="uf8787b2b" class="ne-image">
2. 在命中测试页面，输入源文本以及上传图片，并按需进行高级配置下各配置项的定义后，点击左下角的测试，即可在命中段落中查看命中效果。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775636205819-0a8b0307-1e8b-49b4-a69e-f388a2e2feb2.png" width="1520" title="" crop="0,0,1,1" id="u3cc0dc14" class="ne-image">

其中：

+ 仅输入源文本：可进行以文搜图的命中测试。
+ 上传图片并在源文本处输入 query：可执行以图搜图的命中测试。

### 使用知识库
1. 完成知识库的创建与维护后，您可以在智能体中进行引用，从而为智能体提供更加精准的回复参考。其中：
+ 在工作流应用中使用，可参见：[知识库节点](https://alipaytbox.yuque.com/sxs0ba/huntb8/node_knowledge_base)。
+ 在写 Prompt 应用中使用，可参见：[配置知识库](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_setting_knowledge)。
2. 在知识库节点选择完【图片知识库】后，顶部的输入项中会出现【图片链接/变量】，需进行配置，规则如下

#### 方式 2：以图搜图

+ 图片链接/变量：【开始-当前对话信息-当前对话图片-图片URL】（需打开上传开关后才有，打开方式请参考下方的**其他使用说明**的问题一）
