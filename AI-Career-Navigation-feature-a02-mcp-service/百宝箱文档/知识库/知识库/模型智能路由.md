本文将介绍什么是模型智能路由及如何在知识库中配置过程中进行使用。

## 什么是模型智能路由
在百宝箱，模型智能路由是知识库中的一项高级能力。它基于大语言模型对用户意图的理解能力，自动分析用户问题与知识库内个文件的标题、描述等信息之间的关联性，从而动态筛选并锁定最相关的特定文档，并仅从该文档中提取知识。

### 功能介绍
在传统知识检索模式下，用户需要手动指定查询范围，以提升准确性。而模型智能路由通过引入大模型的语义理解能力，在用户未明确限定查询文件的情况下，自动完成相关文档的识别与聚焦。能够在大量相似文档中准确定位并匹配最优的知识内容，有效避免信息干扰，显著提升回答的准确性、纯净度与响应效率。

### 核心优势
+ **自动关联匹配：**无需用户手动选择文件，系统自动判断最相关文档。
+ **提升回答质量：**仅从高度相关的单一或有限文档中提取答案，减少噪声。
+ **增强用户体验：**简化操作流程，实现“问即所得”的自然交互体验。



智能路由适用于知识库中存在大量结构或主题相似但内容迥异的文档场景，是构建高效、智能知识服务系统的关键能力之一。

## 应用示例
为直观展现模型智能路由功能的价值，下文以“家庭旅行规划师”为典型应用场景，通过一个关于杭州灵隐寺的常见提问，对比启用智能路由前后的系统响应差异。

在家庭旅行规划场景中，用户常需从多份结构相似但地域不同的旅游攻略中获取精准信息。若知识库中存在多份主题相近的文档，传统检索方式易引入干扰内容，而模型智能路由则可显著提升答案的准确性与用户体验。

### 知识库文档概览
假设杭州旅游推荐的知识库中含有一下三份高度结构化但目的地不同的杭州旅行攻略：

+ **文档 A，杭州西湖经典三日游：**聚焦西湖景区、灵隐寺、龙井村等核心景点，含详细交通与美食推荐。
+ **文档 B，千岛湖亲自休闲四日游：**主要介绍千岛湖环湖骑行、水上项目及周边民宿，适用于家庭度假。
+ **文档 C，浙西天目山生态徒步指南：**侧重天目山自然步道、露营地及山区交通提示，面向户外爱好者。

三份文档均包含相似的“行前准备”内容（如证件、天气、必备物品等），但核心行程、景点与本地推荐各不相同。

### 用户提问
当用户提问：“去灵隐寺怎么坐车比较方便？附近有什么推荐的素斋或杭帮菜？”

### 模型智能路由的核心价值
| 场景痛点 | 模型智能路由带来的价值 |
| --- | --- |
| 知识库中存在多份结构相似但地域/主题不同的攻略文档。 | **AI 自动选源**：基于语义理解，精准识别问题所指的具体目的地（如“灵隐寺” → 西湖区域 → 文档A），无需用户了解内部文档结构。 |
| 传统关键词检索返回大量重复或跨地域的干扰信息。 | **结果纯净聚焦**：仅从最相关文档提取答案，杜绝无关内容污染，提升信息可信度与决策效率。 |
| 普通用户难以判断应查询哪份攻略（如不清楚灵隐寺属于哪条线路）。 | **使用零门槛**：用户像与真人导游对话一样自然提问，系统自动完成“路由”到正确知识源的全过程。 |


在家庭旅行规划等高信息密度场景中，模型智能路由不仅是一项技术优化，更是用户体验的关键升级——让精准答案“主动找到用户”，而非让用户在海量文档中“大海捞针”。

## 如何使用
:::info
**说明：**

模型智能路由在运行过程中，AI 需要分析文件的标题名称、描述等信息与用户问题间的关联性，在使用前，请确保为每份文档取一个**合适的名称**以及**适当的描述**信息。

:::

### 步骤 1：调整文件名称与描述
按照产品的具体型号或内容的核心概要为文件重新命名。例如：

+ `iPhone17 产品说明书`
+ `2025 年员工出勤统计表`

### 步骤 2：选择模型智能路由
在知识库节点的配置面板中，在**按类目批量选择** tab 下选择**模型智能路由**的路由方式。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1775552075224-ab5bfb3d-e39f-4368-88a2-d3d6241e0094.png" width="1528" title="" crop="0,0,1,1" id="ud48d49be" class="ne-image">
