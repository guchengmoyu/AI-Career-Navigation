数据仓库是百宝箱核心的数据管理模块，用于统一管理您上传的各类原始文档。它位于知识管理架构的底层——**数据准备层**，专注于原始文件的接入、解析与结构化处理，为后续的知识库的构建提供高质量的数据基础。本文将介绍什么是数据以及如何在数据仓库进行数据管理。

## 什么是数据
数据仓库中的数据来源于您所上传的文档。系统会对文档进行智能解析与语义切分，并将其转换为向量形式，使大语言模型能够从语义层面精准理解内容，并高效检索相关信息。处理后的知识资产可灵活应用于多种业务场景，显著提升知识管理与复用效率。

:::info
**说明：**数据本身并不直接参与 AI 问答或检索，而是作为可复用的内容资源，供后续构建知识服务使用。

:::

## 功能特性
+ **多类型支持**：兼容非结构化文档与结构化表格，满足多样化知识形态。
+ **多场景复用**：处理后的数据可被智能体、插件、卡片消息等场景复用，避免重复解析。
+ **灵活上传**：支持本地上传、模板导入、在线编辑与 API 对接，适用于不同的使用习惯与集成需求。
+ **状态透明**：提供处理进度、分段数量、文本预览等信息，便于监控与核对。
+ **高效稳定**：基于百宝箱底层引擎，保障各类文件的解析质量与处理性能。

## 文件上传
### 支持的文件类型与上传方式
您可以在数据仓库上传结构化数据与非结构化数据，系统根据数据类型设置了相应的格式与大小限制，以保障数据处理效率与稳定性。

#### 文档数据
适用于包含自由文本、段落、标题等内容的文档，如报告、手册、文章等。

+ **支持的格式：**DOCX、PDF、TXT、MD
+ **上传限制：**
    - 单次上传最多 10 个文件。
    - 每个文件不超过 10MB。
    - PDF文件不超过 300 页，超出 300 页的部分将不会进行解析。
+ **上传方式：**本地文件上传（支持拖拽或点击选择）

#### 表格数据
适用于表格类数据，系统将默认使用第一行数据识别表结构，从而自动判断数据类型，并保留字段语义信息，适用于 FAQ、产品参数表等场景。

+ **支持的格式：**CSV、XLSX
+ **上传限制：**
    - 单次仅支持上传 1 个文件。
    - 文件大小不超过 20M。
+ **上传方式：**
    - **本地文件上传**：上传符合格式要求的 CSV 或 XLSX 文件。
    - **自定义数据表：**先定义数据结构（即表头），再基于模板进行数据维护。
    - **API 接口上传：**通过调用开放 API 实现自动化数据同步。

#### 图片数据
适用于以图搜图的知识库场景，实现精准图像检索。该功能基于多模态大模型技术，能够同时理解图片的视觉内容和语义信息，广泛应用于商品图库检索、设计图纸比对、文物照片识别等场景。

+ 支持的格式：JPG、JPEG、PNG
+ 文件大小限制：每个图片文件不超过 20 MB
+ 文件数量：无数量限制
+ ****本地文件上传（支持拖拽或点击选择）

支持开发者预先创建一个自定义数据表，并定义数据结构，需要包含字段名称、字段描述、数据类型、字段默认值、是否必填、是否进行唯一性校验等配置。例如：

#### API 上传
对于需要与业务系统集成的场景，百宝箱提供标准的 RESTful API 接口，支持将外部系统的结构化数据自动同步至数据仓库中。

关于 API 上传的详细说明可参见：[API 同步](https://alipaytbox.yuque.com/sxs0ba/huntb8/api_knowledge_create-document)。

## 文件处理
上传或录入完成后，系统将自动执行以下处理流程：

| 处理阶段 | 说明 |
| --- | --- |
| 内容解析 | 提取文本内容，保留段落结构（非结构化）或字段映射关系（结构化）。 |
| 智能分段 | 根据语义或表格行/列结构，切分为逻辑完整的文本片段。 |
| 编码预处理 | 清理特殊字符、冗余空格等，提升后续处理的准确性。 |


处理完成后，您可在数据列表中查看处理状态、文本预览及分段详情。
