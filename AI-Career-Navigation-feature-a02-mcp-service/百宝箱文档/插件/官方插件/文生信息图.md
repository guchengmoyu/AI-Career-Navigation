AntV 文生信息图可将你的文本智能转化为专业信息图，支持文章配图、PPT、社交媒体分享等场景。

支持七大类信息图：数据类（饼图、折线图、柱状图等，展示数据分布与趋势）、时序类（时间线、路线图，展示时间顺序）、比较类（对比、排序、利弊分析等，突出差异）、原因分析类（根因图，剖析问题根源）、流程类（漏斗、步骤图等，展示流程变化）、结构层次类（金字塔、分支、象限等，表现多层级结构）及其它类（对话图、挖掘图等）。



# 输入参数
| **参数名称** | **是否必填** | **类型** | **说明** |
| --- | --- | --- | --- |
| text | 是 | String | 生成信息图的文本 |
| beforeContext | 否 | String | 生成信息图文本的上文 |
| afterContext | 否 | String | 生成信息图文本的下文 |
| dynamicTheme | 否 | Boolean | 是否开启动态主题，true 则动态生成色板和背景色，默认 false |
| imgOptions | 否 | Object | 图片配置，配置图片清晰度和图片格式；默认参数 { devicePixelRatio: 2, // 图片清晰度，format: 'jpeg' // 图片格式，默认jpeg, 传 png 则生成透明背景的图片 } |
| imgOptions.devicePixelRatio | 否 | Number | 图片清晰度，默认 2 |
| imgOptions.format | 否 | String | 图片格式，参数支持 jpeg、png，默认jpeg，传 png 生成透明背景的图片 |




# 输出参数
| **参数名称** | **类型** | **说明** |
| --- | --- | --- |
| code | Number | 状态码 |
| message | String | 状态信息 |
| success | Boolean | 信息图生成结果 |
| data | Array | 图片数组 |
| data.imgUrl | String | 图片地址，CDN 地址 |
| data.id | String | 信息图标识 |
