# 前置条件
1. 在百宝箱上需要有一个工作流应用的智能体
2. 插件需要发布上线
3. 新接入应用，请看第二版

# 第一版：操作步骤
1. 在智能体应用工作流中，将旅游规划插件添加到工作流中
2. 链接各个节点
3. 引入引用，加入固定值：<font style="color:#DF2A3F;">xxxxxx，</font>
    1. <font style="color:#DF2A3F;">该token值： xxxxxxxx 只适用于 第一期接入的主智能体应用</font>
4. 添加输入项，输出文本内容
5. 添加输入项，输出卡片消息
6. 添加追问消息

# 第二版：操作步骤
1. 需要去通过管控平台注册，获取bearToken，应用solmcpserverhub，owner：浮霜

[智能体接入流程管控平台SOP](https://yuque.antfin.com/iwc-all/atlas/pk40pxwzdqycgeon)

2. 需要重新拉取一个插件节点，重复第一版的操作步骤。
3. <font style="color:#DF2A3F;">token 传入值为 管控平台返回的bearToken</font>
4. 传入bizCode, 建议bizCode 为 通俗易懂的代表应用的一个标识，方便后续统计访问量
5. 相对于第一版，多加了一个参数 bizCode（可传可不传）, bizCode主要作用是为了可以区分是哪些智能体应用调用了旅行规划插件，方便后续统计该智能体应用调用旅行规划的pv。
