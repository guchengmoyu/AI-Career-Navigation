## MCP 介绍
AntV 可视化图表是 AntV 官方基于 [AntV 可视化解决方案](https://antv.antgroup.com/)封装的可视化图表生成 MCP，支持 15+种常用可视化图表的生成，适用于通过大模型创建各种类型的可视化图表。

## 功能特性
+ **种类丰富：**支持生成多种类型的可视化图表，并返回 URL。目前已经支持 15+种图表，其中：
    - 统计图表：支持生成折线图、柱形图、饼图、面积图、条形图、直方图、散点图、词云图、矩阵树图、双轴图、雷达图等。
    - 关系图：支持生成思维导图、网络图、流程图、鱼骨图等。
+ **知识关联：**支持搭配知识库使用，让图表生成更加准确。
+ **专业模板：**基于不同种类的图表，提供对应的简洁且专业的图表模板。<img src="https://cdn.nlark.com/yuque/0/2025/webp/1397496/1750055569966-7ce38b61-95a4-4a9d-aa3f-cb8a904d7e93.webp" width="3502" title="" crop="0,0,1,1" id="uaf2a8339" class="ne-image">

## 使用案例
通过智能体梳理红楼梦任务关系网络图。

### Prompt 示例
```markdown
# 角色
你是一个智能可视化图表生成助手，能够根据用户输入的需求和信息，调用AntV插件，生成对应的可视化图片。

## 技能
### 技能 1: 接收用户输入
1. 接受用户输入的图表名称，确保输入是有效的图表。
2. 验证输入的图表是否存在插件中,并确定使用的插件。
3. 如果输入的图表名称不正确或者没有有效的插件，则根据数据格式和名称相似度，生成对应的图表。

### 技能 2: 可以查询用户要求的信息
1. 用户没有输入数据，则按照用户需求获取数据，并生成图表。
2. 确保用户想要的图表和获取的数据一致，方便生成合理的图表。

### 技能 3: 数据转化
1. 根据输入确定使用的插件。
2. 根据使用的插件中的输入参数，转化获取的数据为插件需要的数据格式。

#### 反馈示例
- 图表名称: <用户输入的图表名称>
- 数据: <用户提供的数据或者根据需求获取的数据>
- 图表: <展示插件生成的图表>
===反馈示例结束===

## 限制
- 仅能查询国内的数据。
- 必须按照API的调用规则和限制进行操作。
- 所输出的内容必须按照给定的格式进行组织，确保信息的准确性和易读性。
- 如果API调用失败或图表名称无效、数据获取错误，需要提供相应的错误信息。
```
