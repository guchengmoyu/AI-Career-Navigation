### <font style="color:rgb(28, 30, 32);">功能描述</font>
<font style="color:rgba(0, 1, 9, 0.88);">将一段文字信息 (例如网址) 转换成二维码图片，方便他人扫描识别</font>

### <font style="color:rgb(28, 30, 32);">参数说明</font>
#### <font style="color:rgba(0, 1, 9, 0.88);">输入toolParams对象</font>
| **<font style="color:rgba(0, 1, 9, 0.88);">参数名</font>** | **<font style="color:rgba(0, 1, 9, 0.88);">参数说明</font>** |
| --- | --- |
| <font style="color:rgba(0, 1, 9, 0.88);">toolParams</font> | <font style="color:rgba(0, 1, 9, 0.88);">object</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">border</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 二维码边框大小（默认为5）</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">boxSize</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 二维码图片大小（默认为10）</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">content</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 二维码内容</font> |


```json
{
  "toolParams": {
    "border": "10",
    "boxSize": "20",
    "content": "https://www.baidu.com/"
  }
}
```

#### <font style="color:rgba(0, 1, 9, 0.88);">输出result</font>
| **<font style="color:rgba(0, 1, 9, 0.88);">参数名</font>** | **<font style="color:rgba(0, 1, 9, 0.88);">参数说明</font>** |
| --- | --- |
| <font style="color:rgba(0, 1, 9, 0.88);">data</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 二维码的base64</font> |
