### <font style="color:rgb(28, 30, 32);">功能描述</font>
<font style="color:rgba(0, 1, 9, 0.88);">了解指定地点的实时天气详情，包括温度、风向、AQI、湿度、风力等级和天气状况等信息</font>

### <font style="color:rgb(28, 30, 32);">参数说明</font>
#### <font style="color:rgba(0, 1, 9, 0.88);">输入toolParams对象</font>
| **<font style="color:rgba(0, 1, 9, 0.88);">参数名</font>** | **<font style="color:rgba(0, 1, 9, 0.88);">参数说明</font>** |
| --- | --- |
| <font style="color:rgba(0, 1, 9, 0.88);">toolParams</font> | <font style="color:rgba(0, 1, 9, 0.88);">object</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">location</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 地址，仅支持城市（举例：山东、青岛市北区、山东省青岛市市北区水清沟街道九江路）</font> |




```json
{
  "toolParams": {
    "location": "杭州"
  }
}
```

#### <font style="color:rgba(0, 1, 9, 0.88);">输出result</font>
| **<font style="color:rgba(0, 1, 9, 0.88);">参数名</font>** | **<font style="color:rgba(0, 1, 9, 0.88);">参数说明</font>** |
| --- | --- |
| <font style="color:rgba(0, 1, 9, 0.88);">city</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 城市</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">future</font> | <font style="color:rgba(0, 1, 9, 0.88);">list · 近期天气情况</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">realtime</font> | <font style="color:rgba(0, 1, 9, 0.88);">object · 天气实况</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">future.date</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 日期 yyyy-mm-dd</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">realtime.aqi</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 空气质量指数，可能为空</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">future.direct</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 风向</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">realtime.info</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 天气情况，如：晴、多云</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">future.weather</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 天气情况</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">realtime.power</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 风力，可能为空</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">realtime.direct</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 风向，可能为空</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">realtime.humidity</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 湿度，可能为空</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">future.temperature</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 温度，最低温/最高温</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">realtime.temperature</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 温度，可能为空</font> |
