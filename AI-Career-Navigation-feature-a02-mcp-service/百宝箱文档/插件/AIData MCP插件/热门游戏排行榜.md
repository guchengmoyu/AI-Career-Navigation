### <font style="color:rgb(28, 30, 32);">功能描述</font>
<font style="color:rgba(0, 1, 9, 0.88);">热门游戏排行榜服务，支持分页查询不同类型游戏的排名、名称、简介及缩略图链接</font>

### <font style="color:rgb(28, 30, 32);">参数说明</font>
#### <font style="color:rgba(0, 1, 9, 0.88);">输入toolParams对象</font>
| **<font style="color:rgba(0, 1, 9, 0.88);">参数名</font>** | **<font style="color:rgba(0, 1, 9, 0.88);">参数说明</font>** |
| --- | --- |
| <font style="color:rgba(0, 1, 9, 0.88);">toolParams</font> | <font style="color:rgba(0, 1, 9, 0.88);">object</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">type</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 查询榜单类型：1、网游榜单；2、手游榜单；3、单机榜单</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">pageNo</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 页码，默认第一页</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">pageSize</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 页大小，默认为10</font> |


```json
{
  "toolParams": {
    "pageNo": "1",
    "pageSize": "10",
    "type": "1"
  }
}
```

| --- | --- |
| <font style="color:rgba(0, 1, 9, 0.88);">rank</font> | <font style="color:rgba(0, 1, 9, 0.88);">list · 榜单数据</font> |

| <font style="color:rgba(0, 1, 9, 0.88);">pageSize</font> | <font style="color:rgba(0, 1, 9, 0.88);">number · 页大小</font> |
| <font style="color:rgba(0, 1, 9, 0.88);">rank.desc</font> | <font style="color:rgba(0, 1, 9, 0.88);">string · 简介</font> |
