### <font style="color:rgb(28, 30, 32);">功能描述</font>
<font style="color:rgba(0, 1, 9, 0.88);">基于给定日期，提供的全面农历和黄历信息查询，包括传统中国黄历中的吉凶宜忌、节气节日等</font>

| --- | --- |
| <font style="color:rgba(0, 1, 9, 0.88);">toolParams</font> | <font style="color:rgba(0, 1, 9, 0.88);">object</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">date</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 类型 1：yyyy-mm-dd；类型 2：yyyy-mm；类型 3：yyyy</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">type</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 类型1：返回天数据；类型2：返回月数据；类型3：返回年数据</font> |

{
  "toolParams": {
    "date": "2025-10-01",
    "type": "1"
  }
}
