### <font style="color:rgb(28, 30, 32);">功能描述</font>
<font style="color:rgba(0, 1, 9, 0.88);">支持2023年及以后国内重要节日查询，放假及调休信息查询。明年的放假及调休信息一般在当年的10或者11月公布存在延迟。</font>

### <font style="color:rgb(28, 30, 32);">参数说明</font>
#### <font style="color:rgba(0, 1, 9, 0.88);">输入toolParams对象</font>
| **<font style="color:rgba(0, 1, 9, 0.88);">参数名</font>** | **<font style="color:rgba(0, 1, 9, 0.88);">参数说明</font>** |
| --- | --- |
| <font style="color:rgba(0, 1, 9, 0.88);">toolParams</font> | <font style="color:rgba(0, 1, 9, 0.88);">object · 参数</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">to</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 查询结束日期。eg:2025-09-21</font> |
| + <font style="color:rgba(0, 1, 9, 0.88);">from</font> | + <font style="color:rgba(0, 1, 9, 0.88);">string · 查询开始日期。eg:2025-03-21</font> |


```json
{
  "toolParams": {
    "from": "2025-03-21",
    "to": "2025-09-21"
  }
}
```

| --- | --- |
| <font style="color:rgba(0, 1, 9, 0.88);">isHoliday</font> | <font style="color:rgba(0, 1, 9, 0.88);">boolean · 是否放假</font> |

| <font style="color:rgba(0, 1, 9, 0.88);">holidayDates</font> | <font style="color:rgba(0, 1, 9, 0.88);">list · 放假日期</font> |
