## 什么是应用
在百宝箱中，**应用是构建和运行智能体的核心载体**。依托业界领先的大模型技术，百宝箱显著缩短智能体应用的开发周期，大幅降低技术门槛，让开发者更高效地打造智能化服务。

平台支持在应用编排过程中**灵活集成大语言模型能力**，并可无缝融合插件、知识库、交互式卡片等多种资源，实现功能扩展与服务能力增强。通过多模态能力的协同调度，智能体在响应用户查询、执行复杂任务等场景中表现更精准、行为更可控，全面贴合业务预期。

百宝箱智能体应用具备**多端适配能力**，天然兼容移动端与网页端，并可通过标准 API 或 SDK 与企业自有系统深度集成。同时，平台还提供 IoT SDK，支持智能体在各类终端设备上运行。此外，您还可将应用一键发布为支付宝小程序、微信小程序或钉钉机器人，快速触达目标用户，提升服务覆盖效率。

## 功能特性
百宝箱提供不同维度的应用能力，支持开发者构建更加符合自身业务场景与用户预期的应用。

### 模型选择
百宝箱集成多款业内主流大模型供开发者进行选择，并支持根据业务场景进行参数调整，如：多样性、top-p 采样以及最大推理生成长度等。开发者可以根据用户需求以及应用场景，进行参数调试，使应用本身拥有更优秀的对话效果。其中：

+ **多样性：**用于调节输出的随机性。降低多样性会使模型生成更确定、一致的回答；增加多样性则让模型尝试更丰富、意想不到的内容。
+ **top-p 采样：**用于确定生成文本时所考虑的最可能词汇的筛选阈值。例如，如果设为0.1，则模型会从概率超过0.1的词汇中选择下一个词，以平衡相关性和创造性。提高top-p可增加文本多样性，降低则使内容更连贯。
+ **最大推理生成长度：**用于控制模型输出长度，可根据需要调整。不同用途的文本可能需要不同推理生成长度设置。

### 搭建能力
在百宝箱，开发者可以使用知识库、工作流（子）及插件等资源解决应用在与用户交互过程中产生的模型幻觉、专业领域知识不足的问题。

| 能力点 | 说明 |
| --- | --- |
| [知识库](https://alipaytbox.yuque.com/sxs0ba/huntb8/knowledge_overview) | 支持对内容片段进行检索和召回，大模型会根据召回的内容生成应用最终的回复内容，适用于知识问答等场景。 |
| [插件](https://alipaytbox.yuque.com/sxs0ba/huntb8/sygodswszgc6o81n) | 指以 API 或多模态模型的形式，用于拓展应用的能力边界的工具集。<br/>百宝箱已集成包括咨询阅读、旅游出行、效率办公等多种场景的插件，开发者可以按需使用。<br/>同时，若现有插件无法满足您的个性化诉求，百宝箱还提供自定义插件的能力供开发者使用 |
| [工作流节点](https://alipaytbox.yuque.com/sxs0ba/huntb8/sub-workflow_overview) | 工作流节点是百宝箱推出的特色能力，支持开发者将已经封装完成的业务逻辑以子工作流节点的形式集成到当前的业务流程中。有效降低业务开发与维护成本的同时，进一步增强业务的扩展性。 |


### 对话配置
对话配置是能够影响用户在使用智能体过程中交互体验的配置能力，包含开场白、提问建议、联网搜索等能力，详细说明见下表。

| 能力点 | 说明 |
| --- | --- |
| [开场白](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_setting_welcome) | 设置应用的开场语，帮助用户快速了解应用的核心功能。例如 `我是一个读书推荐智能体应用，能帮你获取并推荐书籍信息。` |
| [用户问题建议](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_setting_user-intent) | 应用每次回复后，对用户提问进行引导建议，从而引导用户进行深入互动。支持：<br/>+ 默认建议：根据对话内容自动提供 3 条建议。<br/>+ 自定义建议：根据编写的提示词，提供最多 3 条建议。 |
| [文件上传](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_setting_multimodal) | 支持开发者通过控制文件上传的开关，来选择是否为智能体添加包括文档、图片、视频、音频上传的多模态交互能力。 |
| [联网搜索](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_setting_search-engine) | 使应用拥有实时联网搜索能力，能够为用户提供最新的信息和数据。 |
| [聊天背景图片](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_setting_background) | 为应用设置背景图片，在与用户对话过程中展示，从而增强沉浸感，提升用户体验。 |
| [底纹词](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_setting_placeholder) | 支持设置应用聊天输入框中的引导语，帮助用户明确输入内容。 |
| [快捷指令](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_setting_command) | 快捷指令是指预置在智能体应用对话框上访的快捷按钮，用户点击按钮即可发送其中预置的 query 发起对话或跳转至其中预置的外部链接。 |


### 卡片设计
在百宝箱，卡片是智能体消息展示的核心呈现形式之一。通过灵活的卡片设计，开发者可自定义消息的布局与样式，打造契合业务场景的专属交互界面，有效提升用户沟通体验与信息获取效率。

### 运维能力
**应用构建开发阶段**

开发者可通过运行调试面板与应用进行实时对话。开发者可及时评估应用在对话中的响应表现（如回复内容的准确性、逻辑性、响应速度等），并对提示词、流程逻辑或配置参数进行针对性优化与调整，从而持续提升应用质量与用户体验。详细说明可参见：[调试应用](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_debug)。

**应用上线运维阶段**

开发者可通过数据中心以及用户管理，全面了解已发布智能体的使用情况，包括对话人数、次数、时长、用户留存等数据。并通过数据中心提供的可视化数据分析能力，不断优化智能体，从而提升用户的体验与用户转化。

### 多端发布
百宝箱支持将应用一键发布至多个渠道，包括支付宝智能体、支付宝小程序插件、微信生态、Web 服务、SDK 集成以及行业应用模板等，实现多端联动与统一部署。通过全渠道覆盖，助力企业提升智能体的触达范围与用户曝光，加速用户增长，并有效提升运营效率与服务体验。详细说明可参见：[发布应用](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_release)。
