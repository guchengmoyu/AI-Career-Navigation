本文默认您没有支付宝小程序开发经验且尚未创建支付宝小程序，将从 0 到 1 为您介绍如何创建支付宝小程序项目并进行智能体接入。

## 前提条件
+ 在进行智能体接入前，请先完成百宝箱智能体应用的创建与编排，若无，请参见：[新建应用](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_new)，完成相关操作。

## 操作步骤
### 步骤 1：注册支付宝开发者账号
开发者登录[支付宝开放平台](https://open.alipay.com/)，若您尚未注册相关账号，可根据[支付宝官方文档-开发者账号注册](https://opendocs.alipay.com/mini/introduce/register?pathHash=d7e497fd)完成相关操作。

### 步骤 2：创建支付宝小程序
创建小程序是指在支付宝开放平台上创建一个全新的小程序，并完成小程序命名、生成对应的小程序 Appid 的前置步骤。详细说明可参见：[支付宝官方文档-创建小程序](https://opendocs.alipay.com/mini/introduce/create?pathHash=a4aca438)。

### 步骤 3：下载小程序开发者工具
小程序开发者工具是支付宝开放平台打造的一站式小程序研发工具，提供了编码、调试、测试、上传、项目管理等功能。同时，智能体接入的相关工作需要在该工具中进行，其中：

+ 工具下载：[点击此处](https://opendocs.alipay.com/mini/ide/download)进行下载。
+ 工具使用说明：[请参见支付宝官方文档-工具概述](https://opendocs.alipay.com/mini/ide/overview?pathHash=4da33275)。

### 步骤 4：新建小程序项目
1. 本地启动小程序开发者工具。
2. 在工具中，点击小程序项目 > 小程序下的 +，进行小程序项目创建。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770197692472-207d35a3-0900-4cdd-a594-c7d56ccc9d10.png" width="1000" title="" crop="0,0,1,1" id="u9ebc273c" class="ne-image">
3. 在选择端过程中，选择支付宝，点击下一步。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770197771872-07beb10c-8566-4907-8ad3-bd133d2ef643.png" width="996.8" title="" crop="0,0,1,1" id="ubb384268" class="ne-image">
4. 在选择模板过程中，选择空白模板，并点击下一步。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770197838709-ecf700f8-0c77-4027-9fcc-660b564ab03b.png" width="1000" title="" crop="0,0,1,1" id="ufd3b367f" class="ne-image">
5. 在新建小程序项目过程中，完成项目名称、路径以及框架语言的选择后，点击完成。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770197976851-60d58094-9b37-490a-a69a-557feb421076.png" width="1000.8" title="" crop="0,0,1,1" id="u03729cda" class="ne-image">

此时，一个空白的小程序项目就搭建完成了。

### 步骤 5：订阅百宝箱在支付宝平台发布的官方插件
1. 开发者访问[百宝箱通用智能体小程序插件详情页](https://b.alipay.com/page/fw-market/home/detail/AM010401000000153126)。
2. 在服务详情页，点击**立即订阅**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770194262058-25882770-a5e6-4f44-b4a3-999ea5a5603b.png" width="2026.4" title="" crop="0,0,1,1" id="ubf13db0a" class="ne-image">
3. 在订购应用信息确认页，选择与插件绑定的小程序并完成联系人信息填写后，点击**授权并订购**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1768964788448-180c2b39-9f02-4ae0-9ff9-7b4e5d3c2925.png" width="1253.6" title="" crop="0,0,1,1" id="uef83c200" class="ne-image">
4. 完成支付订单的确认后，即可完成订阅。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1768964879618-8a989fb8-4e57-47f1-a8e3-811d1c952c1e.png" width="637.6" title="" crop="0,0,1,1" id="ud49347e4" class="ne-image">

### 步骤 6：配置项目
在本地启动小程序开发者工具，打开由[步骤 4 ](#LT0uF)创建的小程序项目，并修改项目文件，实现百宝箱官方插件注册。

#### 注册插件
修改项目根目录下的 `app.json`文件，绑定当前项目与步骤 5 中订阅百宝箱官方插件，代码示例如下。

```json
{
  "plugins": {
    "myPlugin": {
      "version": "*",
      "provider": "2021005182605430" //百宝箱插件appid
    },
  }
}
```

:::info
💡 **说明**：provider 为插件提供方的 AppID，注册百宝箱官方插件时，固定为 `2021005182605430`。

:::

#### 绑定百宝箱智能体
修改项目中 `page/index.js`文件，实现项目与智能体的绑定，代码示例如下。

```javascript
Page({
  onLoad(query) {
    my.redirectTo({
      url: 'plugin://myPlugin/chat-page?agent_id=百宝箱应用id'
    })
  },
});

```

:::info
💡 **说明**

开发者可通过下述方式快速获取百宝箱 agent_id：

+ 访问百宝箱应用编排页，在浏览器地址栏中获取。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1771919801758-da1cbd33-f9f8-4eca-8ca8-b17d68221535.png" width="1533.6" title="" crop="0,0,1,1" id="uf92a118f" class="ne-image">
+ 在应用发布的配置页的应用信息中获取。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770200130182-1c295b3d-bfb9-41c3-8aa7-2e4c1cf4c5c4.png" width="1521.6" title="" crop="0,0,1,1" id="u37cf403b" class="ne-image">

:::

#### 修改页面内容
修改项目中 `page/index.axml`文件，定义页面的展示内容，本文以展示空白界面为例，您可按需定义。

```xml

```

### 步骤 7：上传并发布项目代码
完成上述配置后，点击左上角的关联应用选择，选择由步骤 2 创建的小程序，并点击小程序开发者工具中的上传版本，完成代码推送。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770199252692-d8d9f5fa-cce9-4ac6-9d4b-9a8341a33e6c.png" width="1534.4" title="" crop="0,0,1,1" id="u12f6a717" class="ne-image">

上传成功后，根据页面提示完成项目提审。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1770199697354-157db140-8ce5-4a71-aef9-737bbf94cfe3.png" width="1537.6" title="" crop="0,0,1,1" id="u0d796b59" class="ne-image">

通过上述步骤，您已经完成了小程序账号注册、项目创建、插件注册以及智能体的绑定，最终将项目推送到线上，供用户使用。
