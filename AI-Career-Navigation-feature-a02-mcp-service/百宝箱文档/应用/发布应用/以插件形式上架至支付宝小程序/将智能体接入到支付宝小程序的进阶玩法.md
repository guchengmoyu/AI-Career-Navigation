本文将介绍在将百宝箱智能体接入支付宝小程序过程中的一些高级玩法（如动态引入插件、定制智能体对话页面、引入百宝箱卡片等），帮助开发者进一步提升小程序的对客表现。

## 前提条件

## 高阶玩法 1：动态引入插件
在订阅百宝箱官方提供的小程序插件后，我们可以通过下述代码实现插件的静态注册。

```json
{
  "plugins": {
    "myPlugin": {
      "version": "*",
      "provider": "2021005182605430" //插件appid
    },
  }
}
```

在考虑到性能问题的时候，可以考虑使用如下所示的动态引入方案。

```javascript
Page({
  data: {
    isReady: false
  },
  onLoad(query) {
    // 页面加载
    console.info(`Page onLoad with query: ${JSON.stringify(query)}`);

    my.loadPlugin({
      plugin: '2021005182605430@*', // 指定要加载的插件 ID 和版本号，为 * 时自动选择版本
      success: () => {
        const plugin = requirePlugin('dynamic-plugin://2021005182605430');        
        this.setData({ isReady: true }); // 插件已加载，可以渲染插件组件了
      },
    });
  },  
  handlerClick(){  
    // 进入插件首页
    my.navigateTo({
      url: 'dynamic-plugin://2021005182605430/chat-page?agentId=百宝箱应用id',
    });
    // 进入插件自动发起提问
    // my.navigateTo({
    //   url: 'dynamic-plugin://2021005132616548/chat-page?agentId=百宝箱应用id&query=你好',
    // });
  }
});
```

### 添加用户身份认证
用户身份是智能体中非常重要的信息，小程序插件默认会获取当前使用支付宝小程序的用户支付宝open_id传入到百宝箱工作流中，开发者可在工作流中根据用户ID参数做相关业务处理。

如果业务项目中需要传入小程序主体自身的用户身份信息，可接入Auth身份认证，详细说明可参见：[Auth身份认证介绍](https://alipaytbox.yuque.com/sxs0ba/huntb8/qt7b0r4iaydeqf8h)。

### 插件回跳宿主小程序配置
> 参考文档：[https://opendocs.alipay.com/mini/plugin/plugin-development?pathHash=40489346#%E6%8F%92%E4%BB%B6%E9%A1%B5%E9%9D%A2%E8%B7%B3%E8%BD%AC](https://opendocs.alipay.com/mini/plugin/plugin-development?pathHash=40489346#%E6%8F%92%E4%BB%B6%E9%A1%B5%E9%9D%A2%E8%B7%B3%E8%BD%AC)
>

通过宿主小程序在`onLaunch`里**暴露方法给插件**的方式，来支持从插件中回跳到宿主小程序页面，这样的好处是**可支持从跳转后的页面返回到上一个页面**，而不是回到支付宝首页

```typescript
App({
  onLaunch(options){
    // onLaunch中将宿主的 navigateTo 包装后传递给插件
    const plugin=requirePlugin('myPlugin');
    plugin.setAppNavigater((options)=>{
      // 这里可以进行逻辑校验
      my.navigateTo(options);
    });
  },
});
```

### 实现自定义容器组件
为了降低代码**接入成本**，可实现一个容器组件，将容器组件传递给智能体插件，智能体插件会传入一个`cardData`属性，容器组件可根据`cardData.card_id`去判断该渲染哪一个组件

```xml
<view>
  <!-- 自定义开场白欢迎卡片 -->
  <custom-card-1
    a:if="{{ cardData.card_id === '2025xxx0' }}"
    cardData="{{cardData}}"
    />
  <!-- 自定义回答卡片 -->
  <custom-card-2
    a:if="{{ cardData.card_id === '2025xxx1' }}"
    cardData="{{cardData}}"
    />
</view>
```

```json
{
  "component": true,
  "usingComponents": {
    "custom-card-1": "../custom-card-1/index",
    "custom-card-2": "../custom-card-2/index"
  }
}
```

```vue
Component({
  props: {
    cardData: {},
    bridgeAPI: {},
  },
  data: {},
  methods: {},
});
```

#### 自定义组件接收参数
#### cardData
下发的卡片数据，数据结构在百宝箱平台自定义卡片中配置。

#### bridgeAPI
为了实现 用户自定义的 小程序组件卡片与智能体对话环境的交互，目前提供了多种常用功能，如 发起query、页面跳转等。详细见：

| 属性/方法 | 说明 | 类型 |
| --- | --- | --- |
| openScheme | 跳转三方小程序/宿主小程序/h5 | `(params: { scheme, success, fail })=>void` |
| sendQuery | 发送query，（`question_content`是query词, `biz_extra_params`是业务扩展参数，随query一起发送）,第二个可选配置参数支持传递`hidden`控制发送query后隐藏提问问题 | `(queryObj: { question_content, biz_extra_params: {} }, params: {query_hide: boolean})=>void`<br/>参数说明：<br/>接收两个参数，都是对象，第一个参数接收两个属性：<br/>+ `question_content`是发送消息文字，必传<br/>+ `biz_extra_params`是扩展参数，非必传，传入后可在工作流开始节点自定义参数获取到<br/><img src="https://cdn.nlark.com/yuque/0/2025/png/49692699/1756957535159-3ee314fe-7c16-4de0-874a-e418db2f0916.png" width="175" title="" crop="0,0,1,1" id="tuu1B" class="ne-image"> |

#### 为智能体插件注入自定义组件
`app.json`中配置及解释：

```json
{
  "pages": ["pages/index/index"],
  "plugins": {
    "myPlugin": {
      "version": "*", // 智能体插件版本号
      "provider": "2021005127651682", // 智能体插件id
      "genericsImplementation": {
        // 插件页面
        "chat-page": {
          // 自定义组件，必须用host-card这个名称，相当于组件名
          "host-card": "./components/host-card/index"
        }
      }
    }
  }
}

```

:::info
解释：

为智能体插件中的`chat-page`对话页面提供一个名为`host-card`的自定义组件，该自定义组件的路径是`./components/host-card/index`

插件会引用`host-card`组件，将它放在首页指定区域。

**（****👀****总结，这个配置中的**`**chat-page**`**和**`**host-card**`**要固定写死不能变，组件路径随便）**

:::
