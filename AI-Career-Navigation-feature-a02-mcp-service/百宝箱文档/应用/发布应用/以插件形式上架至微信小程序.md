## 代码引入
### 引入插件
使用插件前，使用者要在 app.json 中声明需要使用的插件和对应的版本，完整配置如下：

> 建议采用分包策略进行插件注册，这样可以避免体积过大的问题（单包体积2M上限）
>

```json
{
  "pages": [
    "省略...",
  ],
  "subpackages": [
    {
      "root": "subpackage",
      "pages": [
        "index/index"
      ],
      "plugins": {
        "chatPlugin": {
          "version": "1.1.18",
          "provider": "wx62abac5e2cdc7aab",
          "export": "exportToPlugin.js"
        }
      }
    }
  ]
}
```

### 进入插件智能体对话页
      需要跳转到插件页面时，url 使用 plugin:// 前缀，形如 `plugin://[PLUGIN_NAME]/[PLUGIN_PAGE]`,这里的[PLUGIN_NAME]就是第一步app.json里配置的插件命名（chatPlugin），页面固定为`chat-page`

:::info
智能体对话页: `plugin://chatPlugin/chat-page?[query参数]`

:::

##### wxml进入插件
```jsx
<navigator url="plugin://chatPlugin/chat-page?[query参数]">
  进入对话页
</navigator>

```

##### js进入插件
```javascript
wx.navigateTo({
  url: 'plugin://chatPlugin/chat-page?[query参数]',
});
```

#### <font style="color:rgb(38, 38, 38);">用户身份</font>
<font style="color:rgb(38, 38, 38);">      用户身份是智能体中非常重要的信息，小程序插件默认会获取当前使用支付宝小程序的用户支付宝open_id传入到百宝箱工作流中，开发者可在工作流中根据用户ID参数做相关业务处理。</font>

<font style="color:rgb(38, 38, 38);">      如果业务项目中需要传入小程序主体自身的用户身份信息，可接入Auth身份认证</font>

[OAuth身份认证介绍 · 蚂蚁百宝箱](https://alipaytbox.yuque.com/sxs0ba/huntb8/qt7b0r4iaydeqf8h)

#### query参数支持如下
| 参数名 | 类型 | 是否必填 | 说明 |
| :---: | :---: | :---: | :--- |
| agent_id | `string` | **是** | 接入的智能体工作流id |
| user_id | `string` | **否** | 标志用户的唯一id，一般为微信的`openid`，也支持接入方自定义 |
| code | `string` | **否** | 标志用户的唯一id，一般为微信的`openid`，也支持接入方自定义 |
| channel | `string` | **否** | 渠道信息，在对接百宝箱时双方约定生成 |
| query | `string` | **否** | 进入对话流时默认发送的对话文本 |
| query_hide | `string` | **否** | 与`query`同时使用，控制是否隐藏默认发送的对话文本，需要隐藏时，设置为字符串的`true`即可 |


:::color5
##### 注意
+ query中传入 user_id 是通用的免认证一般用法
+ code & channel 是高级认证用法，用处更多，但接入相对复杂，如需使用请联系百宝箱工作人员
+ `user_id` 与 `code` & `channel` 互斥，query中**至少包含二者其一**

:::

### <font style="color:rgb(38, 38, 38);">实现自定义容器组件</font>
<font style="color:rgb(38, 38, 38);">为了降低代码</font>**接入成本**<font style="color:rgb(38, 38, 38);">，可实现一个容器组件，将容器组件传递给智能体插件，智能体插件会传入一个</font>`<font style="color:rgb(38, 38, 38);">cardData</font>`<font style="color:rgb(38, 38, 38);">属性，容器组件可根据</font>`<font style="color:rgb(38, 38, 38);">cardData.card_id</font>`<font style="color:rgb(38, 38, 38);">去判断该渲染哪一个组件</font>

```xml
<view>
  <!-- 自定义开场白欢迎卡片 -->
  <custom-card-1
    wx:if="{{ cardData.card_id === '2025xxx0' }}"
    cardData="{{cardData}}"
    bridgeAPI="{{bridgeAPI}}"
  />
  <!-- 自定义回答卡片 -->
  <custom-card-2
    wx:if="{{ cardData.card_id === '2025xxx1' }}"
    cardData="{{cardData}}"
    bridgeAPI="{{bridgeAPI}}"
  />
</view>
```

```json
{
  "component": true,
  "usingComponents": {
    "custom-card-1": "../custom-card-1/index",
    "custom-card-2": "../custom-card-2/index"
  }
}
```

```vue
Component({
  properties: {
    cardData: {
      type: Object,
      value: {},
    },
    bridgeAPI: {
      type: Object,
      value: {},
    },
  },
  data: {},
  methods: {},
});
```

### 自定义组件接收参数
#### cardData
下发的卡片数据，数据结构在百宝箱平台自定义卡片中配置。

#### bridgeAPI
为了实现 用户自定义的 小程序组件卡片与智能体对话环境的交互，目前提供了多种常用功能，如发起query、页面跳转等。详细见：

| 属性/方法 | 说明 | 类型 |
| --- | --- | --- |
| openScheme | 跳转三方小程序/宿主小程序/h5 | `(params: { scheme, success, fail })=>void` |
| sendQuery | 发送query，（`question_content`是query词, `biz_extra_params`是业务扩展参数，随query一起发送）,第二个可选配置参数支持传递`hidden`控制发送query后卡片隐藏 | `(queryObj: { question_content, biz_extra_params: {} }, params: {query_hide: boolean})=>void`<br/>参数说明：<br/>接收两个参数，都是对象，第一个参数接收两个属性：<br/>+ `question_content`是发送消息文字，必传<br/>+ `biz_extra_params`是扩展参数，非必传 |
| requestId | 当前消息id | `String` |
| lastedRequestId | 本次会话最新消息id | `String` |
| agentId | 百宝箱应用id | `String` |
| isHistory | 是否是历史卡片 | `Boolean` |
| conversationId | 本次会话id | `String` |

### 为智能体插件注入自定义组件
`app.json`中配置及解释：

```json
{
  "pages": ["pages/index/index"],
  "plugins": {
    "chatPlugin": {
      "version": "1.1.18",
      "provider": "wx62abac5e2cdc7aab",
      "export": "exportToPlugin.js",
      "genericsImplementation": {
        "chat-page": {
          "host-card": "components/parent-host-comp/index"
        }
      }
    }
  }
}

```

:::info
解释：

为智能体插件中的`chat-page`对话页面提供一个名为`host-card`的自定义组件，该自定义组件的路径是`./components/parent-host-comp/index`

插件会引用`host-card`组件，将它放在首页指定区域。

**（****👀****总结，这个配置中的**`**chat-page**`**和**`**host-card**`**要固定写死不能变，组件路径随便）**

:::

# FAQ
## 怎么从智能体对话页跳转到宿主小程序指定页面？
受制于微信小程序限制，目前**没有任何手段可以实现这个功能**，插件是**<font style="color:#DF2A3F;">不能跳转</font>**到宿主页面的，只能使用`navigateToMiniProgram`跳转其他小程序，[详见这里](https://developers.weixin.qq.com/miniprogram/dev/framework/plugin/api-limit.html)

## 插件不支持超长文本音频播放
受制于webAudio API 的限制，由于不能使用`AudioWorklet`，智能体对话页的文本自动播报能力在遇到超长文本播报场景会有**性能问题**，建议手动关闭语音自动播报功能

<img src="https://cdn.nlark.com/yuque/0/2026/png/2591869/1767771616724-6f1d0205-c332-4994-9449-e232dc57dc1a.png" width="120.5" title="" crop="0,0,1,1" id="P5uNG" class="ne-image">

## 宿主自定义卡片不展示
微信开发者工具对插件 & 宿主自定义卡片的渲染存在兼容性问题，即使代码配置、代码引用都是正确的，在微信开发者工具上面，智能体对话流依然有可能渲染不出宿主提供的自定义卡片，所以建议优先使用 预览 & 真机调试 功能来验证，正确的配置和引入自定义卡片**一定能在预览、真机调试模式下显示**
