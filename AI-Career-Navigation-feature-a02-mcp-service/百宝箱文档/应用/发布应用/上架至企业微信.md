# 前提说明
+ 已注册[企业微信](https://work.weixin.qq.com/)，并通过<font style="color:rgba(0, 0, 0, 0.88);">API长连接方式创建智能机器人</font>
+ <font style="color:#000000;">使用行业应用模版克隆的应用，需添加至“白名单”后才可上架至该渠道，如需使用请在右下角在线客服联系平台添加“白名单”。自行创建的对话型应用，可以正常发布至该渠道。</font>
+ <font style="color:#000000;">企业微信机器人</font>**<font style="color:#000000;">不支持Markdown格式的输出</font>**<font style="color:#000000;">。建议开发智能体时，Prompt中明确指明“输出内容不能使用Markdown格式”</font>
