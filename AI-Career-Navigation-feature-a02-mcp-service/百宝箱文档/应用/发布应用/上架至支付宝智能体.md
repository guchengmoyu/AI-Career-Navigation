本文介绍如何将智能体应用发布到支付宝中<font style="color:rgb(64, 64, 64);">，助力业务多渠道上架</font>。

## 前提条件
1. 将应用发布上架至支付宝智能体时，智能体应用需要满足以下质量要求：
+ <font style="color:#343030;">回答准确率 ≥ 90%；</font>
+ <font style="color:#343030;">首个token P90产出耗时 ≤15s；</font>
+ <font style="color:#343030;">首个token P99产出耗时 ≤15s；</font>

:::info
**说明**：您可根据[评测智能体](https://alipaytbox.yuque.com/sxs0ba/huntb8/evaluation_agent)完成相关报告的生成。

:::

## 操作步骤
1. 在应用编排页，点击右上角的发布，以进入发布配置页。
2. 在应用发布配置页，点击开放渠道 > 支付宝智能体 > **上架**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1771918439451-7f2a3922-5a9c-4ff2-9db2-d75a913dadc5.png" width="1522.4" title="" crop="0,0,1,1" id="u6589bdc1" class="ne-image">
3. 在支付宝智能体上架面板中，完成应用信息编辑并勾选同意《智能体入驻协议》后，点击**确定**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1771918617896-74dbb7a0-1e8e-4339-a794-06e8640ec453.png" width="877.6" title="" crop="0,0,1,1" id="ua842f143" class="ne-image">

其中，各配置项说明如下。

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 基本信息-应用名称 | 是 | 默认为创建应用时填入的应用名称，支持按需修改。 |
| 基本信息-应用介绍 | 是 | 默认为创建应用时填入的应用介绍信息，支持按需修改。 |
| 行业类目 | 是 | 默认为创建应用时选择的所属行业信息，支持修改。 |
| 提供方 | 是 | <font style="color:#000000;">指智能体的业务提供方的主体名称，后续在支付宝的智能体列表中，为智能体的基本信息（显示位置如下图）</font><br/><img src="https://mdn.alipayobjects.com/huamei_b00jk5/afts/img/A*BzV8R5lAXK4AAAAAQcAAAAgAegitAQ/original" width="211.99655151367188" title="" crop="0,0,1,1" id="z6DqB" class="ne-image"> |
| <font style="color:rgba(0, 0, 0, 0.88);">质量准入评测报告</font> | 是 | <font style="color:#000000;">默认显示最近一次符合支付宝侧准入要求的报告。如您当下存在多个满足要求的评测任务，您可自行变更，仅单选</font> |


4. 点击确定后，将发起上架审核，待审批通过后，将为您执行上架操作，您可在应用发布配置页查看审批状态或取消上架申请。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1771919029616-c038e52c-aec7-442d-8d1b-b1699f0a8c3f.png" width="1521.6" title="" crop="0,0,1,1" id="u768faf5c" class="ne-image">

:::info
**说明**：

+ 支付宝官方会对应用质量进行审核，预计2个工作日完成申请，请耐心等待。
+ **若支付宝侧审核不通过**，请点击“查看原因”查看相关原因，根据问题点进行应用质量的优化后，再次发起“上架”申请。
+ **若支付宝侧审核通过，产品将自动完成智能体应用的上线。**

:::
