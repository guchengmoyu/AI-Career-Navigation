将智能体应用发布到微信小程序后，智能体应用将作为独立的微信小程序，在微信端提供服务。<font style="color:#181818;">即</font>**<font style="color:#181818;">小程序如已有页面功能，智能体在小程序部署后将覆盖原有小程序的所有页面。</font>**

# <font style="color:#181818;">使用限制</font>
+ <font style="color:#000000;">一个智能体只能发布到一个微信小程序</font>
+ <font style="color:#000000;">微信小程序账号主体类型需为个人以外的其他类型，并完整填写基本信息和服务类目</font>
+ <font style="color:#000000;">微信小程序需完成备案，备案流程可参考</font><font style="color:rgba(0, 0, 0, 0.45);"> </font>[<font style="color:rgb(34, 45, 217);">微信开放平台文档</font>](https://developers.weixin.qq.com/miniprogram/product/record/record_guidelines.html)
+ 仅支持对话型应用发布至微信小程序。当下“白名单”上线，如您需使用该渠道，可通过在线客服联系平台添加白名单。
