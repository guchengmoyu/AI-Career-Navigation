<font style="color:#000000;">智能体应用以H5链接的形式嵌入小程序。上架后，自动生成公开访问的H5地址，您可以将该地址配置在微信小程序中。</font>

# <font style="color:#000000;">使用限制</font>
+ <font style="color:#000000;">需要有自己的微信小程序</font>
+ <font style="color:#000000;">搭建的智能体应用相关卡片均支持H5端渲染</font>

# 操作步骤
## 上架至微信H5服务
1. 应用创建完成后，单击页面右上角“发布”。“确认发布”后，进入发布渠道页面。

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1756446243071-e313feff-f191-42c3-9020-46dae7778d53.png" width="1590.0000421206169" title="" crop="0,0,1,1" id="ub40c560d" class="ne-image">

2. 在发布渠道页面，“微信tab”下选择发布渠道：微信H5服务，并点击“上架”。

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1763003485992-83552045-8e14-460c-a669-d69773baf559.png" width="1602.2222646666173" title="" crop="0,0,1,1" id="u7137f21c" class="ne-image">

3. 在“<font style="color:rgba(0, 0, 0, 0.88);">上架微信H5服务</font>”弹窗中，完成表单配置：

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1763003486134-34cc47ac-5921-4920-b56f-595f629f5390.png" width="576.1111263728441" title="" crop="0,0,1,1" id="u14d8bac5" class="ne-image">

| --- | --- |
| <font style="color:rgba(0, 0, 0, 0.88);">APP ID</font> | 前往 [微信公众平台](https://mp.weixin.qq.com/) 账号设置->基本设置->账号设置，复制APP ID（小程序ID）信息 |
| <font style="color:rgba(0, 0, 0, 0.88);">是否进行用户身份校验</font> | 指用户进入小程序后访问智能体应用，进行用户身份校验将保障用户身份信息在小程序和智能体应用中是一致的、安全的。建议您选择“是”。 |

完成表单配置后，点击“确定”提交表单。

4. 上架表单提交后，平台将自动发起智能体的上架，并自动生成公开访问地址。

## 下架至微信H5服务
点击“申请下架”，再次确认后，即可实现取消上架。

> <font style="color:#000000;">注意：</font>
>
