本文介绍如何将智能体应用通过插件的形式发布到微信小程序中，<font style="color:rgb(64, 64, 64);">实现AI能力与小程序场景的深度融合，助力业务智能化升级</font>。

**当下该渠道仅对使用过该渠道的应用可见，新增应用或者之前没有使用过该渠道的应用，将不支持使用该渠道。**

# 前提说明
+ 一个微信小程序只可以通过插件绑定一个智能体
+ 使用“出行”、“博物馆”和“文旅景区”行业应用模版克隆的应用，需添加至“白名单”后才可上架至“微信小程序插件”渠道。如需使用，请在右下角在线客服联系平台进行支持。
+ 重点操作：完成插件添加和审批后，请<font style="color:rgba(0, 0, 0, 0.88);">根据</font>[开发文档](https://mp.weixin.qq.com/wxopen/plugindevdoc?appid=wx62abac5e2cdc7aab&token=370366878&lang=zh_CN)完成使用插件的开发

# 操作步骤
## 上架微信小程序插件
1. 应用创建完成后，单击页面右上角“发布”。“确认发布”后，进入发布渠道页面。

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1752052017534-11026584-b50a-4256-8825-f2cd9bb8c76b.png" width="1591.1111532611624" title="" crop="0,0,1,1" id="u98ba3057" class="ne-image">

2. 在发布渠道页面，“微信”tab下的“<font style="color:rgb(0, 0, 0);">微信小程序插件</font>”渠道点击“上架”。

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1752052017546-a24f7332-c7ff-4be1-9b5a-63a44c43ef01.png" width="1595.5555978233442" title="" crop="0,0,1,1" id="u3eab57d8" class="ne-image">

3. **<font style="color:rgba(0, 0, 0, 0.88);">订购插件，实现插件与微信小程序的绑定</font>**
+ 步骤一：前往微信小程序后台，复制以下2个插件的ID，在微信小程序完成插件的添加
    - 复制2个插件的ID

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1752052017693-36772038-81c3-4503-921c-01eeaef548fc.png" width="640.8837280273438" title="" crop="0,0,1,1" id="u4686c042" class="ne-image">

    - 将上两个插件在微信测完成添加，具体配置路径如下：

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1752052019684-f140b9fa-048e-4722-aa58-1f2a1e36bdb3.png" width="1291.111145313876" title="" crop="0,0,1,1" id="ua254dcab" class="ne-image">

+ 步骤二：等待<font style="color:rgba(0, 0, 0, 0.88);">插件开发者通过申请后，根据</font>[开发文档](https://mp.weixin.qq.com/wxopen/plugindevdoc?appid=wx62abac5e2cdc7aab&token=370366878&lang=zh_CN) 完成使用插件的开发

可在插件管理的“状态”列插件申请是否通过：

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1752052019283-0845f48b-a95a-4b76-8bc1-655ac3176aa9.png" width="892.7778014283127" title="" crop="0,0,1,1" id="u75e51c92" class="ne-image">

4. 在“<font style="color:rgba(0, 0, 0, 0.88);">上架微信小程序插件</font>”表单中，**输入绑定的小程序ID**。点击确定后，即可完成智能体以插件的形式在小程序内使用。

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1752052019437-8bd84faf-5429-4982-b018-18220acd297b.png" width="912.2222463878591" title="" crop="0,0,1,1" id="ua1239f28" class="ne-image">

**小程序 APP ID获取方式：**

+ 步骤一：点击“<font style="color:rgb(31, 31, 31);">微信公众平台</font>”登陆小程序

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1752052019539-d0db2d3d-5bc3-4d18-adf5-0e0feb727efb.png" width="602.8837280273438" title="" crop="0,0,1,1" id="uda74fdcf" class="ne-image">

+ 步骤二：复制小程序ID，路径：<font style="color:rgb(31, 31, 31);">账号设置 -> 基本设置</font>

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1752052019814-687ddc3a-8e0b-4977-a638-9fc1af534a0c.png" width="913.8889130986773" title="" crop="0,0,1,1" id="ue7fbd8ea" class="ne-image">

6.完成小程序 APP ID的配置后，点击“确定”，即完成了该渠道的发布

<img src="https://cdn.nlark.com/yuque/0/2025/png/50703104/1752052021672-ef00698c-1da2-4fdc-969b-2ccca3a60e5d.png" width="1260.000033378602" title="" crop="0,0,1,1" id="u4613446e" class="ne-image">

## 下架微信小程序插件
微信小程序插件完成上架后，点击“申请下架”，即可完成该渠道的下架。
