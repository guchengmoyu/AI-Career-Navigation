# 概述
<font style="color:rgb(15, 17, 21);">百宝箱提供覆盖多行业的应用模板，助力企业及开发者快速构建行业复杂智能体。您可直接克隆现有模板，根据业务需求灵活定制；也可将自研应用发布至模板市场，供其他开发者使用，进一步提升个人或企业的影响力。</font>

# 资源说明
模板应用所关联的知识库、插件及卡片资源，在模板上架并完成克隆后，其使用情况如下：

| 资源类型 | 模板克隆后资源情况说明 |
| --- | --- |
| 知识库/应用数据 | + 模板所使用的知识库及关联的应用数据，其结构将完整克隆至使用者空间<br/>+ 实际数据内容不会被克隆 |
| 插件 | + 官方插件：由官方维护，模板克隆后仍保持引用关系<br/>+ 个人插件：由开发者维护，模板克隆后相关插件资源将同步复制至使用者空间 |
| 卡片 | + 官方卡片：由官方维护，模板克隆后仍保持引用关系不变<br/>+ 个人卡片：由开发者维护，模板克隆后相关卡片资源将同步复制至使用者空间 |


# 如何上架应用至模板市场
## 提交上架申请
**前置条件**：完成应用的创建并通过必要的调试运行和发布流程。

<img src="https://cdn.nlark.com/yuque/0/2025/png/29282973/1758788267591-3121bf5d-2cd8-4f60-a63d-2c1fb357a29a.png" width="1440" title="" crop="0,0,1,1" id="ueeb92177" class="ne-image">

**操作步骤**：

1. 进入上架渠道页面，在 **行业应用模板** 标签页中点击 **上架** 按钮。
2. 填写上架配置信息：
    - **模板分类**：必填，选择与应用所属行业相匹配的分类；
    - **模板简介**：必填，用1-2句话简要说明模板的核心能力；
    - **使用说明文档**：提供公开访问的文档链接，内容需清晰介绍模板功能及使用方式，可参考右上角文档示例；
    - **公开体验渠道**：若应用已上架至支付宝、微信等渠道，可选择作为移动端体验入口，模板详情页将展示该渠道的二维码；
    - **配置项**：系统将自动解析模板包含的资源项，鼠标悬停可查看详情，请确认资源信息无误。
3. 信息确认无误后，点击 **确定**，提交模板上架申请。

## 应用更新
当您的应用存在服务升级或基础信息修改等更新时，请按以下步骤重新提交上架申请：

1. 应用发布新版本后，进入上架渠道页面，**行业应用模板** 标签页中点击 **上架** 按钮。
2. 根据更新内容填写并提交上架配置（流程同上）。
3. 新版本需重新通过平台审核后，方可覆盖更新模板市场中的原有版本。
