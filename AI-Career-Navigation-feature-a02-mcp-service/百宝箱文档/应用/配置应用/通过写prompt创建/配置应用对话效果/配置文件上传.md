百宝箱支持开发者通过控制文件上传的开关，来选择是否为智能体添加包括文档、图片、视频、音频上传的多模态交互能力。本文将介绍如何配置文件上传。

:::warning
⚠️ **注意：**在开启文件上传能力前，请确保当前应用已经配置了具有对应文件处理能力的大模型或插件。

:::

## 效果展示
开启文件上传能力后，用户在输入 query 的过程中，可进行对应类型的文件上传，从而丰富交互体验。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1762155861984-e526d088-99fc-44e8-8025-c1ff58ba46de.png" width="1535.2" title="" crop="0,0,1,1" id="ue142fde7" class="ne-image">

## 配置说明
1. 开发者访问[我的应用](https://b.tbox.cn/inc/my)。
2. 在应用列表中找到并点击目标（简单构建的对话型）应用。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1762155097068-7037e9cc-e193-42a0-8fa7-bc3a07b3f113.png" width="1535.2" title="" crop="0,0,1,1" id="R7Zvb" class="ne-image">
3. 在应用编排页面，点击开启对话配置 > 文件上传 > 文件类型的开关。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1762156135390-5eaf14e6-2d09-4b94-90d6-695066e34f12.png" width="1000.8" title="" crop="0,0,1,1" id="u8ce9d6e0" class="ne-image">

其中，支持的文件类型与要求如下。

| 能力名称 | 说明 |
| --- | --- |
| 文档上传 | 支持用户在使用应用过程中上传文档，限制如下：<br/>+ 文件数量：最多 20 个；<br/>+ 文件大小：每个文件不超过 20 MB；<br/>+ 文件类型：.pdf、.txt、.csv、.doc、.docx、.xlsx、.md、.json、.pptx、.ppt、.xls。 |
| 图片上传 | 支持用户在使用应用过程中上传图片，限制如下：<br/>+ 图片数量：单次最多上传10 张；<br/>+ 图片大小：不超 10 MB；<br/>+ 图片格式： .jpg、.jpeg、.bmp、.webp、.png。 |
| 视频上传 | 支持用户在使用应用的过程中上传视频，限制如下：<br/>+ 文件数量：单次最多 3 个；<br/>+ 文件大小：每个文件不超过 100 MB；<br/>+ 文件类型：.mp4、.mkv、.mov、.avi、.flv |
| 音频上传 | 支持用户在使用应用的过程中上传音频，限制如下：<br/>+ 文件数量：单次最多 3 个；<br/>+ 文件大小：每个文件不超过 100 MB；<br/>+ 文件类型：.mp3、.m4a、.pcm、.aac、.mav |


4. 同时，开发者可以将鼠标 hover 在目标文件类型的卡片上，点击调整配置，来控制用户上传的文件格式、文件大小、单次最多上传文件数等配置。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1762156721806-a8455cb2-6760-4343-a2d9-a96d874c63bf.png" width="1022.4" title="" crop="0,0,1,1" id="ueffa9049" class="ne-image">
