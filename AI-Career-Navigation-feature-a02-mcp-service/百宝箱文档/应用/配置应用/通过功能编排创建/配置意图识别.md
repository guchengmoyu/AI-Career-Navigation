意图识别是功能编排应用的核心能力。能够自动识别用户输入（query），并匹配开发者预设的意图分支（插件或子工作流），从而为用户提供高效且准确的智能服务。

## 操作步骤
1. 开发者访问[我的应用](https://b.tbox.cn/inc/my)。
2. 在应用列表中，找到并点击目标应用卡片，以进入功能编排页面。
3. 在功能编排页面，点击意图识别模块的 **+ 添加新功能**。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1766391857127-93c13e11-d865-4b8d-8c6f-c21a1853cc0b.png" width="1533.6" title="" crop="0,0,1,1" id="uc9d57868" class="ne-image">
4. 在意图识别配置面板中，分别配置功能名称、调用场景、标签、调用技能以及核心功能示意图等信息。完成配置后，点击右上角的**确定**。

<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1766391975535-aa970150-da96-4d89-974d-f8ad2fec317b.png" width="500" title="" crop="0,0,1,1" id="u91cf77fd" class="ne-image">

其中，各配置项说明如下。

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 功能名称 | 是 | 指当前意图识别能力的场景名称，例如“美食导购”、“酒店推荐”等 |
| 调用场景 | 是 | 指当前场景的详细描述，例如当用户提问涉及美食推荐、周边有什么餐饮等问题时，调用本场景，从而帮助大模型进行更为准确的意图识别。 |
| 标签 | 否 | 指对场景的补充说明。 |
| 调用技能 | 是 | 点击调用技能区域的**点击添加 > 插件/（子）工作流**实现对应能力的集成与引用，从而扩展当前场景下，智能体的边界能力。 |
| 核心功能示意图 | 否 | 点击上传图片，为当前场景配图，帮助开发者或运维人员快速识别并定位当前场景能力。 |
