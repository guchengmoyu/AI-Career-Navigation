本文将介绍如何配置 AI 构建产物应用的对话效果，从而提升产物应用的对客表现。

## 能力概览
对话配置是智能体应用的核心交互设置模块。通过该模块，你可以从模型底座、交互方式、多媒体能力、快捷指令四个维度，全方位定义智能体的对话体验。

无论是需要高精度逻辑推理的专业助手，还是支持语音交互的陪伴型应用，你都可以通过灵活的组合配置，快速构建出符合业务场景的智能体。

## 适用场景
以下是几种常见业务的应用配置场景，帮助你更好地选择配置：

| 业务场景 | 推荐配置 | 场景说明 |
| --- | --- | --- |
| <font style="color:rgb(13, 13, 13);">专业办公助手</font> | <font style="color:rgb(13, 13, 13);">高性能大模型 + 打字输入 + 开启图片/文件上传 + 关闭语音</font> | <font style="color:rgb(13, 13, 13);">适用于代码生成、文档分析等场景，强调输入的精准度与多模态处理能力。</font> |
| <font style="color:rgb(13, 13, 13);">适老化/无障碍服务</font> | <font style="color:rgb(13, 13, 13);">默认语音输入 + 开启语音播报 + 开启语音输入开关</font> | <font style="color:rgb(13, 13, 13);">降低使用门槛，让用户通过“听说”即可完成所有交互，无需手动打字。</font> |
| <font style="color:rgb(13, 13, 13);">创意/设计类应用</font> | <font style="color:rgb(13, 13, 13);">开启图片/视频上传 + 快捷指令（如“生成海报”、“风格迁移”）</font> | <font style="color:rgb(13, 13, 13);">侧重于视觉内容的输入与处理，配合快捷指令提升创作效率。</font> |
| <font style="color:rgb(13, 13, 13);">轻量级咨询问答</font> | <font style="color:rgb(13, 13, 13);">标准大模型 + 打字输入 + 预设快捷指令（如“常见问题”）</font> | <font style="color:rgb(13, 13, 13);">适用于客服或信息查询，通过快捷指令引导用户快速提问，减少输入成本。</font> |


## 配置说明
在应用构建的预览页，你可以点击左上角的对话配置，唤起对话配置面板，进行相关配置。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1785464888336-88a09e53-87a3-43fe-a749-0e63b16ba195.png" width="1048.8" title="" crop="0,0,1,1" id="u8bac8bc7" class="ne-image">

各配置说明如下。

| 配置模块 | 配置项 | 说明 |
| --- | --- | --- |
| 大模型 | 模型切换 | 在下拉列表中开通模型服务并选择应用内提供智能服务的大语言模型。<br/>:::info **说明**：在进行模型配置前，请先完成[模型服务开通](https://alipaytbox.yuque.com/sxs0ba/huntb8/bill_activate_model_service)。<br/>:::  |
| 默认输入方式 | 默认输入方式切换 | 选择用户在应用内对话的输入方式，当前支持打字输入与语音输入两种。 |
| 支持文件上传 | 图片上传 | 通过开关控制当前应用是否支持用户上传图片。 |
| | 视频上传 | 通过开关控制当前应用是否支持用户上传视频。 |
| 语音 | 语音输入 | 通过开关控制当前应用是否支持用户通过语音输入与应用对话。该配置优先级高于默认输入方式，即使配置的默认输入方式为“语音输入”，若关闭该配置，用户也无法通过语音方式进行对话。 |
| | 语音播报 | 通过开关控制当前应用是否支持语音播报能力。 |
| 快捷指令 | 配置快捷指令 | AI 构建能力在进行应用构建时，会根据你输入的需求初步生成快捷指令，你可以在这里：<br/>+ 点击编辑：修改指令名称与指令的文本内容。<br/>+ 点击删除：删除不符合预期的快捷指令。<br/>+ 点击添加：新增自定义指令名称与内容。 |
