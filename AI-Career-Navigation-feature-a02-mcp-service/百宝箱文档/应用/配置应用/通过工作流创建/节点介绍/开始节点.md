开始节点是工作流的默认节点之一，用于接收用户输入到智能体应用的内容并携带全局变量以启动整个工作流。它只有输入参数，并不包含输出参数。开发者可按需变更输入参数中当前对话信息（即用户输入的原始内容）的数据类型，并自定义其他参数。

### 添加开始节点
在创建工作流应用时，默认带有且仅有一个开始节点，无需单独添加。

### 配置开始节点
1. 在工作流的流程逻辑页面，点击开始节点卡片，唤起开始节点配置面板。
2. 在开始节点配置面板中按需更改当前对话信息的数据类型、添加自定义参数、变更节点所携带的历史对话轮数。<img src="https://cdn.nlark.com/yuque/0/2025/png/1397496/1764222292127-65563111-9c16-4892-9dd1-257420bff735.png" width="2043.2" title="" crop="0,0,1,1" id="ud60b030e" class="ne-image">

其中，各配置项说明如下。

| 配置项 | 说明 |
| --- | --- |
| 当前对话信息 | 支持选择文本以及结构化数据的输入类型。 |
| 自定义参数 | 支持开发者自行维护字段的名称、描述以及数据类型，作为自定义变量在工作流运行过程中流转。 |
| 携带历史对话轮数 | 指每次对话携带的历史对话长度，默认为 3，该值越大携带的内容越多。 |
