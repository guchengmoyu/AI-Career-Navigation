知识库是用于存储、向量化处理开发者上传至百宝箱的应用数据，从而为智能体提供更加精准的回复内容。百宝箱支持以节点的形式将知识库串联在工作流中，为智能体提供知识管理能力。

<font style="color:rgb(38, 38, 38);">百宝箱采用</font>**<font style="color:rgb(38, 38, 38);">数据准备层</font>**<font style="color:rgb(38, 38, 38);">与</font>**<font style="color:rgb(38, 38, 38);">知识库管理层</font>**<font style="color:rgb(38, 38, 38);">结合的知识库架构。该架构将数据处理与知识重组解耦，实现专业化分工与资源的高效复用，从而为企业提供更加强大、灵活且高效知识管理能力，共同支撑企业级知识服务的构建与运营。</font>

## 配置知识库节点
完成知识库节点的添加后，百宝箱还支持在节点配置面板中，进行搜索关键词配置、知识库添加、高级参数配置以及输出内容的配置，从而提升知识库召回的准确性。

1. 在工作流编排面板，点击知识库节点。
2. 在唤起的知识库配置面板中，进行节点配置。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1782717882706-1c7c1f23-21d7-4969-8856-b9ca0acab161.png" width="2047.2" title="" crop="0,0,1,1" id="u2606815f" class="ne-image">
3. 在节点配置时，根据业务诉求，进行语义/全文检索或地理位置检索的检索方式选择。

:::info
**说明**：两种检索方式仅支持单独启用，不支持同时使用，请根据业务需求选择对应的检索方式。

:::

### 语义/全文检索
当选择**语义/全文检索**时，各配置项说明如下。

| 模块 | 配置项 | 说明 |
| --- | --- | --- |
| 输入 | 搜索关键词 | 指用于在知识库进行匹配知识点的关键词，支持：<br/>+ 固定：由开发者指定关键词，进行知识点匹配。<br/>+ 引用：引用前置节点的输出内容作为知识点匹配的关键词，如引用开始节点的对话信息等。 |
| 知识库 | 知识库关联绑定 | 支持通过定向选择以及按类目批量选择的方式进行知识库添加，其中：<br/>+ **按知识库定向选择**：支持在知识库列表中手动选择目标知识库，并将其与节点关联，适用于任务简单且明确的一次性场景。<br/>+ **按类目批量选择**：通过勾选单个或多个分组，实现目标分组下各知识库的批量添加，从而实现知识库的动态匹配。 |
| | 路由方式 | 指动态匹配知识库的方式，**仅通过按类目选择进行知识库绑定时可用**。支持：<br/>+ **模型智能路由**：能够基于大语言模型对用户意图的理解能力，自动分析用户问题与知识库内个文件的标题、描述等信息之间的关联性，从而动态筛选并锁定最相关的特定文档，并仅从该文档中提取知识。关于该能力的详细说明可参见：[模型智能路由](https://alipaytbox.yuque.com/sxs0ba/huntb8/knowledge_intelligent-routing)。<br/>+ **手动路由**：当选择手动路由时，需要通过在匹配方式中手动配置匹配参数（支持固定输入或动态前置节点的输出内容）。系统会根据该参数进行知识库的动态匹配。 |
| 高级配置 | 检索匹配策略 | 指从知识库中获取知识时所采用的检索方式，合适的检索策略能够更有助于找到正确且有效的信息，继而提高智能体答案生成的准确性与可用性。当前支持：<br/>+ **智能检索（默认项）：**结合语义检索和关键词检索的优势，经过综合排序后再给出检索的结果列表，召回效果较好但是耗时会更长。<br/>+ **语义检索：**指通过向量化文本对比的方式，判断问题与知识之间的关联程度，从而筛选出高关联的部分。该策略会像人类一样去理解上下文之间的关系，适用于需要理解语义或跨语言查询的场景。<br/>+ **关键词检索：**指使用提问时的关键词在知识库中进行精确匹配，适用于需要精准回答的场景。 |
| | 检索最大结果数 | 指从知识库返回的最大段落数，该值越大，返回的段落条目越多。默认只返回`5`条。 |
| | 检索最小匹配度 | 匹配度是衡量用户查询（query）与知识库中文档分段见的寓意相关程度的指标，通常取值范围在 `[0,1]`，默认值为 `0.500`:<br/>+ 越靠近 1，说明语义越相关，为 1 时完全一致；<br/>+ 越靠近 0，说明相关性越低，为 0 时毫不相关。<br/>最小匹配度则是一个可预置的阈值，用于对召回结果进行相关性的过滤，低于该值的内容将不会被召回。 |
| | 语义精排 | 精排，即精细排序，是指相连检索完成初步召回后没引入基于预训练语言模型的深度语义排序模型，对召回的文档片段进行二次相关性评估与重排序，以提升最终返回结果的寓意准确性与业务相关性。适用于对回答准确性、专业性和相关性要求较高的业务场景，如智能客服、技术文档 FAQ 等。<br/>+ **未启用精排时：**系统直接一句向量相似度对召回结果进行降序排列，响应速度快，但语义理解能力有限。<br/>+ **启用精排后：**系统将向量化检索召回的候选文档输入至百宝箱预置的 Rerank 模型，该模型会通过细粒度的语义匹配、上下文对齐以及内容质量评估，对结果进行精细化打分和重排，确保与用户查询意图最相关、信息最完整的文档优先输出，开启后会增加耗时。 |
| | 精排最大结果数 | 开启语义精排后可配置，用于设定系统最终返回给用户的最相关结果的数量上限，默认值为 `3`。 |
| | 精排最小匹配度 | 开启语义精排后可配置，用于设定系统最终检索的匹配度阈值，仅保留相关性高于该值的结果，低于该值的将被筛除。默认值为 `0.800`。 |
| | 后排序 | 开启后将打乱知识库原有的混合召回排序，召回结果会按自定义规则重新排列，可拖拽调整优先级。 |
| | 高级配置模板 | 点击高级配置右侧的**使用模板配置**，可快速启用百宝箱基于行业特性预置的参数模板，从而降低高级配置参数的配置难度。 |
| 输出 | 名称 | 可自定义节点输出的名称，默认为“结果”。 |
|  | 数据类型 | 设置知识库节点返回内容时，所采用的数据类型，可选择：<br/>+ **数组结构化数据**：以 JSON 的形式返回内容。<br/>+ **数组文本**：以非结构化文本的形式返回内容。 |


### 地理位置检索
:::info
**说明：**地理位置检索仅支持关联表格知识库，请确保已创建包含经纬度信息的表格知识库。

:::

当选择地理位置检索时，各配置项说明如下。

| 模块 | 配置项 | 说明 |
| --- | --- | --- |
| 输入 | 经度 | 指定用于检索的经度坐标，支持引用前置节点的输出内容作为经度值，如引用开始节点的定位信息等。 |
| | 纬度 | 指定用于检索的纬度坐标，支持引用前置节点的输出内容作为纬度值。 |
| | 搜索半径 | 设定检索的空间范围，单位为米（m）。默认值为 1000 米。 |
| | 搜索范围 | 指定检索的目标区域范围，支持：<br/>+ **范围内**：返回指定坐标周围搜索半径范围内的知识条目。<br/>+ **范围外**：返回指定坐标周围搜索半径范围外的知识条目。 |
| 知识库 | 知识库关联绑定 | 地理位置检索**仅支持关联表格知识库**。点击"添加知识库"按钮，在知识库列表中选择目标表格知识库进行关联。 |
| 高级配置 | 检索最大结果数 | 指从知识库返回的最大结果条数，默认值为 5 条。该值越大，返回的结果条目越多。 |
| 输出 | 名称 | 可自定义节点输出的名称，默认为"结果"。 |
|  | 数据类型 | 地理位置检索仅支持**数组<结构化数据>**类型返回，以 JSON 形式输出检索结果。 |
