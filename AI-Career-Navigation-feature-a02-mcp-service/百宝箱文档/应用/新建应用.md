本文将介绍如何在百宝箱中新建应用。

## 操作步骤
1. 开发者登录并访问[百宝箱首页](https://www.tbox.cn/agentWeb/aiCoding/home)。
2. 在首页选择 AI 构建、Agentic 自主规划、写 Prompt 以及工作流创建等新建方式。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1788147103645-2e266584-3ce3-45a8-a2c5-26edd28a2e97.png" width="1918" title="" crop="0,0,1,1" id="cbXE2" class="ne-image">

### 方式 1： 使用 AI 构建
当选择 AI 构建时，你只需要在对话框中完成需求描述并进行技能、构建模式、模型等配置，AI 构建助手将根据所配置的内容自动完成智能体的构建。详细说明可参见：[AI 构建概述](https://alipaytbox.yuque.com/sxs0ba/huntb8/aicoding_overview)。

### 方式 2：使用低代码模式
在低代码模式中选择目标模式，并在新建应用面板中，配置应用名称、所属行业、开发模式以及应用描述后，点击右下角的**新建**。<img src="https://cdn.nlark.com/yuque/0/2026/png/1397496/1788148605987-16f8faed-b5f6-4879-b621-10da527aec4d.png" width="679" title="" crop="0,0,1,1" id="nBuSR" class="ne-image">

其中，各配置项说明如下。

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 应用图标 | 是 | 支持上传图片作为应用的图标，发布后，将以智能体头像的形式展现给用户。 |
| 名称 | 是 | 自定义应用名称，发布后将作为智能体的名称对客展示，名称字数需控制在 20 字以内。 |
| 所属行业 | 是 | 选择智能体服务所对应的行业信息，帮助百宝箱更加了解您的开发诉求。 |
| 开发模式 | 是 | 低代码模式下，可选择 Agentic 自主规划、写 Prompt 创建以及工作流三种创建方式，详细说明可参见：[构建方式](https://alipaytbox.yuque.com/sxs0ba/huntb8/agent_overview#KJI0y)。 |
| 描述 | 否 | 自定义应用的描述信息，一个完善的应用描述有助于提升用户对智能体的了解程度，描述字数需控制在 200 字以内。 |
