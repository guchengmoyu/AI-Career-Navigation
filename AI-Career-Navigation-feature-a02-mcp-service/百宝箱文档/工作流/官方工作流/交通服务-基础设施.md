## 代码节点
### 主意图增加交通指南意图识别prompt
```plain
1. 交通指南 
描述: 咨询景点内公共设施的位置信息及怎么去某些地方的导航路线、附近设施
参数:
- 出发地: 用户提问问题类型是附近景点、公共设施介绍，需要提取出发地的地名，未明确则默认返回“当前位置”
- 位置意图: 附近位置/实际位置，提问包含"附近","旁边","周边"为附近位置，否则是实际位置
- 目标位置: 用户提问中的目的地的地名,如带我去立雪堂，提取目标位置为立雪堂，不可为null
- 楼层:  根据语境判断是否涉及楼层信息，如“一楼的餐厅”、“B1层停车场”等，自动补充楼层标识（1F、2F、3F、B1、B2）。
```

def convert_keys(data, mapping):
    """递归处理嵌套结构和字符串中的JSON，排除不在KEY_MAPPING中的字段"""
    if isinstance(data, dict):
        # 只保留 mapping 中存在的键，并进行递归转换
        return {
            mapping[k]: convert_keys(v, mapping)
            for k, v in data.items()
            if k in mapping
        }
    elif isinstance(data, list):
        return [convert_keys(item, mapping) for item in data]
    elif isinstance(data, str):
        try:
            parsed = json.loads(data)
            return convert_keys(parsed, mapping)
        except json.JSONDecodeError:
            return data
    else:
        return data
