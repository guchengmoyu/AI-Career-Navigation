# 来源与改写说明

公开资料只用于建立职业、技能、课程入口、趋势方向和合规约束。模拟岗位、用户、薪资、事件、趋势指数和对话均由本项目生成。

## 使用原则

1. 保存来源机构、URL、访问日期、许可条件和派生字段。
2. 不复制公开课程或行业报告的长段正文。
3. 不自动抓取招聘网站，不保留真实企业名称或完整职位描述。
4. O*NET 派生内容保留署名、许可证和修改声明。
5. 外部页面失效时将资源标记为待复核，不静默替换来源。

## 事实声明层级

- `verified_primary`：逐页核验的官方页面元数据，仅保存标题、提供方、链接和页面类型。
- `primary_derived`：根据公开分类或目录由团队改写、映射或扩展。
- `synthetic`：固定随机种子与规则生成，不代表真实市场事实。

智慧教育平台资源中，22 条为已核验课程或课程专题页，98 条为团队派生主题卡。二者使用不同 `resource_type`，不得在界面中合并标注为“官方课程”。

完整记录见各版本的 `source_registry.csv`。
