# 真实用户测试指南

模拟数据不能替代赛题要求的用户测试反馈。建议在系统可用后组织两轮测试，每轮 5–8 人，总计至少 10–15 名不同测试者。

## 最小流程

1. 明确告知测试目的、采集字段、保存期限和退出方式。
2. 不收集姓名、手机号、学号、身份证或完整简历。
3. 为测试者分配 `TESTER-001` 等匿名编号。
4. 让测试者完成画像、岗位选择、学习计划和一个场景训练任务。
5. 记录任务是否完成、耗时、1–5 分评分、问题和改进建议。
6. 第一轮问题修复后再进行第二轮，并保留版本和修改记录。

空白模板位于 `templates/user_test_feedback_template.csv`。模板不得预填虚构反馈。
