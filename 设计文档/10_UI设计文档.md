# A02 UI/UX 设计文档

## 一、设计概述

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| 简洁清晰 | 减少认知负荷，核心信息一目了然 |
| 引导式体验 | 对于复杂操作（问卷、路径设定）提供分步引导 |
| 数据可视化优先 | 用图表代替文字，直观展示成长数据 |
| 一致性 | 统一的色彩、字体、间距、组件风格 |
| 响应式 | 适配桌面端（≥1024px）和移动端（≥375px） |

### 1.2 设计语言

| 属性 | 规范 |
|------|------|
| 主色调 | #1677FF（科技蓝） |
| 辅助色 | #52C41A（成长绿）、#FAAD14（激励橙）、#FF4D4F（警示红） |
| 背景色 | #F5F7FA（浅灰）/ #141414（深色模式） |
| 圆角 | 8px（卡片）/ 6px（按钮）/ 12px（弹窗） |
| 阴影 | 0 2px 8px rgba(0,0,0,0.08) |
| 字体 | 系统默认字体栈（-apple-system, "PingFang SC", "Microsoft YaHei", ...） |
| 字号 | H1:28px H2:24px H3:20px Body:14px Caption:12px |

│  │          │  │                                      │ │

**侧边栏**：桌面端常驻左侧（宽 200px），可折叠至 64px 图标模式；移动端为底部 Tab 栏。

**顶部导航栏**：固定在顶部，包含 Logo、页面标题、AI 快捷对话入口、用户头像菜单。

### 2.2 页面清单

| 页面 | 路径 | 优先级 | 说明 |
|------|------|--------|------|
| 登录/注册 | `/login` | P0 | 用户认证入口 |
| 首页（总览面板） | `/dashboard` | P0 | 成长数据总览 |
| 信息采集问卷 | `/questionnaire` | P0 | 首次使用引导 |
| 职业画像 | `/profile` | P0 | 能力雷达图与分析 |
| 学习路径 | `/path` | P0 | 路径时间轴与任务 |

| 场景训练交互 | `/scenarios/:id` | P0 | 对话式训练 |
| AI 对话 | `/chat` | P0 | 自由对话界面 |
| 学习进度 | `/progress` | P1 | 详细学习统计 |
| 路径详情 | `/path/:id` | P1 | 路径阶段性详情 |
| 评估报告 | `/evaluation/:id` | P1 | 场景评估详情 |
| 个人设置 | `/settings` | P1 | 偏好与账户管理 |

## 四、交互设计规范

### 4.1 核心交互模式

| 交互模式 | 适用场景 | 实现方式 |
|---------|---------|---------|
| 分步引导 | 问卷填写、路径设定 | 步骤条 + 上/下一步 |
| 卡片展示 | 面板总览、场景列表 | 卡片网格布局 |
| 时间轴 | 学习路径、成长记录 | 垂直时间轴组件 |
| 气泡对话 | AI 对话、场景模拟 | 聊天气泡组件 |
| 数据图表 | 画像、进度、趋势 | ECharts 图表 |
| 抽屉详情 | 任务详情、评估详情 | 侧边抽屉面板 |

### 4.2 反馈机制

| 反馈类型 | 设计方案 |
|---------|---------|
| 加载状态 | 骨架屏 + 进度指示器 |
| 操作成功 | Toast 提示 + 动画反馈 |
| 操作失败 | 错误提示 + 重试按钮 |
| AI 思考中 | 打字机效果 + 思考动画 |
| 数据更新 | 实时刷新 + 变化高亮 |

### 4.3 动画规范

| 动画类型 | 时长 | 缓动函数 | 场景 |
|---------|------|---------|------|
| 页面切换 | 300ms | ease-in-out | 路由切换 |
| 卡片出现 | 200ms | ease-out | 列表加载 |
| 数据变化 | 500ms | ease-in-out | 分数变化 |
| 气泡出现 | 200ms | ease-out | 对话消息 |
| 打字机效果 | 逐字 | linear | AI 回复 |
| 雷达图绘制 | 800ms | ease-out | 首次展示 |
