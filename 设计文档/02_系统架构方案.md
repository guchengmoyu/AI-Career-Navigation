## 二、核心模块设计

### 2.1 用户服务模块

**功能职责**：
- 用户注册、登录、认证
- 用户信息管理
- 用户偏好设置

**技术实现**：
- JWT Token 认证
- OAuth 2.0 第三方登录
- 用户数据加密存储

**接口设计**：
```
POST /api/user/register        # 用户注册
POST /api/user/login           # 用户登录
GET  /api/user/profile         # 获取用户信息
PUT  /api/user/profile         # 更新用户信息
GET  /api/user/preferences     # 获取用户偏好
PUT  /api/user/preferences     # 更新用户偏好
```

---

### 2.2 职业画像模块

**功能职责**：
- 多维度能力评估
- 动态画像生成与更新
- 能力雷达图绘制

**数据维度**：
```
用户画像数据结构 {
  基础信息: {
    教育背景、工作年限、当前职位、所在行业
  }
  能力评估: {
    专业技能、软技能、领导力、创新力、学习力
  }
  兴趣偏好: {
    职业兴趣、工作方式、发展偏好
  }
  市场匹配: {
    岗位匹配度、薪资竞争力、发展潜力
  }
}
```

**技术实现**：
- 基于问卷的能力评估算法
- 基于大模型的深度分析
- 雷达图可视化 (ECharts)

---

### 2.3 职业路径规划模块

**功能职责**：
- 3-5 年职业路径生成
- 学习任务分解
- 路径动态调整

**路径生成算法**：
```
输入: 用户画像 + 目标职位 + 市场数据
      │
      ▼
┌─────────────────┐
│ 能力差距分析     │
│ (Gap Analysis)  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 学习资源匹配     │
│ (Resource Match)│
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 路径优化排序     │
│ (Path Optimize) │
└────────┬────────┘
         │
         ▼
输出: 分阶段学习路径 + 时间表 + 里程碑
```

**路径数据结构**：
```json
{
  "career_path": {
    "target_role": "AI 产品经理",
    "duration": "3年",
    "phases": [
      {
        "phase": 1,
        "title": "基础能力建设",
        "duration": "6个月",
        "milestones": ["完成 Python 基础", "掌握数据分析"],
        "tasks": [
          {
            "type": "course",
            "name": "Python 编程入门",
            "platform": "Coursera",
            "duration": "40小时"
          }
        ]
      }
    ]
  }
}
```

### 2.4 学习路径服务模块

**功能职责**：
- 学习资源整合
- 学习进度追踪
- 学习效果评估

**数据模型**：
```
学习记录 {
  user_id: 用户ID
  path_id: 路径ID
  task_id: 任务ID
  status: 进行中/已完成/已跳过
  start_time: 开始时间
  end_time: 结束时间
  progress: 进度百分比
  score: 完成评分
  feedback: 用户反馈
}
```

---

### 2.5 场景模拟训练模块

**功能职责**：
- 职场场景构建
- 交互式对话模拟
- 表现评估与反馈

**场景设计**：

| 场景类型 | 场景描述 | 训练目标 |
|---------|---------|---------|
| 远程协作 | 模拟远程团队会议、任务分配 | 沟通能力、协作效率 |
| AI 辅助办公 | 使用 AI 工具完成工作任务 | AI 工具使用、效率提升 |
| 跨岗位沟通 | 与不同部门同事沟通需求 | 跨领域沟通、需求理解 |
| 项目汇报 | 向领导汇报项目进展 | 表达能力、逻辑思维 |
| 面试模拟 | 模拟技术/行为面试 | 面试技巧、自我展示 |

**技术实现**：
```
场景模拟流程 {
  1. 场景初始化
     - 选择场景类型
     - 加载场景配置
     - 初始化角色设定

  2. 对话交互
     - 用户输入
     - 大模型处理
     - 角色响应生成

  3. 表现评估
     - 关键指标提取
     - 评分算法计算
     - 反馈建议生成

  4. 结果总结
     - 整体表现评分
     - 改进建议
     - 学习资源推荐
}
```

### 2.6 对话服务模块

**功能职责**：
- 自然语言理解
- 多轮对话管理
- 个性化回复生成

**对话流程**：
```
用户输入
    │
    ▼
┌─────────────┐
│  意图识别    │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  实体抽取    │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  上下文管理  │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  大模型推理  │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  回复生成    │
└──────┬──────┘
       │
       ▼
用户输出
```

**角色设定**：
- **职业导师**：专业、权威，提供深度职业建议
- **学习伙伴**：亲切、鼓励，陪伴学习过程
- **面试教练**：严谨、细致，模拟真实面试场景

---

### 2.7 知识图谱模块

**功能职责**：
- 职业知识图谱构建
- 实体关系管理
- 知识查询与推理

**图谱结构**：
```
节点类型 {
  职业(Job): {名称、描述、薪资范围、技能要求}
  技能(Skill): {名称、类别、难度、学习时长}
  行业(Industry): {名称、趋势、头部公司}
  学习资源(Resource): {名称、平台、类型、评分}
  认证(Certification): {名称、机构、认可度}
}

关系类型 {
  需要技能(Job -> Skill): {必要/加分}
  属于行业(Job -> Industry)
  学习路径(Skill -> Resource)
  进阶关系(Job -> Job): {晋升路径}
  相似技能(Skill -> Skill): {相似度}
}
```

## 五、安全与隐私设计

### 5.1 数据安全措施

| 措施 | 实现方式 |
|------|---------|
| 传输加密 | HTTPS + TLS 1.3 |
| 存储加密 | AES-256 敏感字段加密 |
| 访问控制 | RBAC 权限模型 |
| 日志审计 | 操作日志全记录 |
| 数据脱敏 | 敏感信息展示脱敏 |

### 5.2 隐私保护设计

| 功能 | 说明 |
|------|------|
| 最小必要原则 | 仅收集必要数据 |
| 用户授权 | 明确告知并获取授权 |
| 数据导出 | 支持用户导出个人数据 |
| 数据删除 | 支持用户删除账户与数据 |
| 第三方共享 | 明确告知共享范围与目的 |
